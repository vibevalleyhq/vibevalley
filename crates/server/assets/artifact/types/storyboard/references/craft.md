# 分镜节奏、连贯性工艺与核对清单（storyboard / craft）

## 1. 叙事节奏与景别交替

- **景别有呼吸**：避免连续 3 个以上相同景别与静止镜头；用 `wide` 建立空间 → `medium` 展示交互动作 → `close-up` / `screen-ui` 聚焦关键细节，交替推进。
- **按语速算时长**：中文自然旁白按 **4.2–4.8 字/秒**、英文按 **2.4–2.8 词/秒** 估算 `durationSec`，并在镜头首尾留 `0.3s–0.5s` 气口；一个镜头只讲 1 句核心意思，单镜时长控制在 `2.0s–6.0s`。
- **视听互补，不念屏幕**：画面已经展示的大字标题，旁白负责解释「为什么重要」或情绪推进，避免逐字念出画面上的每个词。

## 2. 视觉连贯性（Continuity）

- 所有镜头的 `prompt` 共享 `styleGuide` 里的光影、镜头焦段与配色词，并在 `refAssets` 绑定同一组 `asset/refs/` 角色/风格锚点图，避免相邻镜头画风突变。
- 相邻镜头注意运动方向一致（例如前镜向右推、后镜承接向右展开或用 `match-cut` 衔接同一几何形状）。

## 3. 交付前核对清单

- [ ] 全部 `shots[].id` 唯一且未破坏既有镜头编号；所有 `durationSec` 与旁白字数（或实测配音时长）匹配。
- [ ] `frameAsset`、`refAssets`、`audioAsset` 所列路径全部真实存在于 `asset/{frames,refs,audio}/`。
- [ ] 景别与运镜有起伏变化，首镜 3 秒内抓人，尾镜有明确记忆点或收束。
- [ ] 涉及修改 `status: "locked"` 镜头或用户手写台词的变更均经 `artifact_suggestion` 提议，未静默覆盖。
