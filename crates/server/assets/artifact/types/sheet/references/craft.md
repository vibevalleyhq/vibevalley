# 数据表格建模工艺与校验清单（sheet / craft）

## 1. 清晰的分层表结构

- **参数与假设独立成区或独立成表**：将增长率、汇率、单价等可调假设集中在 `assumptions` 表，下游测算表全部用公式引用，避免魔法数字散落在几十个公式里。
- **一列一义**：每列只承载单一字段与统一量纲（在列标题或 `format` 中标明单位，如 `万元`、`ms`、`%`）；禁止在同一列混写数字和「待定」文字。
- **善用首行/首列冻结**：超过 10 行或 6 列的工作表配置 `freeze: { rows: 1, cols: 1 }`，滚动核对时不丢上下文。

## 2. 防错与可审计性

- 所有除法公式包裹 `IFERROR(..., 0)` 或显式判零，杜绝 `#DIV/0!`、`#REF!`、`#VALUE!` 污染汇总行。
- 关键异常值或手动覆写项在单元格上添加 `note` 说明依据。
- 需要给非技术受众做趋势展示与下钻筛选时，可基于同一组数据另建 `dashboard` 作品呈现；`sheet` 聚焦于精确台账、建模试算与批量核对。

## 3. 交付前核对清单

- [ ] `structure/workbook.json` 列出的全部工作表文件均存在且 `id` 唯一。
- [ ] 所有汇总与衍生列均使用公式（`f`），零硬编码心算值，且无 `#REF!`/`#DIV/0!`/`#NAME?` 错误。
- [ ] 数值列全为原生 `number`，日期全为 `YYYY-MM-DD`，枚举列值全部命中 `options`。
- [ ] 原始外部导出文件完整留存在 `asset/*.csv`，修改用户手填单元格/公式均通过 `artifact_suggestion` 提议。
