# 运动节奏、镜头编排与交付清单（motion / choreography）

## 1. 动效节奏原则

- **快进慢收**：进场优先用 `outQuart` 或 `outBack`（`0.35s–0.55s`），镜头平移或景别切换用 `inOutCubic`（`0.5s–0.8s`），避免匀速 `linear` 产生僵硬感。
- **动作重叠（Overlap）**：主标题到位约 60% 时副标题或图标即开始入场（错落步长 `0.08s–0.14s`），杜绝「一个完全停稳才动下一个」的机械排队。
- **留足定格阅读时间**：每组核心信息完整显现后至少静止 `1.0s–1.8s`（带配音时以语音自然停顿为准）再切场。
- **单一视觉焦点**：同一时刻画面中只有 1 个主动运动的主体，其余元素保持静止或微弱呼吸。

## 2. 画面安全与音频平衡

- 1080p 画布四边保留至少 `96px` 安全留白；字幕居底居中，距底边 `72px–96px`，单行不超过 22 个汉字或 48 个英文字符。
- 含人声配音时，BGM `gain` 压低至 `0.18–0.28`，并在片尾留 `0.6s` 淡出。

## 3. 交付前核对清单

- [ ] 任意跳转时间点 `t` 与顺序播放渲染结果完全一致（无帧间累加状态）。
- [ ] `structure/timeline.json` 中各场景 `start`/`end` 连续无意外黑屏间隙，总时长与末尾场景对齐。
- [ ] 所有引用图片、音视频均存在于 `asset/{image,audio,video}/` 目录内。
- [ ] 对用户微调过的节奏或字幕文案均通过 `artifact_suggestion` 提议，未覆盖原参数。
