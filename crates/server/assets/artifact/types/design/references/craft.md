# 界面工艺与反套路准则（design / craft）

## 1. 先立气质，再排组件

- **拒绝千篇一律的紫粉渐变卡片墙**：开工前明确产品视觉气质（冷静工具台、温暖编辑出版、高密度专业控制台），用字重、字号对比与有意识的留白建立层级，而非给每块内容套厚重阴影和霓虹渐变。
- **网格与节奏统一**：全画板遵守同一基础间距网格（4px/8px 倍数），主操作区一眼可辨（每屏仅 1 个高强调主 CTA）。

## 2. 真实内容与全态覆盖

- 用贴合业务语境的真实人名、金额、状态与时间戳，严禁 `Lorem ipsum`、`Test 123` 或无意义占位图。
- 关键业务流程至少并排给出：**默认有数据态** + **空态 / 异常态** + **移动端窄屏适配**，让开发与评审直接看到边界表现。

## 3. 交付前核对清单

- [ ] `manifest.json` 中的 `frames` 与 `structure/frames/*.json` 一一对应，画板坐标互不重叠。
- [ ] 所有图片均存于 `asset/` 并使用相对路径，无外链地址。
- [ ] 已关联 `design-system` 时，核心色彩/字号/圆角走语义令牌引用，文字对比度满足 WCAG AA（≥ 4.5:1）。
- [ ] 对用户修改过的画板文案或主布局已通过 `artifact_suggestion` 提议，未静默覆盖。
