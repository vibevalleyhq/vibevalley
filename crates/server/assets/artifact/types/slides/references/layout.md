# 1920×1080 画布版式配方（slides / layout）

默认安全边距为上下 `96px`、左右 `128px`（`16:9` 净内容区 `1664×888`；`4:3` 净内容区 `1184×888`）。常见 `layout` 枚举与信息容量上限：

1. **`cover`（封面 / 分节章标题）**：左上眉标（`22px`）+ 主标题（`84px`，≤ 2 行）+ 副标题与日期署名（`34px`），底部留白 ≥ 25%。
2. **`kpi-grid`（三栏/四栏指标卡）**：3–4 张等宽指标卡，每卡大号数字（`72px`，`tabular-nums`）+ 1 行标签 + 1 行对比基准。
3. **`two-column`（双栏对照 45% / 55%）**：左栏现状/痛点，右栏目标架构/改进收益，每栏 ≤ 4 条短点。
4. **`split-visual`（左文右图 / 左图右文）**：文字栏 ≤ 3 条核心解释，视觉栏放 `asset/` 架构图、界面截图或原生 `chart`。
5. **`statement`（大字论断 / 金句收尾）**：居中或左对齐单一核心判断（`56px–68px`），下方附 1 行来源或下一步行动。
6. **`comparison-table`（紧凑对比表）**：最多 4 列 × 5 行，高亮推荐列，单元格控制在 8 字以内。
