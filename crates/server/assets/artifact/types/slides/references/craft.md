# 演示叙事与视觉克制（slides / craft）

## 1. 标题即结论

- 差标题：「第三季度销售数据」
- 好标题：「华东大客户续费率升至 94%，带动 Q3 净增翻倍」
- 观众只扫每页标题就能读懂完整逻辑链，无需依赖口头补全。

## 2. 拒绝廉价模板感

- 全套最多使用 1 个主品牌色加 1 个辅助语义色；大面积底色保持干净中性面（优先继承关联 `design-system` 的 `surface`/`ink`/`accent`）。
- 数字一律启用等宽对齐（`tabular-nums`），同比/环比标注明确基准与正负方向。
- 图表优先用结构化 `chart` 元素或干净的 `asset/*.svg`，直接标出关键拐点数值，省去冗余网格线与装饰性阴影。

## 3. 交付前核对清单

- [ ] 连续两页没有重复完全相同的版式（例如连续三页纯列表）。
- [ ] 每页正文不超过 5 条要点、总字数 ≤ 60 字（中文）或 ≤ 45 词（英文），无文本溢出风险。
- [ ] 每页均有精炼的 `notes` 演讲提词，与页面文字互补而非逐字复读。
- [ ] 所有引用配图均存在于 `asset/`，无外链图片与损坏路径。
- [ ] 修改用户原稿的措辞均走 `artifact_suggestion`，未静默覆盖。
