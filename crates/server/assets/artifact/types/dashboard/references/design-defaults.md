# 看板排版与视觉克制准则（dashboard / design-defaults）

## 1. 首屏信息层级

1. **顶部标题与全局筛选栏**：展示看板标题、数据更新时间（`updatedAt`）、全局筛选器与一键重置按钮。
2. **KPI 指标带（3–4 张卡）**：每张卡突出 1 个核心数字（等宽数字 `tabular-nums`）+ 明确的同比/环比基准（标注周期，如 `vs 上月`）。
3. **主视觉分析区（1–2 张核心图）**：主趋势图（折线/面积）+ 结构对比图（条形/堆叠），支持 hover 查看精确数值与源表字段。
4. **明细与排行表**：置底提供可排序明细表与 CSV 导出入口，支撑下钻核查。

## 2. 色彩与语义纪律

- 单张图表不超过 4 条序列色；若关联 `design-system` 自动复用其语义色盘，否则使用系统明暗自适应色阶（涨跌/好坏统一用正向绿与警示红，不混用装饰彩虹色）。
- 明确标注单位、量纲与截断轴提示（柱状图 Y 轴必须从 0 起步，禁止截断夸大差异）。
- 空态兜底：当筛选条件命中 0 行时，在图表与指标区显示「当前筛选条件下无记录」及重置按钮，绝不渲染 `NaN` 或 `Infinity`。

## 3. 交付前核对清单

- [ ] 每个 KPI 与图表序列均绑定到 `structure/data/*.json`，零硬编码心算值。
- [ ] 所有数据集的数值列均为原生 JSON `number`，无带逗号的字符串数字。
- [ ] 明暗双主题下图表网格线、图例与数字均具备清晰可读对比度。
- [ ] 涉及修改用户既有指标定义或筛选默认值的变更均通过 `artifact_suggestion` 提议。
