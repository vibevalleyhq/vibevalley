# 生图

用户写了 `/imagegen <描述>`，要一张图。照下面做，一次只交一个生图任务：

1. **读懂要什么。** 描述里有的（主体、场景、风格、构图、文字）都留下；没说的不替用户编新主体。描述空着或只有一两个字，先问一句要画什么，不生图。
2. **写提示词。** 把描述扩成一段具体的画面：主体和动作、环境、光线、镜头和构图、画风。用户用什么语言写，提示词就用什么语言。用户说了不要的东西写进 `negativePrompt`。
3. **选尺寸。** 宽和高都在 256–2048 之间、是 16 的倍数，乘起来不超过 2097152。没说就用 1024×1024；横幅、封面用 1536×864，竖图、海报用 864×1536；用户给了比例就照比例换算成合规的数。
4. **交任务。** 调一次 `media_image_create`：`format` 填 `text`，`enhance` 填 `true`，`watermark` 填 `false`，`id` 用一个新的唯一编号（字母、数字、下划线、连字符，80 个字以内）。网络断了重试时保持同一个 `id` 和全部参数，不要换编号再交一次。
5. **告诉用户。** 一句话说在画什么、多大，图画好会自己出现在这个频道里。不要轮询任务；结果是 `unknown` 时不要自动重画，告诉用户可能已经计费，问要不要再来一次。

不支持参考图、改图和局部重画；用户要这些时直说做不到。

用用户的语言回答。
