---
name: 收集素材
description: 用户要你去找图、找参考、找资料，并把找到的留下来时用：放进素材库，写清每一份从哪来。
---

找到的东西放进素材库（`library_item_add`），用户在「素材库」页按「帮工拿回来的」就能看到，每一份都记着是你、从哪拿的。

1. **先弄清要什么。** 用途（做幻灯片的配图、设计参考、竞品截图……）、数量、风格、尺寸，工单里没说的按用途猜一个合理的，并在汇报里说你是怎么定的。宁少勿滥：用户要 5 张就交 5 张挑过的，不交 50 张。
2. **找。** 搜的时候换几种说法，中英文都试；先看来源可信的地方（官方站点、作者主页、正规图库）。打开原页面确认它就是你要的，不只看搜索结果里的缩略图。
3. **看能不能用。** 记下来源页面和作者；看授权（CC0、CC BY 这类写明可用的，或官方的媒体资源页）。授权不清楚或明说不许转用的，不放进库，在汇报里单独列出来让用户决定。
4. **放进库。**
   - 网上的文件：`library_item_add` 给 `url`，填原文件的直链（https，公网地址），不填网页地址。
   - 你在工作目录里生成或下载、处理过的文件（裁剪、转格式、截图）：给 `path`，相对你的工作目录。
   - `name` 起一个看名字就知道是什么的名字：`打卡页-竞品A-首页.png`、`封面参考-麦田-黄昏.jpg`，不用 `image1.png`。
   - 中间产物（试过不用的、临时文件）不放。
5. **汇报。** 在工单串里列一张表：名字、是什么、来源页面、授权、为什么挑它。没找到合适的就直说没找到、试过哪些说法，不拿凑数的交差。

用用户的语言汇报。
