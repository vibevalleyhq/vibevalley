# 农场的皮

农场是页面（`apps/web/src/farm`，`/farm/<项目>`）从服务端折好的 `StateFrame` 画出来的一座像素小院，一个项目一座：从「项目」地图上岛的「进岛」进来，信号塔旁的项目牌写着是谁的，点牌子回地图；`/` 进这台设备上次进的那座（没记过时进最近有提交的那个项目的，一个项目都没有时是不属于哪个项目的那座），所以「回农场」总落在一座农场上。工单是地，帮工是地上的小动物，照手上的事走去书屋、工坊、电台，庄稼按这一轮的进度长；项目是地图上的岛，要你处理的事是左下角手机的来电。皮只读核心状态，自己只加跟着时钟走的东西（走动、姿势、光、院子的动静、音效），不存帮工的任何状态，也不决定能不能做一件事。

## 管什么，不管什么

| 管 | 不管（谁管） |
|---|---|
| 像素村：384×256 的格子、放大和裁边、LDtk 地图、寻路、光、院子的动静 | 地的样子（庄稼和牌子）怎么算：`apps/server/src/game/view.ts` 的 `plotOf`，[工单](docs/subsystems/issue.md)；金币、连胜、成就和账本（[游戏](docs/subsystems/game.md)） |
| 帮工走去哪、什么姿势、在哪块地上 | 帮工的阶段和在做什么（[帮工](docs/subsystems/session.md)） |
| 快捷栏的农具：点一块地做什么、用不上时说为什么 | 农具调的接口背后的规则（`issue.status.update`、`issue.comment.create`，[工单](docs/subsystems/issue.md)） |
| 地图：每个项目一座岛，地是它的 worktree 和空位 | 项目的上限、worktree（[项目](docs/subsystems/project.md)） |
| 农场手机：来电响铃、接听去哪、通话记录、小游戏 | 哪些事算来电、怎么说（Inbox，[通知](docs/subsystems/notice.md)） |
| 系统通知和菜单栏的说法（[客户端](docs/subsystems/app.md)「通知和菜单栏」） | 通知送到页面没开着的手机上（连接器，[田头](docs/subsystems/channel.md)） |
| 合成音效、图鉴 | 首页的生命周期（[客户端](docs/subsystems/app.md#怎么走)）和界面（[farm-ui.md](docs/reference/farm-ui.md)「界面清单」） |
| 素材怎么读进页面（`sprites.json`、密度） | 生图和切图的流水线：`design/`（[工程流程](docs/subsystems/process.md#怎么走)） |
| | 页面的目录和数据层（[客户端](docs/subsystems/app.md)、[农场的 README](apps/web/src/farm/README.md)）；每个界面的清单（[farm-ui.md](docs/reference/farm-ui.md)「界面清单」） |

## 在哪

谁画哪一块、store 的动作、画布怎么告诉 DOM 东西在哪，在 [农场的 README](apps/web/src/farm/README.md)。

- **像素村** `apps/web/src/farm/canvas/`（PixiJS）：`VillageCanvas.tsx` 挂画布，`scene.ts` 每帧把核心状态画成画面、按脚底的 y 排前后；`dog.ts`、`life.ts`、`fx.ts` 院子的动静和地上的效果。
- **世界** `apps/web/src/farm/world/`：`world.ts` 给位置起名、算帮工去哪（`Whereabouts`、`spotsFor`、`poseOf`、`placeOfAction`）；`level.ts` 读 `apps/web/public/village.ldtk`；`framing.ts` 放大和裁边（`frameVillage`）；`hits.ts` 点到了什么；`plots.ts` 地有哪几块（`beds`）和地上画什么；`sprites.ts` 读 `public/pixel/sprites.json`。
- **引擎** `packages/engine`：`nav`（寻路）、`pixi`（光、天色、法线、粒子、小虫、节奏）、`audio`（合成器和响度）、`clock.ts`（一天的钟）。
- **HUD 和面板** `farm/hud/`、`farm/panels/`：农场卡、额度、特效层，右上角的「记忆树」到 `/tree`（`src/tree`，[记忆树](.agents/notes/proposed/feature/2026-10-22-memory-tree.md)）；收获、播种袋（`SeedForms.tsx`）、成就、仓库、计划板、菜单。
- **农具和去处**：`farm/tools.ts` 的 `Tool`、`aimTool`（指着一块地时说点下去做什么）、`toolForKey`；`farm/commands.ts` 把点击变成接口调用；`farm/world/places.ts` 的 `yardPlaces` 是院子里每样东西打开哪个面板或页面。
- **音效** `ui/pixel/sound.ts`：配方（`SOUNDS`）和分组（`SOUND_GROUPS`），几张皮共用；农场什么时候响在 `farm/cues.ts`（`farmCues` 比前后两刻，`support.ts` 的 `farmSounds` 照它响）；合成在 `packages/engine/src/audio`。指针在 `apps/web/public/cursors/`，字体 Fusion Pixel 12px 在 `public/fonts/`。
- **手机** `farm/phone/`：`Phone.tsx` 机身，`calls.ts` 来电和记录，`screens.tsx` 主屏；小游戏的规则是纯函数（`games/blocks.ts`、`dino.ts`、`sokoban.ts`、`bugSnake.ts`、`merge.ts`），画面是 `*Game.tsx`。
- **通知** `apps/web/src/features/notice/tray.ts`（`noticeFor`、`CallBell`、`traySummary`），由 `src/features/notice/Follow.tsx` 交给宿主。
- **地图** `apps/web/src/features/project/rules.ts`（纯函数，`islandsOf`、`islandLooks`）、`features/project/ProjectMap.tsx`；挂在工作台「项目」页（`/projects` 的「全部」，选一个项目是它的岛）。
- **图鉴** `apps/web/src/features/catalog/`（`/catalog`）：规则在 `features/catalog/rules.ts` 的 `shelves`、`framesOf`、`remakeOf`。

服务端这边只有两样给皮的东西：`StateFrame.view`（`FarmView`，`viewOf`）和 `StateFrame.inbox`（`inbox`）；地图另读项目列表里的 `ProjectSummary.maxSessions`。

## 模型和不变量

- **皮里没有第二份状态。** 地、帮工、来电都从这一帧的 `StateFrame` 读；页面自己记的只有画面和这次打开的东西：小动物走到哪、`Whereabouts`、接过哪个来电、小游戏的棋盘。重开页面这些都从头来。
- **一个项目一座农场。** 地号（`play.station`）在项目里各算各的（`farmOf`、`freeStation`：没有项目的帮工算一座），两个项目的第一个帮工都在各自的第 1 块地；全农场同时干活的上限（`maxRunning`、`noRoom`）不变。页面只把这个项目的帮工交给画地的部分：`farmFrameOf`（`farm/scope.ts`）过滤原始帧，`createFarmFrames` 过滤 store，画布、地上的牌子、特效、音效、帮工栏、面板和农场的命令读它；田头、首页、来电、等级读全农场的。
- **一块地是一张工单。** 帮工的地按它的 id 查 `FarmView.plots`，地的样子由服务端照它的工单算好。它画在哪块地上看帮工的 `play.station`（0–5）；`beds` 有 9 块：6 块是同时在做的 6 张工单（`maxRunning`），另 3 块在 Lv.5、8、12 开垦成花坛，只是外观。没开垦的画成锁住的地。
- **庄稼和牌子是服务端算好的，是工单站位的一张图**（`game/view.ts` 的 `plotOf`）：卡没卡、要不要主人只由工单的 `attention` 定（[工单](docs/subsystems/issue.md)「给主人看的状态」），地块不再从帮工的阶段、问题、意见另推一遍，所以地上说的和工单页说的是同一件事。帮工只补「这一轮长到哪」：

| 工单站在 | 庄稼（`Crop`） | 牌子 |
|---|---|---|
| 在做（帮工刚到场） | 刚播种 `seeded` | |
| 在做 | 这一轮还没改文件是发芽 `sprout`，改过文件是长叶 `leafy`，改过文件后跑了命令是开花 `flowering` | 模型调用在重试时「重试中」 |
| 在做，修验收没过的意见 | 杂草 `weeds` | 除草中 N |
| 等你回答 | 干裂 `dry` | 等你回答 |
| 等你验收 | 开花 `flowering`；验收过了是麦子或胡萝卜（按帮工 id 固定一种） | 等你验收；验收过了是「可收获」；计划里的一步不挂牌子（在计划里操作） |
| 卡住了：有冲突 | 枯萎 `withered` | 有冲突 |
| 卡住了：没做成（结论工单读不出结论也是） | 枯萎 `withered` | 有虫 |
| 卡住了：停在半路 | 停在当时的样子 | 停在半路 |
| 卡住了：没动静 | 干裂 `dry` | 没动静 |

  没挂工单的帮工（起草、规划计划的）照它自己的阶段画（`plotOfSession`）。牌子上卡住的原因是词表 `stuck` 的词；「有虫」「可收获」「除草中」是皮自己的说法。声音也跟着站位：工单进了等你验收响「熟了」，卡在有冲突或没做成响「有虫」（`farm/cues.ts` 的 `farmCues` 读 `Issue.attention`）。帮工离开后，那块地在页面上画 3.6 秒麦茬（`harvested`），然后是空地；这是画面，不在 `FarmView` 里。

- **帮工去哪是一条规则**（`world/world.ts`），画面只管坐标：
  - 手上的事决定去处（`placeOfAction`）：读、搜去书屋，跑命令和 MCP 去工坊，查网页去电台，等着坐长椅，改文件和别的在自己的地边。
  - 换去处要节流（`Whereabouts`）：想去新地方够 1.2 秒、在原地待够 2 秒才动身；地熟了、枯萎、干裂（`plotCalls`）时马上回到地前面、面朝外。
  - 在地边时隔一阵换个位置（`spotsFor`、`Stroll`）：干活时每 5–11 秒，别的时候 7–15 秒；改文件、跑命令时进地里，歇着时可能去草坪；同一个地点人多了往两边排开。
  - 姿势（`poseOf`）：熟了「欢呼」，枯萎或干裂「发愁」，改文件、跑命令、MCP 是「干活」，读、搜这些是「琢磨」，没在做事是站着。
  - 地都占满时（`station` 为 -1）帮工在院门外排队；不在场的从大门进来。
- **世界坐标只有一套：384×256 个像素格。** 素材画成两倍密，`ui/pixel/atlas.ts` 用地图图片的宽除以 384 得出密度，把 `sprites.json` 里的宽高和落脚点都除以它；关卡、点击区、HUD 的坐标都按格子写，不随密度改。
- **放大只用整数倍**（`frameVillage`）：从能盖满窗口的倍数往下找，第一个满足「左右每边裁掉不超过村子宽度的 5%（`villageCutAcross`），上下每边不超过高度的 8%（`villageCutDown`）」的就用。1152×768 正好放下，所以桌面窗口默认是这么大、拖动时保持 3:2（[客户端](docs/subsystems/app.md)）；1440×900 放大 4 倍、左右各裁 48、上下各裁 62 屏幕像素；1920×1080 放大 5 倍、只裁上下；竖着的手机放大 1 倍。盖不满的地方留边，边上垫一张放大、压暗的农场。最外一圈至多左右各 19 格、上下各 20 格可能看不到，能点的东西应放在这圈里面。
- **HUD 和字是盖在画布上的 DOM**（`farm/hud/`），任何缩放下都清楚，贴着农场在窗口里露出来的那一块的边；字号只用 12 和 24。
- **指针跟着农具和指向处变**（`canvas/VillageCanvas.tsx`）：指着道具、农具能用或不能用、按下时各选一张 CSS 指针；`public/cursors/cursors.json` 的 `hx`、`hy` 是热点，不是精灵的落脚点。
- **地图数据在 LDtk**：Ground 层标能走的地方；Things 层是地块、帮工去的地点（`Place`）、道具、灯、大门、排队处、管家和狗。地块和道具的底由游戏从 Ground 里扣掉（`walkable`），因为它们会动。
- **寻路**（`packages/engine/src/nav`）：能走的地方铺成格子（像素村用 2 格一个），靠近障碍的格子贵一点，所以帮工走在过道中间；不从两个挡住的格子之间斜着挤过去；找到的路把能直走、不更贵的拐角拉直。到不了就直走过去。
- **光是页面算的**：法线贴图在加载时从画里生成，不另画夜景；天光随钟点变（约 06:00 日出、19:00 日落），天黑后窗户、路灯、提灯是点光源；镜头前的一层植物往鼠标那边偏几个像素，院子本身不动。
- **院子的动静和效果只在页面**：炊烟、蝴蝶、池塘、狗（拍它会醒、会玩把戏）、浇水和收获的闪光、金币，都从状态画出来，不进核心状态。
- **院子里的东西是入口**（`yardPlaces`）：小摊是商店，箱子堆是仓库，告示板是任务与成就，邮筒是日志，图纸桌是种植计划，帮工名册、工坊（农具）、书屋（技能书）去工作台对应的页，点院子里的管家是跟它说话（拿出手机、展开到田头）；换管家的样子是左上角管家的头像。
- **音效现合成，没有音频文件**：每个是 `sound.ts` 里的一个配方，`packages/engine/src/audio` 合成成样本再播。按人耳加权的响度（K 计权，取最响的 100 毫秒）分三档：点击约 -28，干活和状态变化约 -24，奖励约 -20，都压在说话声以下；改了配方要重新量（调试台的「音效」页）。
- **音效从状态里响，不从点击里响**（`useFarmSounds`）：换工具、地上的效果、面板开关、语音接通和挂断、帮工到场、长虫、服务端推来的 `GameEffect`，不管是谁让它变的都响。
- **来电号稳定**：来电是服务端的 Inbox，号带帮工的轮次（同一轮同一个号，下一轮又熟了是新号）；页面按号记接过、挂过的，只响一次。
- **来电的规矩**（`phone/calls.ts`）：农场画面打开时已有的来电算未接、不响；新来电弹出手机、响铃（合成的 `ring`），20 秒（`ringFor`）没理算未接；接听就是给管家打电话（`voiceCall.start`，管家先说这件事，[语音](docs/subsystems/voice.md)「管家打电话找主人」），同时去处理（帮工的打开它的地，计划的打开计划板，@ 你的打开那个对话），挂断是先放着；那件事在别处处理掉、从 Inbox 里消失，来电自己停。通话中不响铃，记成未接：管家在电话里说。接没接过、通话记录只在这次打开里。
- **田头在手机里，手机像折叠屏**（`phone/Phone.tsx`）：收着是原来的手机，右边沿一个「田头」的签（有新话时带红点，手机键上也写「新」）；展开是同一部手机、同一块屏，左半是手机的主屏，右半是田头（`chat/ChatWindow.tsx`），中间一条缝，状态栏横贯整块屏；窄屏上展开只露田头。机身上没有按键：十字键和 A、B 只在小游戏里出来，状态栏的「农场通」回主屏（小游戏里先回「游戏」文件夹）。小游戏收在主屏的「游戏」里。点主屏的「管家」就是打给管家：左边是通话屏，同时展开到田头（已经在通话就不再拨）；一通电话开始（通话键、接来电、桌面的快捷键）也拿出手机展开，电话里两边说的话说着就上屏（实时字幕，[语音](docs/subsystems/voice.md)「字幕」），说完写进田头；通话中收起就不再自己展开。Esc 先收起，再收手机；收了手机下次拿出来是收着的。点工单串、`farm.showChat` 拿出手机并展开。曾经田头是右下角单独的小窗：和手机各占一角，手机的「管家」通话屏和田头的通话键是同一通电话却在两处。
- **刚发的话马上上屏**（`features/channel/composing.ts` 的 `pending`）：发出去就清空输入框，话淡着显示「发送中」，频道里来了带同一把 `sendKey` 的那条就换成它；发送失败把话放回输入框。
- **打电话是手机的事**：田头没有通话键，输入行左边也不再有管家的头像（它是旧的小窗用来收起的）；手机的「管家」一屏就是这通电话（打给管家、通话中、挂断、没接通的原因），田头头上写管家在听、在想，没接通的原因和「去设置」在田头头下，都读同一个 `voiceCall`。
- **小游戏的规则是纯函数**：一局是一个值，每一步是值到值，带种子的随机，能重放；画面只跑动画帧、接十字键和 A、B、画在 canvas 上。最好成绩只在这次打开里；推箱子的棋盘放在农场的 store 里，收起手机、来电都不丢，5 个固定关卡，能逐步撤销、重开本关。小游戏不进账本、不给金币。
- **通知和来电用同一套规则**：都从帧里的 `inbox` 读，话是来电自带的 `words`，同一个来电只响一次（`freshOf`）；窗口在前面时不弹系统通知。页面没开着时什么都收不到，那时靠连接器把话送到微信、飞书或 QQ。
- **地图上的地 = 在做的工单 + 空位**（`features/project/rules.ts` 的 `islandsOf`）：项目里的每个帮工一块（不管在干、熟了还是歇着），按来的先后排；后面是空位，个数是项目的上限减去在干活的，也不超过农场还空着的地；被农场的地挡住的画成锁住的地。一座岛最多 6 块。上限来自 `ProjectSummary.maxSessions`（`project.max_sessions`，默认 3；没设或超过 6 时是 6）；空位和服务端拒绝开工（`noRoom`）用的是同一条规则 `roomLeft`（`packages/protocol/src/rules/phase.ts`），不各算一份。排上队的待办（`queuedAt`）按先后是院门外的种子袋。不在项目列表里的项目只画它的帮工、不再给空位。岛下面的名牌写着「进岛」并带箭头，点它或岛进这个项目的岛视图。
- **每块地写着项目**：几个项目的地混在一个农场里，有帮工的地在牌子那一栏写它的项目名；有牌子（等你验收、等你回答……）时项目名在牌子下面一行。
- **岛是整张的画**：六种样子（`islandLooks`），项目用哪座由名字定；每座中间留一块空院子，`process.py` 找出院子、把岛缩到院子 150 格宽，院子的位置写进 `sprites.json` 的 `yard`，页面按它摆地。
- **图鉴只读已打包的东西**：图来自 `sprites.json`，指针来自 `cursors.json`，音效来自 `sound.ts` 的配方；没有自己的清单，切了新图就出现。分类按名字前缀（`shelves`），帧按编号认（`framesOf`），重画和重切的命令按清单里的 `sheet`（切自哪张原图）给出（`remakeOf`）；改了命名前缀要同时改 `shelves`，否则新图落进「其他」。

## 怎么走

**一帧**：服务端经 SSE 推来 `StateFrame` → 每块 `bed` 找 `station` 对上的帮工，按它的 id 查 `view.plots` 换成 `plot-<庄稼>` 的图 → 每个帮工算庄稼、姿势、去处（`Whereabouts`），给出目标点，沿寻路的路一段段走 → 按脚底的 y 排前后，打光，画 HUD 和牌子。帮工从帧里消失后，它的小动物从大门走掉。

**一次点击**（`world/hits.ts` 定点到了什么：帮工压过狗，狗压过道具，道具压过地）：

| 农具（数字键 1–6） | 点一块地 |
|---|---|
| 手 | 空地播种（见下「播种袋」）；有帮工的看工单详情：和工作台的工单页说同一套状态、同一个主动作（[farm-ui.md](docs/reference/farm-ui.md) 第 2 项） |
| 浇水 | 工单允许 `tell` 时给帮工带句话 |
| 杀虫 | 工单允许 `cure` 时让它接着修 |
| 除草 | 只有提示，点下去不做事 |
| 收获 | 工单允许完成（`complete`）时打开收成清单（改动），确认后完成 |
| 铲除 | 工单允许 `stop` 时叫停这一轮，否则允许 `close` 时请它收工 |

农具、收成清单和工单详情只用最新帧里的 `Issue.attention.acts` 判断能做什么，统一发 `issue.act`。庄稼、帮工阶段和计划归属只用于画面，不再决定动作。收成清单开着时，工单不再允许收获就撤下确认键；冲突清单只展示改动，是否提供「让它解决冲突」也读工单动作。

**播种袋**（`farm/panels/SeedForms.tsx`：农场点空地打开，地图点一座岛的空位也打开它）：

1. **种在这座农场的项目**：写着「种在 <项目>」和它的栈（Go、Node（bun）……），袋子里不选项目。不属于哪个项目的那座农场里，袋子说先进一个项目的农场，按钮去「项目」地图（一个项目也没有时去开一个）。
2. **挑种子**：问服务端 `project.template.list`，页面不带种子的副本，只画它给的。从上到下是「最近」（这个项目里派出去过的工单标题，新的在前、不重复、最多 5 条），「常见的活」（按类分：修问题、测试、新功能、整理、依赖、文档、检查、发版，每类一个页签、一个庄稼图标，一次只摊开一类），「自己写」的文本框，和「谁来种」。选一颗常见的活，文本框里是它的标题和一行「做到什么程度算完」，光标选中第一个〔…〕空，填上就能种；那一行里的命令照项目的栈写好（`go test ./...`、`bun run test`……），认不出栈就写「测试」「构建」这类泛称。 读取失败时显示原因和「重新拿种子袋」，服务恢复后可以在原袋子里重试，已写的工单文字保留。

播种是经田头发一条消息（`channel.message.send`）：选的或写的那段话原样发，带档案和项目，农场的还带地号（岛上没有农场的地，不带，服务端照常挑一块），管家照着派活。「开始」就是播种；「草稿」不播种：这段话成为这个项目的一张备选工单（`writeIssue`：`issue.create` 再 `issue.draft`，选了谁来种就是它的帮工），袋子关上，打开它的详情（[工单](docs/subsystems/issue.md#怎么走)「起草」）。

指着一块地时 `aimTool` 写出点下去做什么，用不上就写原因、什么都不发；点击保留指向时的农具（`PlotAim`），执行前再读最新工单动作，地上的帮工换了就拒绝这次点击。Esc 放下工具，手上已经是手时打开菜单。

**来电**：Inbox 里出现新号 → 手机弹出、响铃，系统通知同时按来电的 `words` 发（窗口不在前面时）→ 接听经来电的 `target` 打开地、计划板或对话；20 秒没理进未接。

## 和谁打交道

- **核心状态**：读 `StateFrame`（形状在 `packages/protocol`）的 `state`、`view`、`inbox`、`effects`；地的样子是 `plotOf`（`game/view.ts`），来电是 `inbox`（`notice/inbox.ts`），皮不重写这两条规则。
- **工单、帮工**：农具按工单允许的动作调用 `issue.act`；播种是经田头发一条带档案和项目（农场的还带地号）的消息。
- **种子**：播种袋读 `project.template.list`（`issue` 服务从工单里读出「最近」，`project` 服务看项目根目录认栈，工单模板的目录在 `apps/server/src/agent/template_catalog.json`），页面不带副本（理由见下「种子的目录和填法在服务端」）。
- **项目**：地图读项目列表里的 `maxSessions`，项目页每 30 秒问一次；工单和帮工跟着核心状态来。
- **游戏**：金币、升级、成就到了一档是服务端推来的 `GameEffect`，皮只画效果、响声音、弹通知。
- **素材流水线（`design/`）**：生图 `design/pixel/gen.sh`，切图 `design/pixel/process.py` 写出 `apps/web/public/pixel/` 和 `sprites.json`（不手改）；原图在 vibevalley-art，`design/art.sh` 链接进来。操作命令见[开发](docs/development.md#素材音效和官网)。

## 为什么这样

- **画成农场，不是工地。** 第一版是 three.js 的伪 3D 工地，机器人不好区分，隐喻只有「干活」，装不下「做完了等你收」「出问题了要你处理」；农场有成熟、虫子、干裂、杂草、收获，正好对上这些状态。画风选了型号 B「温室花园」：型号 A（经典农场）颜色和按钮太吵，不适合长时间开着；型号 C（夜间科技温室）暗、字和状态不好认，夜里的样子改成了昼夜变化；型号 D（竖屏）留作手机版。工地版的代码删了，不留存档：没人构建的代码在哪都会悄悄坏掉，git 历史就是存档。
- **像素村，不是贴在背景上的高清精灵。** 风来之国那样的像素画里，小人在有细节、有光影的地图上走，走路本身就说明在干什么；高清精灵缩放后像素对不齐，场景也只有种菜。院子扩成书屋、工坊、电台、长椅，帮工照手上的事走过去，入口放进院子里，院子才不只是种菜的地。
- **渲染层只管画，状态在服务端。** 选 PixiJS 这样只管画的层，点击和循环由页面自己管；放弃了自带场景和状态管理的完整游戏框架（Phaser 这类），和 Godot、Bevy 这类引擎：它们会在框架里再养一份帮工的状态，违背「核心状态只有一份」，而我们重度依赖的文字界面、中文输入是引擎的弱项。每秒 60 次的东西（走到哪、动画帧、灯光闪烁）是渲染层的普通对象，不进核心状态。
- **镜头不晃，只有前景偏一点。** 让整个镜头跟着鼠标晃视差最足，但画面是用来看帮工干活的，底下的地在晃让人不踏实。
- **一个项目一座农场，不是全农场共用一块地。** 主人先在地图上挑一座岛再进去，之后就专注在这个项目：共用的地里混着别的项目的帮工，播种还得问项目。放弃了只把播种默认成当前项目、地照旧共用（「专注」只落在牌子上）；也没把「现在看哪座农场」放进服务端：它是这台设备在看什么，不是农场的事实，几台设备可以各看各的。
- **地图放在 LDtk，不在代码里描矩形。** LDtk 的实体带字段（这个道具开哪个面板），IntGrid 正好是「能不能走」，比 Tiled 更合适；换布局在 LDtk 里改，打开就能核对能走的地方。
- _*格子 A* 而不是手摆路点。_* 手摆路点每换一次布局要全部重连；直线走只绕开地块中心，仍会擦着木框和花丛走。
- **素材密一倍，逻辑坐标不动。** 坐标全部乘 2（768×512）要改关卡、路径、点击区、HUD 和动画偏移，改一处漏一处；按密度加载让逻辑一行不动。密度不设开关，由图本身算出来，游戏里不会新旧密度混着。只密 1.5 倍在非 Retina 屏上也是整数倍，但细节涨得少；代价是非 Retina 外接屏上一个新像素是 1.5 个物理像素，粗细会有一点不匀。一类图整张交给 codex 重画，不一张张画：同一个角色的帧一次画完才一致。
- **只有一套像素画面，没有皮肤开关。** 手绘的旧版农场留着时，每加一样东西都要想两边，没人维护的那边会悄悄坏掉；只有一个取值的开关只会让人以为还有别的。`design/assets/` 只留重画界面图要用的手绘原图（`gen.sh` 的 `ui-*`、`look-*` 照它们重画）。
- **整数倍放大，裁一点边。** 非整数倍会一行宽一行窄、走动时闪；把地图往外多画一圈最自然，但要重新生图、改关卡；只把边填成压暗的农场，边还是那么宽。上下 8%、左右 5% 是因为那几行只有崖壁、树梢和篱笆，左右 5% 正好保住左边的井和铁塔。
- **音效现合成，从状态里响。** 录音或买音效包要管文件、授权和格式，响度还要逐个调；在点击处理里放声音，帮工自己做完、服务端推来的变化就没有声音，同一件事在不同入口响法不一样。代价是声音偏简单。
- **种子的目录和填法在服务端。** 目录放进页面，连进来的设备和服务端版本对不上时种子就对不上；认栈要读项目目录，页面读不到，填命令的规则又得在页面里写一份，所以服务端一次给填好的。「最近」从库里读，不用核心状态里的工单：核心状态只有开着的和最近关的 50 张，派得多的项目「最近」会是空的。「做到什么程度算完」是话里的一行，不是工单的单独字段：播种走的是田头的一句话，加字段要改 `say`、管家的工具和工单的表。开工排着队的待办单开 `issue.dispatch`：它已经是 `todo`，挪状态说不出「现在有空就开」。代价是每次打开播种袋多一次请求；栈只看根目录，前后端放在子目录里的仓库认成根目录那一种，命令落回泛称。
- **来电不存，现算。** 服务端推「来电」事件要新的事实、要存，而这些事核心状态里都有；接没接过只属于这台设备的这次打开，不另加一个存储。来电不自动接管画面，在角落弹出、20 秒收起成未接，打扰最小。
- **通知只在页面开着时弹，规则在页面。** 系统推送（APNs、FCM）是页面关着、不在局域网时唯一的路，但 APNs 要苹果开发者账号和证书，FCM 在国内多数安卓手机上收不到、要一家家接厂商推送；页面关着时靠微信、飞书连接器。等要做系统推送时，「该通知谁」才搬到服务端。
- **推箱子是固定关卡。** 随机摆箱子容易无解；固定关卡能控制教学顺序，可解性用搜索测。小游戏不给金币：计分只奖真实收进主分支的活。
- **地图的空位照服务端的上限算，上限不进核心状态。** 页面写死每个项目 3 个空位，改了配置地图就说错、点进去派不出去；上限是启动时读的配置，不随事实变，放进 `FarmView` 要改折法和黄金数据，只换来少读一次项目列表。也没让歇着的帮工按上限占位：歇着的不占上限，那样画空位会比服务端说的少。没画成一整张有路相连的大地图（项目数不定、手机上要缩），也没在农场画面里按项目分区（农场是固定的 9 块地）；岛是整张画留空院子，因为生图拼不出无缝的小块。
- **图鉴读清单，不另写对照表。** 页面里写前缀到原图的表要和切图脚本保持一致；清单里记 `sheet`，切图时顺手写上，不会对不上。原图不打包进应用，只给路径。不放进调试台：那是窄面板，装不下几百张图。
