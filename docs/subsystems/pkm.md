# 笔记

笔记（PKM）是主人自己的知识库：一个文件夹里的 Logseq 式大纲页面，按 PARA 分在几个文件夹里，在工作台的「笔记」页（`/pkm`）里看和写。文件是真相，服务端读进来、改完写回去，主人同时用别的编辑器改也行。

## 管什么，不管什么

| 管 | 不管（谁管） |
|---|---|
| 笔记库的文件夹、页面文件读成大纲、大纲写回文件 | 帮工和管家交上来的稿子（[稿子](docs/subsystems/artifact.md)） |
| 块的操作（插、改、缩进、挪、标记）、找页面、搜、反链、块引用读出来 | 帮工的档案的记性（[记性](docs/subsystems/memory.md)）；搜索只借它的切词 |
| 闪念记进今天的日记、剪藏、聚类、改名和合并、导出、撤销 | 帮工和管家的笔记工具：找、读、记一句、提改写；管家看到在做的项目、主人的话召回相关的块 |
| 主人在文件里写的批注，和对一块提的改写（接受、拒绝） | |

## 在哪

- 服务端 `apps/server/src/pkm`（服务 `Pkm`），归 Collaboration，排在 `artifact` 后面：
  - `pkm.ts`：服务本身：读文件、写文件、一把锁、批注和撤销的表。
  - `outline.ts`：文件和大纲互相转换（纯函数）：`parse`、`print`、块的边（`[[页]]`、`#标签`、`((块))`、属性里的 `[[页]]`；`#标签` 和页面同一条规则 `pkmTag`：`#` 前面不是拉丁字母、数字或 `_ / & #` 就算，所以 `读了#读书` 是标签，`C#`、`issue#12` 不是）、别的编辑器改过以后接回块 id（`carryIds`）。
  - `ops.ts`：块的操作，用两边共用的规则（`packages/protocol/src/rules/pkm.ts` 的 `applyBlockOps`、`flatBlocks`，页面先在本地施加同一份）；`graph.ts`：几页合起来的查询（纯函数）：找页、块引用、反链、搜索、回顾雷达、导出、改名时改链接、改写时留住链接，给命中和路径去掉记号的 `plainOf`；`para.ts`：PARA 的文件夹、文件名和日记的日子（`journalDay`）。
- 笔记库在 `$VIBEVALLEY_HOME/pkm/`，配置 `pkm.root` 可以换成别的文件夹（[设置和配置](docs/subsystems/setting.md#模型和不变量)）：`00_Inbox`、`01_Projects`、`02_Areas`、`03_Resources`、`04_Archives`、`journals`，剪藏的原文在 `.pkm/snapshots/`。
- 表：`pkm_comment`（批注和改写：哪页哪块、谁、状态、提的字、理由）、`pkm_change`（每次改动写的那个文件：改之前和之后的字，撤销用）、`pkm_term`（FTS5 的全文索引：每一块的词）。
- 形状在 `packages/protocol/src/pkm/shapes.ts` 的 `Pkm*`；块的操作是封闭的联合 `PkmBlockOp`（按 `op` 区分）。接口 `pkm.*`（[capabilities.md](docs/reference/capabilities.md)），命令行是 `vibevalley pkm capture|show|list|edit|radar`，搜笔记用顶层的 `vibevalley search`（[开发](docs/development.md#只用命令行派一个活)）。
- 页面 `apps/web/src/features/pkm`：`PkmPage.tsx` 摆左中右三栏：左边侧栏，中间日记流或一页，右边旁注；`Sidebar.tsx` 搜索、今天、雷达、按 PARA 的页（悬挂缩进：图标和组名在第一列，所有页名在第二列；雷达的收件箱、搁着、过期只在有东西时出一行，过期的数是莓色；组名不带页数，折叠的箭头只在指着或折着时出现）；`Calendar.tsx` 右边最上面的月历，能折起来（记在本机）；`PageView.tsx` 一页的正文一栏和旁注（月历、评论、反链、这页的大纲）；`OutlineView.tsx` 写大纲的地方；`writer.ts` 本地先改、一批一批交给服务端（`PageWriter`）；`editing.ts` 每个键、粘贴、补全做什么（纯函数）；`days.ts` 日记的标题、截止还剩几天、月历；`Search.tsx` 搜笔记的对话框（外壳的 Ctrl+K 也开它）。

## 模型和不变量

- **页面就是文件**：一个 `.md` 一页，它在哪个 PARA 文件夹就是哪一层；标题是 `title::`，没有就是文件名（`__` 读成 `/`）。页面的属性是文件开头的 `key:: value` 行。
- **块**：每个 `- ` 是一块（只剩 `-` 的一行是空块：别的编辑器会去掉行尾的空格），缩进两个空格一层，`TODO`、`DOING`、`DONE`、`NOW`、`LATER`、`WAITING`、`CANCELED` 和 `[#A]` 这类优先级写在开头；块下面紧跟的 `key:: value` 是块的属性，`id::` 是它的 id。块里的代码围栏原样是字，里面的 `- `、`[[ ]]`、`key::` 都不算。
- **读写不变**：服务端写出的文件读进来再写，一个字节都不变：属性按固定顺序，两个空格缩进，行尾没有空格。
- **id 只在需要时写进文件**：文件里本来有的、别的块用 `((id))` 引用的、有批注或改写的块写 `id::`，别的不写。新加一个指向某块的引用时，那块所在的页面跟着写出它的 `id::`，下次从文件读进来，引用仍然找得到。
- **块 id 编辑之后不变**：服务端改完写回的页面不再从文件重读。别的编辑器改了文件、重读时，没写 `id::` 的块按「同一层、同样的标记和字」接回原来的 id，对不上的按位置生成。
- **文件改了才重读**：一页被读到时比对文件的修改时间，变了就重读，字一样只记下新时间。列表、回顾雷达会先把整个库扫一遍。服务端开机后第一次被问到笔记时才把整个库读进内存。
- **一把锁**：所有会读文件或写文件的操作一个一个来；一页读出来、改完、整页写回。写文件先写临时文件再改名。
- **批注的状态在库里**：主人在文件里写的 `==那几个字==^[批注]` 和块属性 `comment::` 按块和序号记进 `pkm_comment`，状态比文件多活一次读写。改写（`pkm.comment.suggest`）必须留住原来那块里所有的 `[[链接]]` 和 `((引用))`，提上来的字里少了的补在末尾。接受以后那块换成提的字，批注标记和 `comment::` 去掉，这块上没答的批注一起算答过；拒绝只改状态。
- **撤销**：每次改动记下写的那个文件改之前和之后的字，撤销把最新一条放回去（新建的文件就删掉）；只留最近 200 条。只为写 `id::` 而写的不算改动。

## 怎么走

**闪念**（`pkm.capture`）：字照大纲读（`outline.ts` 的 `outlineOf`：一行一块，开头的 `- ` 去掉，按缩进挂到上一行下面，块的 id 都是新的）。不给 `page` 时记进今天的日记（`journals/2026_11_03.md`）末尾，每个顶层块是 `LATER …`，没带 `#inbox` 的加上；没有今天的日记就新建一页。给了 `page` 就原样接在那一页末尾。页名找不到时，说最像的几页。

**改一整页的原文**（`pkm.source.get`、`pkm.source.update`，命令行的 `pkm edit`）：读出页面文件的原文（带 `id::`）和它上次写的时间；写回时这期间文件被改过就拒绝，没改过就照原文重写这一页（一次撤销）。

**日记**（`pkm.journal.open`）：那天（`YYYY-MM-DD`）的日记，没有就建一页、里面一块空的可以写。页面列表里的日记带 `day`（从文件名读），页面不解析标题；日记的标题照主人的语言写（「11月3日周二」），文件名照 Logseq。

**在页面上写**：键先在本地改（`PageWriter`，和服务端同一份施加规则），光标马上过去；操作排队，一次一批交 `pkm.block.apply`，回来的页替换本地的、还在排的再施加一遍；被拒绝就丢掉排着的、退回服务端的那份，说没存上。正在写的那块不按时重读。键：回车在光标处拆成两块（行首是在上面加一块空的，打开的父块是加在第一个子块），Shift+回车换行，Tab 和 Shift+Tab 缩进，Alt+↑↓ 挪，⌘回车换标记，↑↓ 在第一行和最后一行时走到上下一块，退格在行首删掉空块、把有字的并进上一块（有子块的不动），⌘Z 是服务端的撤销；多行粘贴按缩进拆成块；`[[`、`#` 补页面，`((` 搜块，行首 `/` 出命令（标记、标题、链到今天的日记）；中文输入法打的 `【【`、`】】`、`（（`、`））`、行首的 `、` 和 `＃` 当场换成这些记号（`base/typedMarks.ts`，单个 `【` 是中文的标点，不换），不用切到英文；候选也照拼音找（全拼、首字母或混着，`#ds` 找到「读书」，`base/search.ts` 的 `spelled`）。手机上编辑时下面一条工具条代替这些键。大纲的末尾是淡淡的下一行（一个淡的圆点和「接着写…」），指着大纲时才出现（触屏和空页上一直在），点它在最后写：最后一块还空着就回到它，不另起一块。

**帮工和管家用笔记**（`apps/server/src/tool/pkm.ts`）：两边都有 `pkm_search`、`pkm_page_get`（每块一行，带 id 和层级，最多 300 块）、`pkm_capture`（记进今天的日记，LATER #inbox，后面写着谁记的）、`pkm_comment_suggest`（提改写，主人在笔记页接受了才换）；agent 从不直接改一块。管家每次看到的现状里，项目文件夹下面多一段「主人笔记里在做的项目」（项目那一层的页，最多 8 页：标题、一句话、几件没做完）；主人说的话（只有主人的）先拿去找笔记，最多 3 块放在这一轮的输入里「笔记里可能相关的」。

**一次选几块**（`features/pkm/selection.ts`）：Esc 离开一块时选中它，在第一个字前 Shift+↑、在最后一个字后 Shift+↓ 离开并接着往上下选；选中时 Shift+↑↓ 扩大，↑↓ 换成上下一块，Shift+点另一块选到那里。大纲接过键：Tab、Shift+Tab、Alt+↑↓、⌘回车、退格对选中的一起做，一批交上去；每块连着它下面的走（父块选中了，子块不另算）；第一块（往下挪是最后一块）动不了时一块都不动。⌘C、⌘X 把选中的连同下面的复制成 Markdown 大纲（最浅的不缩进），粘进一块又按缩进拆回块。回车写最后选到的那块，Esc 或焦点离开大纲就不选了。

**拖着挪**：块的圆点也是拖它的把手（像 Logseq）。放在一行的上半是放到它前面，下半是放到它后面，下半且越过它的字开头 32px 是放进它里面当第一个子块；放的地方画一条线。拖的是选中的块之一时选中的一起走，按原来的顺序。op 是 `move_to`（`block`、`target`、`at`：`before`、`after`、`inside`），放不进自己或自己下面。规则在 `packages/protocol/src/rules/pkm.ts`，放在哪、拖哪些在 `selection.ts` 的 `dropAt`、`dropOps`。手机上拖不了，用工具条的上移下移。

**折叠写进文件**：像 Logseq 一样，折起来的块在文件里多一行 `collapsed:: true`（在块的属性里排第一），展开就把它置空、打印时不写；重读、换设备都一样。折叠也是一次改动，能撤销。

**新建和设属性**（`pkm.page.save`）：没有这个标题的页就在给的那一层（默认收件箱）新建，`markdown` 是它的大纲；有了就合并属性，层变了就把文件挪到那一层的文件夹（`pkm.page.move` 同样）。

**改块**（`pkm.block.apply`）：先比对文件，再按顺序施加每个操作，整页写回一次。插入的块 id 由插入的一方给（页面的编辑器），没给的由服务端生成。

**看一页**（`pkm.page.get`）：页面、页上和它的反链里每个 `((引用))` 现在读出来的字（引用里的引用再读，最多两层，绕回来的说循环）、别的页面链接到它的块（按项目、日记、领域和资源、归档分组，新改的页在前）、这页没答的批注。

**搜**（`pkm.search`；页面是一个对话框，侧栏和外壳的 Ctrl+K 都开它，结果按页分组、命中的词标出来，打开时停在那一块：`/pkm/<页>?b=<块>`）：每一块的页标题、路径（上面几层块的第一行）和字，照记性的切法（中文按 gse）切成词存进 FTS5 的 `pkm_term`，每读进或写出一页就整页重写它那几行，开机后第一次用时整个重建。查询切成同样的词，每个词按开头匹配、用 `OR` 连起来，`bm25` 给分；整句出现再加两分，乘以这一层的权重（项目 2、领域 1.5、日记 1.4、资源 1.2、收件箱 1、归档 0.5）。可以只要某一层、某种标记、链接到某页的块。命中带一行去掉记号的字（`plain`：`[[x]]` 留下字，`((块))` 读出来，批注标记和 Markdown 记号去掉），路径（`path`）也去掉记号；反链的路径和过期的块同样。

**剪藏**（`pkm.clip.create`）：同一个地址（去掉末尾的 `/`）只有一页：再剪一次把划线加进那一页。新的一页原文存进 `.pkm/snapshots/`，属性写来源、作者、剪藏日期、原文的位置和摘要。

**聚类**（`pkm.cluster.create`）：收件箱、日记和资源里写到这个话题（或页标题里有）的块，各引用一次，放进一页新的资源。

**改名和合并**（`pkm.page.rename`）：新名字没有页就改名、挪文件，旧名字记进 `alias::`；有了就把旧页的块接到它后面、删掉旧文件。然后全库里写着 `[[旧名字]]`（含 `[[旧名字|别的字]]`）的都改成新名字。

**导出**（`pkm.page.export`）：给人的 Markdown：引用读成字，`[[链接]]` 留下字，批注标记去掉，顶层有子块的一块变成标题。

## 和谁打交道

- **记性（`memory`）**：只借 `termsList` 切中文的词（索引和查询用同一种切法），不读不写记性。
- **处理函数（`handlers.ts`）**：`pkm.*` 只转发到 `Pkm`；主人和「连接到本机」能调，`pkm.undo` 只有本机的主人。
- 不进核心状态：笔记不在 `StateFrame` 里，页面用 `pkm.*` 取，看着的时候每几秒再取一次（正在写的时候不取）。
- **外壳的 Ctrl+K**（`features/channel/QuickSwitcher.tsx`）：频道之后列标题对得上的笔记页，最后一行「在笔记里搜」打开搜笔记。

## 为什么这样

- **文件是真相，库里只放文件里没有的。** 笔记是主人自己的东西，要能用 Logseq、Obsidian、编辑器打开、进 git；放进库里就只能经 VibeValley 看。放弃了把页面和块存进表：那样就有两份真相，别的编辑器一改就要合并。页面的索引放在内存：几千页读一遍是几秒的事，反链、引用、回顾雷达都是纯函数，测试不用库；只有全文检索放进库里的 FTS5，它要倒排和打分，自己写不划算。
- **id 按需写进文件。** 每块都写 `id::` 会让文件里满是 uuid；一个都不写，引用和批注重读以后就找不到块。只写有人用的，和 Logseq 一样。
- **服务端写出的页面不重读。** 重读会按位置重新生成没写 `id::` 的块的 id，编辑器里正改着的块的 id 就变了。别的编辑器改过的文件只能重读，按内容接回 id 是能做到的最好的。
- **改写必须留住链接。** 改写是模型写的，最容易丢的就是 `[[链接]]` 和 `((引用))`，丢了反链和引用就断了；补在末尾，比拒绝整个改写好用。
- **先在本地改，同一份规则。** 每个键都等服务端答完光标才动，打字快了会丢光标、页面会闪；页面自己写一份施加操作又会和服务端漂开（缩进带不带子块、标记怎么轮）。施加操作的规则放进 protocol，两边跑同一份；放弃了换成 contenteditable 的富文本编辑器：文件是 Logseq 的 Markdown，一块一个没有框的文本框，看起来和读的时候一样，原样写最不会坏。
- **一个 Ctrl+K。** 外壳已经认 Ctrl+K，笔记另开一个会抢同一个键；并进去只多一组和一行。
- **撤销按文件，不按操作。** 改名会改好几个文件，每个文件一条；只放回一个文件，比回放操作简单，也和别的编辑器的改动不打架。
