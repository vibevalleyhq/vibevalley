# 连接到本机

「连接到本机」是从外面（手机、局域网里的另一台电脑）进农场的那道门。Rust 服务端还没有它：随手机壳一起砍掉了（[原生计划](.agents/notes/proposed/architecture/2026-11-14-native-vibevalley.md)「砍掉的」），日后按需在 Rust 上重做。

## 现状

- **只剩状态接口**：`lan.get` 总答「没开」，带上本机名（`crates/vibevalley-server/src/modules/lan.rs`）；页面的「设备」页据此显示关着。其余 `lan.*`（开关、配对码、本机点头）不服务。
- **主监听只听本机**：服务端固定绑 `127.0.0.1`，没有第二个监听；帮工的 `/mcp` 和全部接口都不出这台电脑。

## 重做时守住的

- **独立监听，不把主监听暴露出去**：主监听挂着无需鉴权的 `/mcp` 和管理接口；外面来的只经单独的门，按 `can` 里的 `remote` 放行，`/mcp` 一律不放。
- **一次性配对码加本机点头**：码短时有效、错几次作废，本机有人同意才签钥匙；设备收回时当场掐断它的连接。
