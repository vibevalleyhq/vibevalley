# 界面怎么做：田间工作台

VibeValley 的界面叫「田间工作台」：工作的地方是一张铺在田头的书桌，暖纸、墨棕、几样庄稼的颜色；看和玩的地方是画出来的像素农场。本篇写工作台怎么做：审美、令牌、原子和模式、和那份八篇大纲的对照、给 agent 的清单。令牌的值以 `apps/web/src/style.css` 为准，本篇只说用途和挑法；写错了由 lint 拦（`vibevalley/no-hex-color`、`vibevalley/design-tokens`，`scripts/oxlint-plugin.ts`、`scripts/design-tokens.ts`）。像素皮怎么画见 [农场的皮](docs/subsystems/farm.md)，页面的分层和宿主见 [客户端](docs/subsystems/app.md)。

## 审美

- **两张皮，一份调色板。** 工作台是 Linear 那样的工作界面，像素皮是画出来的农场；工作台的浅色就是农场的颜色（纸、树皮、叶、麦、莓、水），所以从农场进工作台不像换了一个应用。像素皮自己的根元素定回浅色，深色主题只换工作台。
- **暖而不甜。** 底是纸色（`page`），字是墨棕（`ink`），不用纯黑纯白；深色主题是夜里的木桌，不是冷灰。
- **颜色只说状态。** 叶（`leaf`、`accent`）是好了、主操作；麦（`wheat`）是在等、在想、要你看；莓（`berry`）是坏了、危险；水（`water`）是信息和链接；`idle` 是没人在干。装饰不用颜色，用排版和留白。
- **安静的密度。** 一屏放得下一天的活：正文 13px，控件 28px 高，留白按 4 的倍数。信息多的地方先收起（折叠、⋯ 菜单、悬停才出的工具条），不缩小字。
- **层级靠表面，阴影只给浮起来的。** 侧栏、页面、浮层三层颜色分开；贴在表面上的东西不投影，只有浮在页面上的（菜单、对话框、toast）投影。
- **一个块一圈线。** 线是 12% 的墨（`line`），一个块只有一圈；块里面再分区用留白、`hover` 色或一条分隔线，不再套一圈边。
- **动效说因果，不表演。** 东西从哪来、去哪了、按没按下去；一次动效短到不用等。像素皮走帧（`steps()`），不走缓动。没有一直在动的装饰：会动的循环只给「活着」的状态（在想的点、在录音）。
- **只画真数据。** 没连上就说没连上；空的地方说为什么空、下一步做什么。

## 两张皮

| | 工作台 | 像素皮（农场、记忆树、`ui/pixel`） |
|---|---|---|
| 在哪 | `apps/web/src/ui`、`features/*`、`app` | `farm`、`tree`、`ui/pixel` |
| 字 | 系统的中文字体（`font-sans`），13px 正文 | FusionPixel（`font-pixel`），只在 12、24px 清楚 |
| 图标 | reicon 的线条图标（`ui/Icon.tsx` 的 `<Icon name>`），跟着字的颜色 | `public/pixel` 的贴图（`SpriteIcon`） |
| 线和影 | 1px 的 `line`，`shadow-raise`、`shadow-float` | 2px 的树皮色框，`shadow-px` 和 `ui/pixel/style.ts` 的 `pxWindow`、`pxFrame` |
| 动效 | 缓动和三档时长（下面「动效」） | `steps()` 走帧，一像素一像素地动 |
| 主题 | 浅色、深色（设置 › 外观） | 只有画出来的那一套 |
| 令牌的检查 | `no-hex-color`、`design-tokens` | 不查：画出来的颜色和尺寸是画的一部分 |

头像（`ui/Face.tsx`）、农机的 logo、项目的岛、额度瓶在工作台里也是画，照像素皮。

## 令牌

### 表面

| 令牌 | 用在 | 说明 |
|---|---|---|
| `bg-rail`、`text-on-rail` | 最左的木色栏 | 两个主题里都是深的 |
| `bg-side` | 侧栏、成员栏、设置的导航 | 比页面暗一档 |
| `bg-page` | 页面、卡片、浮层的底 | 卡片和页面同色，靠一圈 `line` 分开 |
| `bg-hover`、`bg-selected` | 悬停、选中、块里分区 | 墨的 6%、10%，两个主题都对 |
| `bg-scrim` | 对话框后面 | |
| `bg-code-bg`、`text-code-ink` | 命令、代码、终端输出 | 两个主题里都是深的 |

### 状态色

| 令牌 | 意思 | 浅底配字 |
|---|---|---|
| `leaf`、`accent` | 好了、主操作、选中 | `bg-ok-soft` 配 `text-ok-ink` |
| `wheat` | 在等、在想、要你看 | `bg-wheat/25` 配 `text-ink` |
| `berry` | 坏了、危险、出错 | `bg-bad-soft` 配 `text-berry` |
| `water` | 信息、链接 | |
| `idle` | 没人在干 | |
| `muted`、`faint` | 次要的字、更次要的字 | |

浅底一定配好它的字（`Tag` 的 `tone` 带着字色），不要在浅色块上让字继承 `ink`：深色主题里会变成浅字浅底。透明度写成修饰（`bg-wheat/14`），不另起颜色。

### 圆角

| 类 | 值 | 用在 |
|---|---|---|
| `rounded-xs` | 3px | 一行字里的标记：键帽、@ 名、角标、像素格 |
| `rounded-sm` | 4px | 标签（`Tag`）、分段的选项 |
| `rounded-md` | 6px | 控件：按钮、输入框、菜单项、小浮层 |
| `rounded-lg` | 8px | 卡片、面板、看板的栏、对话框、菜单 |
| `rounded-xl` | 12px | 大的浮层（工单详情）、栏上的格子 |
| `rounded-full` | | 胶囊、头像、状态点、计数 |

套在一起时里面的圆角小一档（卡片 `lg` 里的按钮 `md`）。

### 控件

| 高 | 用在 |
|---|---|
| `h-6`（24px） | 紧凑的：分段的选项、行内的小按钮 |
| `h-7`（28px） | 默认：按钮（`Button`）、只有图标的按钮（`IconButton`，`size-7`） |
| `h-8`（32px） | 输入框、选择框、带搜索的条 |

按钮里图标和字之间 `gap-1.5`，左右 `px-2.5`。一组控件放在一行时高度一样。

### 线和阴影

- 线只有一种：1px 的 `border-line`；焦点是 `focus` 色的 2px 外框（`style.css` 的 `:focus-visible`，全页一条，组件里不再写一遍）；选中的输入框是 `border-focus`。
- 阴影只有两档：`shadow-raise`（贴着表面的一层：分段选中的那项、看板上悬停的卡片）和 `shadow-float`（浮在页面上：菜单、浮层、对话框、toast）。自己的阴影只在要一条内描线时写（`shadow-[inset_0_2px_0_var(--color-accent)]`），颜色用调色板的变量。

### 字

| 类 | 大小 / 行高 | 用在 |
|---|---|---|
| `text-2xs` | 11 / 14 | 只给计数、角标、键帽 |
| `text-xs` | 12 / 16 | 时间、说明、栏名、次要的字 |
| `text-sm` | 13 / 20 | 正文、按钮、列表（页面默认） |
| `text-base` | 14 / 22 | 对话框和区块的标题 |
| `text-lg` | 16 / 24 | 页面里的大标题 |
| `text-xl` | 20 / 28 | 页面的名字 |

- 粗细三种：400 正文，500（`font-medium`）选中、标签，600（`font-semibold`）标题和名字。
- 数字默认等宽（`body` 的 `tabular-nums`）：计数、时间、额度、钱对得齐，变的时候不跳。
- 代码、id、分支、命令用 `font-mono`。
- 中文的标点不挤压，一行的字不手动断；放不下用 `truncate`（单行）或 `line-clamp-2`，容器要有 `min-w-0`。

### 图标

图标跟着它旁边的字：`text-xs` 配 12px，`text-sm` 的按钮配 14px，只有图标的按钮配 16px，页面头上的配 20px。图标和字竖着居中（`items-center`），多行的字配图标时对第一行（`items-start` 加 `mt-0.5`）。图标只从 `ui/icons.ts` 那张表里按意思取，一个意思一个图。

### 动效

| 令牌 | 值 | 用在 |
|---|---|---|
| `duration-120` | 120ms | 指针底下的：悬停、按下、展开的小箭头 |
| （默认） | 180ms | 状态变化：颜色、显示隐藏、选中 |
| `duration-280` | 280ms | 面板、抽屉、对话框的进出 |
| `ease-out` | `cubic-bezier(0.2, 0, 0, 1)` | 进来的和大多数变化（默认） |
| `ease-in` | `cubic-bezier(0.4, 0, 1, 1)` | 离开的 |
| `ease-in-out` | `cubic-bezier(0.4, 0, 0.2, 1)` | 来回移动、变大小 |
| `ease-spring` | `cubic-bezier(0.34, 1.4, 0.64, 1)` | 只给弹出来的小东西（一个角标、一个新标记） |
| `animate-pop-in` | 280ms，98% 放大淡入 | 菜单、浮层、对话框、toast 进来 |
| `animate-fade-in` | 180ms 淡入 | 提示（`Tip`）、对话框后面的暗幕 |

- `transition-*` 只列要动的属性（`transition-[background-color,translate]`），不写时长就是 180ms 加 `ease-out`。
- 按钮按下时下沉一个像素（`active:translate-y-px`，120ms）。
- 弹出来的东西从它出来的地方长出来：下拉菜单 `origin-top-right`，输入框上面的菜单 `origin-bottom`。
- 系统要求减少动效时，工作台的过渡和循环一律停下（`style.css` 的 `prefers-reduced-motion`）；像素皮的动画各自写了停法。
- 只动 `opacity`、`translate`、`scale`、颜色，不动会重新排版的属性（宽、高、`top`）。

### 层

| 类 | 放什么 |
|---|---|
| `z-10` | 贴在内容上的：黏在顶上的栏头、悬停才出的工具条 |
| `z-20` | 盖在页面上的面板：串的侧面板、工单的详情、拖进来的落点 |
| `z-30` | 菜单、浮层、提示、手机上的抽屉 |
| `z-40` | toast |

对话框用原生的 `<dialog>`，在浏览器的顶层，不排进来。

### 禁用、空、滚动

- 禁用一律 `disabled:opacity-50`，加 `disabled:cursor-default`；按下时不下沉。
- 能滚的区域（不带边框和阴影的那一层）加 `scroll-fade-y`，横着滚的一排加 `scroll-fade-x`：还能往哪边滚，那边淡出 16px，滚到头就不淡。遮罩会连边框和阴影一起遮，所以加在里面那层，不加在带边框的浮层上。折起来的长字加 `fold-fade`，最后三成淡出，看得出还有。
- 消息列表离开最新的一屏，底上出一个胶囊：这期间别人说了几条，或「回到最新」；点了滚回底（减少动效时直接跳）。

## 原子和模式

- **按钮**（`ui/Button.tsx`）：`primary` 一个区域只有一个，是那里最要紧的一步；`plain` 是其余的；`quiet` 放在工具条和行里；`danger` 是字变莓色的 `plain`，不填满。只有图标的用 `IconButton`，它的名字就是悬停的提示和读屏的话。
- **分段**（`ui/Segmented.tsx`）：两到五个互斥的选项；槽是 `bg-hover`，页面色加 `shadow-raise` 的滑块垫在选中的那项下面，换选项时滑过去（280ms）。
- **状态点**（`ui/Dot.tsx` 的 `Dot`，`features/channel/bits.tsx` 的 `PhaseGlyph`）：点的颜色照「状态色」那张表，画在头像、图上时带一圈页面色（`ring`）；会变的状态用 `PhaseGlyph`（图标），静的用点。
- **对话框和确认**（`ui/Dialog.tsx`、`ui/ConfirmButton.tsx`）：对话框标题一行，下面是内容，Esc 和点暗幕关掉。删、合、关这种收不回的用 `ConfirmButton`：第一次点在原地问（「删掉 X？」、危险按钮、「算了」），Esc 或焦点离开就收回；或者先问服务端的预演（`--dry-run` 那一路）把会发生什么列出来。不用 `window.confirm`。消息上悬停的工具条地方小，删除是同一个按钮点两次。
- **标签和计数**：`Tag` 只取 `tone`（`ok`、`bad`、`wait`），自带字色；未读用 `Count`（`rounded-full`、`text-xs`）。
- **附件**（`ui/AttachmentTile.tsx`、`ui/Lightbox.tsx`）：图片在消息里最多 `max-h-64`，一圈 `line`、`rounded-md`，点开是看图的浮层（← → 翻同一条消息的图，Esc 关，原图另开一个标签页）；文件和输入框里待发的附件是磁贴：图的缩略图或类型的图标、名字、大小，待发的能逐个去掉。
- **消息**：一行一条，不画气泡（群聊里人多，靠头像和名字分人）；连着说的不重复头像；时间是 `text-xs text-faint`；悬停的工具条在右上，`z-10`。
- **在想和在写**：只在服务端说它在想、在写的那个频道里画三个点（`ThinkingDots`），带着是谁；不猜。
- **输入框**（`features/channel/Composer.tsx`）：回车发，Shift+回车换行，`@` 出名单；拖文件进来整块变成落点。
- **干活的经过**（`features/session/WorkLog.tsx`）：每一步一个块，底色说它是什么（交给它的话 `bg-wheat/14`、想起的 `bg-leaf/15`、它说的 `bg-hover`、出错 `bg-berry/10`），长的先折起来。
- **空状态**：一个图标、一句为什么空、下一步的链接或按钮（`Empty`）。
- **出错和限流**：一次性的用 toast（坏的是莓色）；持续的写在它所在的地方（额度瓶、连接的小灯、工单的「卡住了」）；拒绝的话里带下一步。

## 给 agent 的速查

**挑动效**：

1. 在指针底下（悬停、按下、小箭头转）→ `duration-120`。
2. 一个状态变了（颜色、显示、选中）→ 默认（不写时长）。
3. 一块东西进来或离开（面板、抽屉、对话框）→ 进来 `duration-280 ease-out` 或 `animate-pop-in`，离开更快、`ease-in`。
4. 一个小东西冒出来要人注意（新的角标）→ `ease-spring`，只用这一处。

**写一个新界面之前**：先找有没有现成的原子（`ui/` 下：`Button`、`IconButton`、`Segmented`、`Dialog`、`Field`、`Tip`、`Icon`），有就用，不另写一个长得差不多的。

**交之前自己查一遍**：

- [ ] 颜色、圆角、字号、阴影、时长、层都是令牌（`vp check` 过了就是）。
- [ ] 深色主题下看一遍：浅色块上的字自带字色，没有写死的颜色。
- [ ] 一个区域最多一个 `primary`；危险的操作不填满，收不回的先确认或预演。
- [ ] 一个块一圈线，块里没有再套边；只有浮层有 `shadow-float`。
- [ ] 每个只有图标的按钮有名字；键盘能走到、Esc 能关。
- [ ] 长的字会截断或折叠（`min-w-0`、`truncate`、`line-clamp-*`），窄窗口不撑破。
- [ ] 空的、加载中、出错三种样子都有。
- [ ] 动效有因果，减少动效时停得下。
- [ ] 照 [验收](.agents/skills/acceptance/SKILL.md) 的页面分册截图，浅色、深色各一张。
