# 农场界面和玩法

一座 QQ 农场那样的 2.5D 卡通农场：一块块等距的方形花坛当田地，庄稼按进度长，冒虫子、地干裂要人去处理，左下一排帮工头像，木牌风格的按钮，有仓库和商店。农场里的东西怎么对上 VibeValley 见 [guide.md](guide.md)「农场和 VibeValley 的对照」。

## 画风

农场是像素画的小院（`/`）：风来之国那样，帮工照手上的事走去书屋、工坊、电台；面板的入口是院子里的小摊、告示板、邮筒这些东西；面板和配置页都穿像素皮肤。布局、配色和格子的来历是型号 B「温室花园」（效果图 `design/mockups/v2/B-cozy.png`，四个型号的对比页是 `design/mockups/index.html`；为什么是农场、为什么是 B，见 [farm-instead-of-construction-site](../.agents/notes/implemented/feature/2026-10-09-farm-instead-of-construction-site.md)），后来整个重画成像素（[理由](../.agents/notes/implemented/feature/2026-10-11-pixel-village.md)）。

像素村用 Flame 画（`app/lib/village/`），院子里怎么摆、怎么动、怎么打光、HUD 在哪，见 [framework.md](framework.md)「像素村」；寻路、音效和素材流水线也在那里。

## 角色

人只有一个：管家。戴草帽的青年，站在农舍门口，头上冒对话气泡，旁边睡着一只宠物（开工时醒着）：小狗、重点色布偶猫或蓝猫。管家可以换样子，宠物可以换（界面 17）。

其余都是小动物帮工，一个帮工档案一种动物，在「捏帮工」里可以换：

| 档案 | 动物 | 性格 |
|---|---|---|
| 后端老周 | 熊 | 稳，力气大，搬砖砌墙 |
| 测试小吴 | 兔子 | 跑得快，一遍遍跑测试 |
| 前端阿郑 | 小狐狸 | 手巧，做界面 |
| 文档员 Kimi | 猫 | 安静，坐得住，读写文档 |
| 情报 Grok | 猫头鹰 | 看得远，查资料 |
| Pi 实验员 | 刺猬 | 爱捣鼓小原型 |
| 夜班反重力 | 浣熊 | 夜里出来干杂活 |

动物和农机没有固定对应：动物只表示这个档案是谁。每种动物有四套衣服（农夫、园丁、雨衣、冬装）和六个动作（待命、走路、干活、琢磨、欢呼、发愁）。

## 地里长什么

一块地同时只种一样东西：6 块地是 6 个帮工的位置，也是同时干活的上限；另有 3 块锁着，分别在 Lv.5、8、12 开垦，开垦后是花坛（只是外观，上限由服务端定）。

地里长什么、挂什么牌子，只看帮工的阶段和「要你做什么」（[architecture.md](architecture.md)「核心状态」；服务端 protocol 的 `PlotOfHelper` 算好放进 `SiteFrame` 的 `view`）：

| 帮工 | 地里 | 牌子 |
|---|---|---|
| 到场（arriving） | 刚播种 | |
| 干活，还没改文件 | 发芽 | |
| 改过文件 | 长叶 | |
| 改过文件后跑了命令 | 开花 | |
| 干活但很久没动静 | 干裂 | 没动静 |
| 干活，模型调用在重试 | 照常 | 重试中 |
| 做完（ripe） | 麦子或胡萝卜（每个帮工固定一种） | 可收获；分支会冲突时是「有冲突」 |
| 失败（failed） | 枯萎、有虫 | 有虫 |
| 歇着（resting：叫停了，或服务端重启过） | 停在当时的样子 | 歇着；分支会冲突时是「有冲突」 |
| 离开 | 收完的麦茬 | |

**地牌**：帮工所在的地，前沿插一块小木牌，写着项目名和分支（去掉 `vibevalley/` 前缀，比如 `clock-in ⎇ w1`）；分支会冲突时下面挂一条红色「冲突」。

**帮工的姿势**（`poseOf`）：改文件、跑命令是「干活」，读、搜、想是「琢磨」；地里熟了「欢呼」，长虫或干裂「发愁」；走在路上是「走路」，其余「待命」。

**帮工不站桩**：干活时每隔几秒换个位置，在自己那块地四周走动（琢磨时站侧面或后面，动手时站前面）；歇着的时候去草地上溜达再回来；手上的事一变就走到对应的位置。走路只走关卡里能走的地（`village.ldtk` 的 Ground 层）：从大门进来，在地之间走过道，绕开地块、篱笆和花丛，挑最短的路、离边远一点（石板路不比草地便宜）；朝前走看到脸，往画面里走看到背影。

**头上**：名字（指着它或刚到时）、此刻在做什么的小图标（指着看完整的动作和对象）、它用的农机的体力条。

## 工具

右边一列，数字键 1–6 拿起，Esc 放下。指着一块地时，地块发光、抬起，上方的小卡片写这块地的情况和手上的工具点下去会做什么；用不上就变灰、写明原因。

| 工具 | 点一块地 |
|---|---|
| 手 | 空地：播种（界面 3）；有帮工：看详情（界面 2） |
| 浇水 | 给帮工带句话（记在它的工单串里）：干着活中途收到，歇着就接着干一轮 |
| 杀虫 | 失败的地：让它看报错接着修 |
| 除草 | 等你批准的权限请求（[提案](../.agents/notes/proposed/feature/2026-10-10-permission-requests-as-weeds.md)）。现在只有提示 |
| 收获 | 做完或歇着的地：服务端上先开收成清单（界面 15），确认后合进项目、帮工收工 |
| 铲除 | 干着活就叫停这一轮，否则请它收工 |

点下去地块会压一下再弹回来，扩散一圈波纹，配一声轻响；用不上时地块轻轻摇一下。整块木框都能点，不只是顶面。鼠标指针是画的：平时是手套，指能点的东西时伸出食指，按下时点下去；拿着工具时变成那件工具，能用的地方带闪光，用不上的地方带禁止标记。

## 界面清单

代码注释里的「screen n」指这里的编号。

**主场景**

1. **农场主界面**：院子、农舍、9 块地、管家、狗、帮工（布局见 [framework.md](framework.md)「像素村」）。
   - 左上：管家头像（点开换样子）、等级、金币、时间和经验条。
   - 右上：菜单（音效、调试台和各处入口），旁边是「地图」「频道」按钮和精力瓶（最紧的那台农机，点开看全部）；窗口窄于 640 时不放「地图」，从菜单去。
   - 院子里的东西是面板的入口：商店、仓库（挂着收进主分支的工单数）、任务、日志、计划（挂着等你处理的计划数：草稿、有步骤没做成、可以收获）、帮工名册、农具、技能书。
   - 正下方：工具的快捷栏。
   - 左下：帮工按钮，点开是全部帮工档案。
   - 右下：田头，农场的群聊窗口（界面 16）。

**从主场景点开的**

2. **田地详情**（点一块有帮工的地）：
   - 左边：庄稼和帮工、阶段、动物和衣服和农机、模型、第几块地第几轮、一共花了多少（「约 ¥0.02 · 4.4 万 token」）、去它的档案。
   - 右边：项目、分支、worktree 路径（可以复制）；工单原文；正在做什么；没动静或重试中的说明；会冲突时一行红字和「让它解决冲突」；上一轮的结论。
   - 计划里的帮工：一行黄底的字，写是哪个种植计划的哪一步（或在拆计划），和「看计划」；没有收获按钮，它的活做完自动合进计划分支。
   - 按钮：杀虫（失败时）、收获…（能收时）、叫停（干活时）、看工单串（在田头窗口里打开它的串）、请它收工；带话的输入框（浇水）。
   - **干活过程**按轮排：每一轮是它收到的那句话（工单、带话，或者对某一步的评论），一条时间条（每一步一段，长短是耗时，颜色是做了什么：读和搜索水蓝、改文件叶绿、跑命令树皮色、说话浅绿、出错莓红；点一段就展开那一轮、跳到那一步），然后是这一轮的步骤。最后一轮展开，之前的只显示它最后说的话，点轮头展开。每一步下面有「评论这一步」，写一句发给它，它带着那一步的上下文接着做，评论挂在那一步下面。步骤本身有：接到的工单、带话、这一轮开头想起了什么（它的 agent 的记性）、它想了什么（「想了想」，农机交出思考时才有，折起来）、它说的话（Markdown）、每次工具调用（点开看输入和输出，成功 ✓ 失败 ✗ 还在跑 …）、重试、问题。它派出去的帮手（Claude 的 Task 这类子 agent）的步骤缩进排在派它的那次调用下面，标「帮手说」「帮手接到」。新的接在下面，停在底部时跟着往下走。
   - 碰过的文件、跑过的命令。
3. **播种袋**（点空地）：选一张种子或自己写，选谁来种（自动或某个档案）。种子先是你以前派过的短工单（新的在前，长的计划步骤不算），再是给工作目录里真实项目的几张常用工单（看看测试、补 README 的启动步骤、给最近改的地方补测试、清掉没用的代码和依赖），没有项目时是不带项目名的同样几张。没开工会先开工；下一个到场的帮工种在点的这块地上。
4. **帮工栏**：每个档案一个头像，圆点表示在干活、熟了、有虫，头像下是它农机的体力条；点开看它请过几次、收成几次（服务端账本的数），可以指定下一单派它，或者去它的档案。
5. **捏帮工**（`/agents/:id`）：左边选动物和衣服，中间是它站在田边、切换六个动作和地里的样子，右边是配置（[agents-and-runtimes.md](agents-and-runtimes.md)）。
6. **商店**：种子、装饰、开垦新地。现在只列了东西，买不了（[提案](../.agents/notes/proposed/feature/2026-10-09-shop-and-daily-tasks.md)）。
7. **仓库**：收进主分支的成果，每张收获了的工单一格（整个种植计划收获了也是一格）：标题、谁做的、哪个项目、多久前收的；点一格打开它的工单（计划打开计划板）。读的是核心状态里关成 `harvested` 的工单，不另存；没收就收工的、没做成的不在这里。
8. **任务与成就**（`app/lib/farm/achievements.dart`）：
   - 上面一条：等级和到下一级的进度条、金币和连胜加成、称号（点开换）。
   - 新手任务清单：做完的打勾，没做的写着奖多少金币；都做完了收成一行。
   - 开垦：哪一级开垦哪块地。
   - 成就墙按类排（收成、手艺、精打细算、协作）：每个一枚奖章、名字、说明、三个档位点、到下一档的进度条、拿到的日期。
   - 彩蛋：找到的照常显示，没找到的只写「还有 N 个彩蛋」。
9. **农场日志**：按时间倒序，每行是时间、头像、谁、一个标签（说、答、做完、没过）；帮工的汇报写出工单、结论和花费。你和管家在田头上说的话和帮工交来的每一轮汇报（田头里的汇报消息）合在这里；帮工在串里说的别的话在田头窗口里。
10. **工单**（`/tickets`）：一块看板。
    - **四列**，从左到右：**待办**（写下来还没派的活，存在服务端，按你排的先后）、**处理中**（列头写「几 / 6 块地」）、**等你看**（做完了、没做成或停在半路）、**已关**（已收获、合进了计划、拆好了计划、没收就收工了；新关的在上，默认只显示最近 15 张，下面「更早的 N 张」展开）。
    - **种植计划也在看板上**：在拆、在做的计划在处理中，拆好了等你看、暂停了、都做完了等你收获的在等你看；卡片写着做到第几步，点它打开农场里的计划板，计划的事在那里做，不能拖。计划里每一步的工单标「种植计划」，标题是「计划名 · 步骤名」，拆计划那一张是「拆计划：计划名」。
    - **顶上**：找工单（标题、帮工、项目里找，几个词都要有），按项目、按帮工筛；筛了以后写「几 / 一共几张」和「清掉筛选」。
    - **卡片**：标题、谁做、项目；待办左边一条优先级的颜色（紧急莓红、高麦黄、低浅色）和「紧急」「高」的标签，写于什么时候；工单写第几轮、开了（或用了）多久、花了多少，标出冲突、好一阵没动静、没做成、丢了、重开的；等你看的再加它最后说的话。
    - **拖卡片就是操作**：待办拖到处理中是开工（派出它选的帮工档案）；待办拖到另一张待办上就排到它前面，拖到待办列的空处排到最后；处理中或等你看拖到已关是关单，等你看的先看收成清单再收获，也可以不收直接收工，处理中的是叫停并收工；已关拖回处理中是重开（写一句这次要做什么）。别的方向拖不过去，能放的列亮绿框。种植计划里的工单（标「种植计划」）跟着计划走：不能单独关、单独重开，在农场的「计划」里管。窄屏（手机）上一次看一列，顶上切换列；跨列的事用卡片打开后的按钮做，列里长按卡片再拖排先后。
    - **写待办**：待办列头下的一行，打字回车就存下（帮工和项目按筛着的，没筛就用上次选的）；「详细写」打开表单：要做什么、优先级、项目、帮工（帮工后面写着它的农机，派不出去的写着为什么），存下或开工。没选帮工或项目的卡片标出来，拖去处理中时打开它的表单让你补上。
    - **地满了就排队**：开工时这台农机、这个项目或整个农场的地都占满了，待办不派出去，标「排队中」留在待办里；服务端每隔几秒按看板上的先后看一遍，有空地就自动开工，田头上说一声。排队的打开以后能「不排了」或「现在就试」。
    - **点卡片**在看板右边打开（窄屏上盖住看板）。工单：顶上一排按状态能做的（处理中：叫停这一轮、关上；等你看：收获、没做成的「接着修」、会冲突的「让它解决冲突」、停在半路的「接着做」，和关上；开着的都有「去农场看这块地」），谁在做、项目、分支、开单和关单、几轮、用了多久、花了多少、最后一轮、冲突；等你看的还有「改动」：几个提交、几个文件、加减行数、会不会冲突、改了哪些文件；下面是按轮的干活过程，开着的能评论某一步（鼠标移到那一步上，右上角出「评论」；手机上点一下那一步），能带话，关了的能重开。干活过程里帮工用的田头工具写成人话（在田头说话、读田头的消息、看有没有找它的话）。待办：改要做什么、优先级、项目、帮工，存下、开工、删掉。
    - 入口：工作台左栏的「工单」；农场里地块详情的「在看板上看」直接打开这块地的工单。
11. **农具房**（`/runtimes`、`/skills`）：农机的设置和技能书（[agents-and-runtimes.md](agents-and-runtimes.md)）。农具房里还有「连接器」（`/connectors`）：在微信、飞书、QQ 里和农场说话。微信、飞书扫码，QQ 填机器人的 AppID 和 AppSecret；飞书、QQ 连上后显示配对码；连上后看主人、上次收到的话、攒着没发的条数，可以断开（[server.md](server.md)「连接器：微信、飞书、QQ」）。
12. **项目**（`/projects`，[server.md](server.md)「项目是一块地」）：工作目录下的每个项目当一块地看。左边是项目，每个前面一块地，按最近一次提交长成什么样：一天内开花（正旺），一周内长叶，一个月内冒芽，三个月内有点干，再久就荒了。右边是选中的那块：
    - **地契**：项目名、长势、开垦于（第一个提交的日子）、耕作（提交数）、庄稼（行数）、种了几样，下面是它在这台机器上的路径和复制按钮；右上的刷新按钮重新数一遍。
    - **种了什么**：语言的占比，按行数（代码加注释，不算空行，Markdown 的正文算注释），画成一块地里的几垄，大的那几垄上有语言的 logo；下面每种语言的 logo、行数、文件数和占比。别名合在一起（TSX 算 TypeScript），七样以后的合成「其他」。
    - **耕作日历**：过去 53 周，一列一周（周一在上），一格一天，那天提交越多长得越高（空地、撒了种、发了芽、长了叶、开了花），按这一年里忙的日子定档；指着一格说是哪天、几次提交。上面是一年的提交数、动过土的天数、最长连着干了几天、最近连着干了几天。
    - **谁来干过活**：一年里按提交数排的人，名字和帮工一样的显示帮工的脸。
    - 入口：工作台左栏的「项目」，农场菜单里的「项目」，帮工的地的详情里点项目名。
13. **图鉴**（`/assets`）：农场用的每张图、每个指针、每个声音，给画图、调图的人看。入口：工作台左栏的「图鉴」，农场菜单里的「图鉴」。三个书架：
    - **图**（`/assets`，`/assets/<名字>` 直接打开一张）：按是什么分类（帮工按动物和衣服分组，管家、狗、地块、院子、农机、图标、在做什么、奖章与成就、Logo、语言、界面）；可以按名字、类别、动物、衣服找，换底色（格子、草地、夜里）看透明边。点一张看大图：按整倍数放大（不糊），标出落脚点和头，会动的（走路、摇尾巴、敲打……）按帧播放、能调快慢；尺寸，它切自哪张原图，重画和重新切的命令（都能复制）。
    - **指针**（`/assets/cursors`）：两套指针，鼠标移上去就换成那个，红点是点下去落在哪。

## 农场手机

左下角、「帮工」上面的「手机」（`app/lib/phone/`）：农场有事找你，它就来电；平时打开是一部像素风的手机。

- **主屏**：一格一个应用：未接（角上是未接几个）、记录、管家（打给管家，开语音，[voice.md](voice.md)）、频道（去 `/chat`）、计划（打开种植计划）、方块、小恐龙、推箱子。机身下面是十字键、主屏键和 A、B：主屏键回主屏，在主屏上再按一下收起手机；Esc 也收起。
- **谁会来电**（服务端的 Inbox，protocol 的 `Inbox`，放在 `SiteFrame.inbox`，见 [server.md](server.md)「Inbox」）：帮工的活熟了、没做成、合不进去、好久没动静；种植计划拆好了等你看、能收了、有一步卡住了（计划里的帮工熟了、没做成、冲突不单独打，由管家替计划打；没动静照样打）；一条 @ 你、你还没读也没回的话（管家或帮工）。来电都是从核心状态现算的，不另存；同一件事的来电号不变，同一个帮工下一轮又熟了算新来电。
- **响铃**：新来电时手机弹出来响，按钮跟着抖（音效 `ring`）；20 秒没理就收起，算未接，按钮上的数字是未接几个。客户端刚打开时已经在等你的，直接算未接，不响。语音通话中不响。
- **接听**去处理：帮工的打开它的地，计划的打开种植计划，@ 你的打开那个频道。**挂断**是先放着。接了、挂了的都不再响，也离开未接（只记在这次打开的客户端里，重开后还在等你的又算未接）。那件事在别处处理掉了（收获了、读了），来电自己停。
- **未接 / 记录**：未接列出还在等你的，点一个就是接听；记录是这次打开客户端以来接了、挂了的来电和打给管家的语音通话（多长）。
- **语音中**：手机显示管家在听、在想、在说，你和他的音量条，最后一句话，和挂断。
- **小游戏**：规则是纯函数（`lib/phone/` 的 `blocks.dart`、`dino.dart`、`sokoban.dart`……；方块和小恐龙按种子能重放），画面只管时钟、按键和画。打开游戏时手机变大（机身更宽、屏幕更高，方块的格子和小恐龙都画大一号；字还是 12 像素），回主屏变回去。玩的时候方向键、空格、Z、X 归游戏，不会拿起农具。
  - **方块**：10×18 的井，七块一袋随机；←→ 移、↑ 转（靠墙会被推开一两格）、↓ 落一格、A（空格）一下到底、B 暂停。一次消的行越多分越高，每 10 行升一级、落得更快。离开游戏或收起手机就暂停，回来接着玩。
  - **小恐龙**：A 或 ↑ 跳，↓ 或 B 蹲（空中按下去落得更快）；跳仙人掌，低的鸟跳过去，高的鸟蹲过去；跑得越远越快，跑过一段才有鸟。分数是跑的距离。
  - **推箱子**：5 个仓库关卡，把所有木箱推到菱形标记上；方向键移动，一次只能推一箱，不能拉。B（X）撤销一步，A（空格、Z、Enter）重开；过关后 A 进入下一关，最后一关后可从头再玩。显示步数和推箱次数，屏幕上也有撤销、重开按钮。离开游戏、收起手机或接电话保留这次打开里的棋盘，重开客户端从第一关开始；不计农场金币。
  - 最好成绩只记在这次打开里。
- 样子：木头机身、两像素的深色描边和硬投影，四种绿的液晶屏（像老掌机），状态栏是信号、「农场通」、时间和电池。

## 计分

金币、连胜、成就奖的是**收进主分支的活**，不是命令数、读写次数或花掉的 token（[理由](../.agents/notes/implemented/feature/2026-10-11-achievements.md)）。它们由服务端记在**农场账本**里，按顺序折出来，放进核心状态的 `progress`；客户端只显示，自己不算。规则是服务端 protocol 的纯函数（`server/internal/protocol/progress.go`）。回报只是金币和称号，不改变帮工怎么干活、地有几块。

| 机制 | 规则 |
|---|---|
| 金币 | 一个帮工的活收进主分支（有新提交才算）：`(30 + min(提交数 × 5, 30)) × 连胜倍率`。收获一个种植计划：`30 + 10 × 合进去的步数`。新手任务每个 20；成就的铜、银、金档各 10、30、60；彩蛋 50。一轮做完不给 |
| 连胜 | 连着收进去的活。倍率每多一件 +10%，最多 ×2。有帮工一轮没做成就清零，叫停不影响 |
| 经验 | 你的 commit 数（[理由](../.agents/notes/implemented/feature/2026-10-10-experience-is-commits.md)）：工作目录（`VIBEVALLEY_WORK_ROOT`）下所有 git 仓库里你名下的 commit，所有分支都算（帮工在自己分支上的提交也算），同一仓库的多个 worktree 只算一次。「你名下」按作者邮箱：git 全局和各仓库的 user.email，加上 `VIBEVALLEY_GIT_EMAILS`。服务端启动时、每 2 分钟、帮工干完一轮 15 秒后各数一次（`server/internal/game/commits.go`） |
| 等级 | 从 Lv.n 升到 Lv.n+1 要 `10n` 个 commit：Lv.2 要 10 个，Lv.5 要 100 个，Lv.8 要 280 个，Lv.12 要 660 个。Lv.5、8、12 各开垦一块地 |
| 成就 | 见下表。计数的分铜、银、金三档；一次性的（新手任务、彩蛋）拿到就是金框。定义在服务端 protocol 的 `Achievements`（`progress.go`） |
| 称号 | 拿到的任何一档（新手任务除外）都能挂在农场卡上：铜档用成就名，银、金档加「银牌」「金牌」，「收成」和「农场规模」每档有自己的名字 |
| 现场反馈 | 收获时金币从那个帮工头上飘起，升级横幅，成就到了一档弹提示，各有一声合成音效（[framework.md](framework.md)「音效」）；macOS 应用另弹系统通知 |

## 手机和快速动作

手机上整张图按比例缩小，能用但看不清（[竖屏提案](../.agents/notes/proposed/feature/2026-10-09-mobile-layout.md)）。帮工的动作来一个切一个，一秒内多次工具调用时会闪（[提案](../.agents/notes/proposed/feature/2026-10-09-action-queue.md)）。

## 新增项目

工作台「项目」左栏的「＋ 新增项目」打开表单。「开一块新地」填项目名，创建带 README 和初始提交的 git 仓库；「去别人家看看」填公开 GitHub 仓库主页地址，自动建议项目名，可自行修改。两者都保存到工作目录，不覆盖同名目录。

下载时显示「正在下载仓库」，最长 3 分钟；失败保留表单，可改地址或重试。成功后刷新列表并打开项目页，可查看代码分布和提交记录，再自行安排帮工。导入不会安装依赖或启动项目，也不会自动派帮工。
