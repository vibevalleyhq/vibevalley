# 农场界面和玩法

农场是像素画小院（`/farm`）：帮工按手头任务前往书屋、工坊、电台，地块庄稼随进度生长；院内小摊、告示板、邮筒对应各功能面板。概念映射、像素渲染、寻路与音效见[农场的皮](docs/subsystems/farm.md)，素材管线见 [开发](docs/development.md#素材音效和官网)。

画风采用型号 B「温室花园」（原图在 `vibevalley-art` 仓库，经 `design/art.sh` 链入；[为什么是农场](docs/subsystems/farm.md)）。字体为 Fusion Pixel 12px，字号仅用 12 与 24。

## 角色

- **助手（人）**：默认助手站在农舍门口（旁有宠物，可在界面 17 更换外观与宠物）；其他助手站在两侧，展示各自档案的外观与心情。
- **帮工（小动物）**：7 种动物（熊、兔子、小狐狸、猫、猫头鹰、刺猬、浣熊）× 4 套衣服（农夫、园丁、雨衣、冬装），仅作外观区分，与农机无绑定关系。内置模板见[内置的模板](docs/subsystems/agent.md#内置的模板)。

## 界面清单

代码注释中的 `screen n` 对应以下编号：

1. **农场主界面**：左上为助手、农场卡（等级、金币、经验）和「工作台」；右上为地图、频道、精力瓶和菜单；正下为工具栏；左下为手机和帮工栏（田头在手机内）。单仓库农场（`/farm/<仓库>`）立有仓库牌，仅展示该仓库帮工，点牌返回地图。按住 ⌥ 显示院内设施名称。
2. **工单详情**（点地块或看板卡片）：农场为居中弹窗（`apps/web/src/farm/issue/IssueView.tsx`），工作台为独立页（`/issues/<id>`，`apps/web/src/features/issue/views/IssueDetail.tsx`），共用 `apps/web/src/features/issue/model/overview.ts`（基于服务端 `Issue.stage`，[工单](docs/subsystems/issue.md)「给用户看的状态」）。从上到下依次展示：
   - **这是什么**：`#号`、单行短标题（`shortTitle`）、仓库与优先级。
   - **现在怎样**：当前阶段、等待或运行耗时、帮工、轮次与花费（卡住标红）。
   - **要你做的**：仅在需用户操作时出现，只放一个主按钮（回答问题、验收通过/收获、打回、恢复卡住、重开）。
   - **做到哪了**：验收标准逐条自评与凭据（`N / M 条做到了`），待验收时可勾选。
   - **做出了什么**：分支、提交数、增删行数与折叠的文件列表。
   - **怎么走到这一步**：时间线（`issue.timeline.get`）与折叠的完整说明、执行步骤。
   - **侧栏**：工作台右栏（或农场左栏折叠区）放次要动作（关单、叫停、带话）与元数据（时间、模型、分支、worktree）。
3. **播种袋**（点农场空地或地图岛屿空位）：归属当前仓库，提供「最近」派过的活、按栈填充的「常见的活」与「自己写」；选定执行人后点「开始」立即派活，或点「草稿」建备选工单并派帮工起草（[农场](docs/subsystems/farm.md)「播种袋」）。
4. **帮工栏**（左下）：展示各帮工头像与农机体力条，末格为「捏帮工」；点头像查看战绩或设「下一单派它」。
5. **档案**（`/agents`，[档案和农机](docs/subsystems/agent.md)）：上方为助手卡片，下方为帮工卡片；右上「从模板装」进入**模板页**（`/agents/templates`），支持预览人设、安装、导入本机模板目录或按新版本更新档案。
   - **助手档案页**（`/agents/<id>`）：编辑名字、职责、人设、模型和外观，支持私聊与删除（默认助手不可删）。
   - **捏帮工**（帮工 `/agents/:id`）：左选动物与衣服，中看预览，右填身份、能力、人设、技能、工具和环境，底部实时显示 `agentProblems`；已存档案含「记性」与「轨迹」页签。
6. **商店**：仅展示列表，暂不支持购买（[提案](.agents/notes/proposed/feature/2026-10-09-shop-and-daily-tasks.md)）。
7. **仓库**：展示已收获的工单，每张一格。
8. **任务与成就**（`apps/web/src/farm/panels/Achievements.tsx`）：展示等级、金币、称号、新手任务、开垦进度、成就墙与彩蛋。
9. **农场日志**：按时间倒序展示用户、助手发言与帮工汇报（最多 80 行）。
10. **工单看板**（`/issues`）：分待办、处理中、等你看、已关四列，支持拖拽流转与排序（满地标「排队中」）。
    - **新工单与起草**：点待办列头「＋ 新工单」填写一句话并选仓库与帮工，生成「草稿」卡片由帮工起草；草稿详情顶层展示三段进度轨、帮工提问与输入框，下方可编辑标题、说明、验收标准、优先级并点「开工」。
    - **父子工单与助手工单**：父工单显示子单完成数，点开 `FamilyDetail` 汇总验收；派给助手的工单不可拖拽，完成后在详情点「知道了」或「关上」。
11. **农具**（`/runtimes`，[档案和农机](docs/subsystems/agent.md)）：每台农机一页，展示探测结果、额度、能力、模型、自带技能/MCP、工具清单及关联档案；可配置开关、命令路径、默认模型/思考强度、环境变量、并发上限与每日预算（存在 `config.json`）。
12. **仓库**（`/repos`，[仓库](docs/subsystems/repo.md)）：左列仓库列表（首行为「全部」），右展示选中仓库岛屿的地块、空位、排队工单、代码概况、语言占比、一年提交日历与参与帮工；支持从 GitHub 克隆或新建空仓库。
13. **图鉴**（`/catalog`）：分图、指针、音效三个书架，支持分类浏览、搜索与切换底色（格子、草地、夜里）。
14. **弹窗和提示**：展示升级、成就解锁、服务端通知与语音连接异常。
15. **收获**（收获前确认）：展示提交、变更文件、diff 与冲突状态；确认后合入主分支，冲突时可点「让它解决冲突」。
16. **田头与聊天页**（[农场的皮](docs/subsystems/farm.md)「田头在手机里」）：
    - **田头**（手机展开右半屏）：顶部切换频道与查看助手状态；中部展示消息流、工单串与汇报标签（`⋯` 支持回应、回复、复制链接、编辑、删除）；底部为输入框、听写键与 `@` 提及。
    - **聊天页**（`/chat`）：完整展开频道分组、私聊、消息与串，侧栏顶部提供「跳到…」（Ctrl+K）与全局搜索，频道头部可查看串、置顶与成员（频道里的助手和在场帮工）（消息地址 `/chat/<频道>?m=<号>`）。
17. **助手和宠物**（左上角助手头像）：更换默认助手外观（存档案）与宠物（存本机偏好）；点院内助手展开手机对话。
18. **图纸桌**（院内图纸桌）：直接打开工作台工单页（`/issues`）。
19. **地图**（`/repos` 的「全部」，[截图](docs/images/map.png)）：每个仓库对应一座小岛，岛上地块对应进行中工单与空位（`RepoSummary.maxSessions`），院门外种子袋代表排队工单。
20. **设置**（`/settings/<分区>`）：左栏是搜索框与分组导航（分区见 `apps/web/src/features/setting/SettingsPage.tsx`），右栏按卡片展示设置项（`SettingsGroup`、`SettingRow`、`KeyRow`），标明农场级或本机级生效范围。
21. **开机加载**：场景图、单独绘制的品牌名和加载状态，准备好后直接进入农场；时段与退场条件见[客户端](docs/subsystems/app.md#怎么走)。
22. **助手页**（`/orchestrator` 与 `/orchestrator/<档案 id>`）：分「记性」「轨迹」（支持标记「这一轮做错了」）与默认助手专属的「声音」三个页签（[助手](docs/subsystems/orchestrator.md)、[语音](docs/subsystems/voice.md)）。

**工作台外壳**（`apps/web/src/app/Shell.tsx`）：最左为安静的导航栏，条目见 `apps/web/src/app/places.ts`，路由见 `apps/web/src/app/App.tsx`。

## 轨迹

助手页与帮工档案页共用 `apps/web/src/features/session/Trajectory.tsx`（先读日志快照再合并直播事件）：

- **一步一行**：展示轮次、时间、彩色类型标签与内容摘要；工具行格式为 `做了什么 {参数} → 结果`（失败标红），点击展开全文与工具输入输出。
- **顶部瀑布条**：分收到、模型、工具三道按耗时排列（跳过轮间空闲），点击片段定位到对应行（计算规则见 `apps/web/src/features/session/runs.ts`）。
- **底部合计与搜索**：汇总轮数、步数、模型与工具耗时及 token 用量（含缓存命中）；右上搜索框按标签、正文与工具输入输出过滤。

## 精力瓶与计分

- **精力瓶**（`apps/web/src/farm/hud/Hud.tsx`、`features/runtime/quota.ts`）：液面反映最紧窗口的剩余额度（低于 15% 变红），pi 显示金色余额瓶。
- **计分**：规则见[游戏](docs/subsystems/game.md#模型和不变量)，页面直接展示服务端计算的金币、等级与成就。竖屏布局见[提案](.agents/notes/proposed/feature/2026-10-09-mobile-layout.md)。
