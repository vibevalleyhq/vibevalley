# 农场界面和玩法

农场是一座像素画的小院（`/`）：帮工照手上的事走去书屋、工坊、电台，地里的庄稼按进度长；面板的入口是院子里的小摊、告示板、邮筒这些东西。农场里的东西怎么对上实际的概念见 [concepts.md](docs/concepts.md)「农场是皮」；像素村怎么画、寻路和音效见 [农场的皮](docs/subsystems/farm.md)，素材怎么生成和切见 [开发](docs/development.md#素材音效和官网)。

画风照型号 B「温室花园」（效果图在原图仓库 vibevalley-art，`design/art.sh` 链接进来；[为什么是农场](docs/subsystems/farm.md)）。字体是 Fusion Pixel 12px，字号只用 12 和 24。

## 角色

人是管家：默认管家站在农舍门口，旁边睡着一只宠物；别的管家站在它两边，各是自己档案的长相和心情。默认管家的长相和宠物能换（界面 17）。

其余都是小动物帮工：七种动物（熊、兔子、小狐狸、猫、猫头鹰、刺猬、浣熊），每种四套衣服（农夫、园丁、雨衣、冬装），只是长相，和农机没有固定对应。预置档案的名字、农机和职责见[种子档案](docs/subsystems/agent.md#种子档案)。

## 界面清单

代码注释里的「screen n」指这里的编号。

1. **农场主界面**：左上是管家、农场卡（等级、金币、经验）和「工作台」，右上是地图、频道、精力瓶和菜单，正下方是工具栏，左下是手机和帮工栏；田头在手机里，展开手机就是。一个项目一座农场（`/farm/<项目>`，从「项目」地图上岛的「进岛」进来）：信号塔旁立着项目牌写着是谁的，地里只有这个项目的帮工，点牌子回地图。院子里的东西是面板的入口；按住 ⌥ 写出每样的名字。
2. **工单详情**（点一块地，或看板上的一张卡）：农场和工作台都是居中的弹窗，说的话共用 `apps/web/src/features/issue/state.ts`（状态和能做的事是服务端的 `Issue.attention`，[工单](docs/subsystems/issue.md)「给主人看的状态」），农场画 `apps/web/src/farm/issue/IssueView.tsx`，工作台画 `apps/web/src/features/issue/IssueDetail.tsx`；工作台的弹窗跟着地址 `/issues/<id>` 开，Esc、✕ 或点背景关上，看板留在后面。从上到下回答主人的六个问题，第一屏答完前四个：**这是什么**：`#号` 和一行的短标题（太长的取第一句，`shortTitle`），右边是项目和优先级；**现在怎样**：一行「等你回答 · 已经 3 分钟 · 阿狐 · 跑了 1 轮 · 用了 10 分钟 · ¥0.42」，卡住了是红的；**要你做的**：只在要主人做事时出现，只有一个主按钮：帮工的问题（带选项的是按钮，点一下就是回答，下面可以自己说）、交回来的结论和「验收通过」或「收获」（「打回」展开一个框，一行一棵草）、卡住的原因和「接着修」「让它解决冲突」「接着做」「叫停这一轮」、关上的「重开」；不需要主人时不出现，也没有空的输入框，带话是旁边的一个按钮，点了才有框；**做到哪了**：验收标准逐条，带帮工的自评（做到了、没做到、不确定）和凭据，标题旁是「N / M 条做到了」，等验收时每条前面能打勾（只在这一页）；在做时一行「正在……」；上次打回的草；**做出了什么**：改动（分支、提交数、增删，文件折着），还没有就说「还没有改动」，收获了说合进了哪；**怎么走到这一步**：服务端给的时间线（`issue.timeline.get`），新的在上，下面折着完整说明、帮工的每一步、每次干活。工作台的右栏只放事实：主动作以外的动作（关上、叫停、带话），时间（开单、开工、在等你、验收过、关单）、帮工和模型、验收方式，其余（档案、分支、worktree、用时、拔了的草）收在「更多」里。农场的左栏画庄稼、小动物、地号和轮次，下面几块折着，详情里是工作台右栏的那些；收获在农场打开收成清单，在工作台打开关单对话框。
3. **播种袋**（点农场的空地，或地图上一座岛的空位）：种在哪个项目不在这里选（岛上的就是这座岛的，农场的就是这座农场的项目）：这个项目「最近」派过的、按类分的「常见的活」（服务端照项目的栈填好命令，选中后光标落在第一个〔…〕空上）和「自己写」，再选谁来种：「开始」交给管家马上派活，「草稿」把这句话写成这个项目的一张备选工单、派帮工起草，打开它的详情（[农场](docs/subsystems/farm.md)「播种袋」）。
4. **帮工栏**（左下）：每个帮工的档案一个头像和它农机的体力条，最后一格是「捏帮工」。点一个看它的战绩，可以「下一单派它」。
5. **档案**（`/agents`，[档案和农机](docs/subsystems/agent.md)）：上面是管家，每个一张卡（点开是它的管家页），末尾「添一个管家」；下面是帮工，末尾「捏一个新帮工」。管家的档案页（`/agents/<id>`，新建是 `/agents/new?role=orchestrator`）只有名字、职责、人设、模型和长相，能私聊、能删（默认管家删不了）。**捏帮工**（帮工的 `/agents/:id`）：左边选动物和衣服，中间看在地里的样子，右边填身份、能力、人设、技能、工具和环境；栏目的说明在栏名提示或栏下，农机不接受的选项置灰。底部一直显示服务端 `agentProblems`：红的是派不出去，橙的是提醒。已存档案还有记性和轨迹：记性页签列手上的活、下回开工会想起什么、记下的每一条；接了外部来源时另有「记性从哪来」，标出来源位置，不能忘的没有「忘掉」。点轨迹整页换成这个档案派出的帮工，最近的先打开；「回到档案」返回时没存的改动还在。
6. **商店**：只列着，买不了（[提案](.agents/notes/proposed/feature/2026-10-09-shop-and-daily-tasks.md)）。
7. **仓库**：收获了的工单，每张一格（计划也是一格）。
8. **任务与成就**（`apps/web/src/farm/panels/Achievements.tsx`）：等级、金币、称号，新手任务，开垦，成就墙，彩蛋。
9. **农场日志**：你、管家说的话和帮工的汇报，按时间倒序，最多 80 行。
10. **工单**（`/issues`）：看板，四列：待办、处理中、等你看、已关。拖卡片就是操作：待办拖到处理中是开工，拖到另一张待办上是排先后，拖到已关是关单（等你看的先看收成清单），已关拖回处理中是重开。地满了的标「排队中」，有空地自动开工。待办列底下的「＋ 写一张，回车存下」就是加号：这句话马上成为一张备选工单（帮工和项目照上次选的），帮工照它起草，详情随即打开。备选的卡片标「草稿」，正在起草的标「<帮工>在起草」；派出去的卡片在等主人时标它的状态（等你回答、等你验收、卡住了），和详情、地上说的是同一个；标题是一行的短标题。备选工单的详情第一层是草稿：三段进度轨停在「聊清楚」，一句现在怎样（想做什么 / <帮工>在起草 / 草稿写好了 / 它有几个问题要问你）和它问的（带选项的，点一个就填进输入框），一个输入框（想做什么；有问题时是回答；写好了是再起草时要它改什么），「起草」或「再起草」和「开工」；下面是草稿各栏：标题、说明、验收标准（一行一条）、优先级、验收方式、项目、帮工，都能改，「存下改动」。起草时不能开工。种植计划是一张「计划：…」卡片，点开就在工作台里看它（`apps/web/src/features/issue/TaskDetail.tsx`）：左边是目标、做完几步的进度条，和按能同时做的批次排好的子工单，每一步折成一行（状态、谁做、在等哪一步），点开是它要做的、检查命令和重试、跳过，帮工做过的能打开成自己的工单；右边是开工、暂停、继续、收获（先看改动）、放弃和计划的属性。子工单的详情顶上一行「‹ 计划「…」的一步」回到计划。加步骤、改步骤还在农场的计划板上。点卡片在右边打开同一份工单详情（`issueView`，内容见第 2 项）；每次干活列出触发原因、结果、用时、花费和中途听到几句。派给管家的工单（定时交给管家的）是一张不能拖的卡片：管家在做时在「处理中」，这一轮结束进「等你看」：答完了详情里有「知道了」（关成已完成）和「关上」，没答成只有「关上」；详情里还有要做的和每次干活，回答在它的频道里。
11. **农具**（`/runtimes`，[档案和农机](docs/subsystems/agent.md)）：每台农机一页，列检测结果、账户和额度、能做什么、模型、它自己装的技能和 MCP、工具清单，以及用到它的档案。设置有启用、命令路径、默认模型和思考强度、叠加的环境变量、最多同时干活几个；pi 和 VibeValley 另有每日预算。设置存在 `config.json`，升级不在这里做，要用农机自己的命令（[理由](docs/subsystems/agent.md#为什么这样)）。
12. **项目**（`/projects`，[项目](docs/subsystems/project.md)）：左边是项目列表，最上面一行「全部」；每个项目画成它在地图上的那座岛。选「全部」右边是整张地图（界面 19）；选一个项目，右边先是这座岛：它的地（在做的工单）、空位、排队的活，下面是地契（路径、提交数、行数）、种了什么（语言占比）、耕作日历（一年的提交）、谁来干过活。岛上的「派一件活」和地图上的「写一张工单」马上建一张备选工单（岛上的就在这个项目里）并打开它的详情，输入框问想做什么。「新增项目」可以从 GitHub 下载一个公开仓库，或开一个新的空仓库。
13. **图鉴**（`/catalog`）：农场用的每张图、指针和音效，给画图、调图的人看。三个书架（图、指针、音效）同一个版面：左栏顶上是书架的切换，下面是这个书架的分类或说明；右栏顶上是搜索框，有图块的书架旁边是图块的底色（格子、草地、夜里）。
14. **弹窗和提示**：升级、成就到了一档、服务端的提醒、语音没接通。
15. **收成清单**（收获前）：提交、改的文件和 diff、没提交的、会不会冲突；确认后合进主分支，冲突时是「让它解决冲突」。
16. **田头**（手机展开后的右半屏，[农场的皮](docs/subsystems/farm.md)「田头在手机里」）：上面是频道名和管家的状态，点开频道菜单切频道、开频道、看定时；中间是气泡，派活消息只露一行、点开看整张工单，刚发的话马上淡着显示「发送中」，下面挂着工单串，汇报带「做完了」「没做成」「叫停了」标签，有记下的一轮才多一行「用了几个工具」，每个气泡旁的「⋯」能回应、回复、复制链接、改（自己的）、删；下面是输入框和听写键（打电话在手机的「管家」），打 `@` 叫人（按键的说明在发送键的提示里）；管家在想或在说时多一个停止键，叫停它这一轮。看到的就算读过。**聊天页**（`/chat`）是同一个田头摊开成整页：频道（按分组、能拖动排位，归档的在底下）、私聊（每个管家和帮工的档案）、帮工、消息和串，侧栏顶上是「跳到…」（Ctrl+K）和搜全农场；侧栏底下是照看这处的管家；频道头上能看串、置顶、成员（照看这里的管家在主人下面）和设置（有不止一个管家时能选照看的管家），一条消息的地址是 `/chat/<频道>?m=<号>`。
17. **管家和宠物**（左上角管家的头像）：换默认管家的样子（存进它的档案）和宠物（存在本机的偏好里）；点院子里的管家是展开手机跟它说话。
18. **种植计划**（院子里的图纸桌）：上面是计划列表和「新计划」；选中的计划有目标、分支、进度和按状态变的按钮（开工、暂停、继续、收获、放弃）；下面按先后分列画出每一步，验收步骤标「验收」；最下面是计划的经过。
19. **地图**（`/projects` 的「全部」，[截图](docs/images/map.png)）：工作目录下的每个项目是一座小岛，岛上的地对着它在做的工单和空位（`ProjectSummary.maxSessions`）；农场空着的地不够时，多的位置是锁住的地。排队的活是院门外的种子袋。点帮工打开它的工单，点空位打开种在这个项目的播种袋（界面 3），点岛打开这个项目（`/projects/<项目>`）。
20. **设置**（`/settings/<分区>`）：左边是分区，右边是选中的那一块，切分区时左边不动。服务端的设置：DeepSeek、Agora 语音、记性、GitHub（`gh` 装没装、登没登录，只读，能重新检测）；自带列表的页也在这里：连接器（`/settings/connectors`，[田头](docs/subsystems/channel.md)）、技能（`/settings/skills`，[档案和农机](docs/subsystems/agent.md)）、声音（`/settings/voice`，[语音](docs/subsystems/voice.md)「配置」）、「连接到本机」（`/settings/lan`，[连接到本机](docs/subsystems/lan.md)）。技能页分「这台电脑上装的」（只读）和「VibeValley 自己的」（可编辑）。首页的「设置」和工作台的扳手都进这里；没填 DeepSeek 钥匙就点「开始游戏」，只在首页菜单下提示先填，点「设置」才进这里。
21. **首页**（`apps/web/src/farm/title/`）：背景按打开时的钟点选清晨、白天、黄昏或夜晚，上面叠着会动的云、炊烟、植物和萤火虫，管家和选好的宠物画在场景里。左边是「开始游戏」「继续游戏」「设置」；有农场可回时才能继续，没填 DeepSeek 钥匙时点开始在菜单下提示，点设置才进设置页。什么时候出现和回去见[客户端](docs/subsystems/app.md#怎么走)，固定钟点的方法见[开发](docs/development.md#调试台)。
22. **管家页**（`/orchestrator` 是默认管家的，`/orchestrator/<档案 id>` 是别的）：管家的专门页，不用捏帮工页；头上有「改它的档案」。页签（「声音」只有默认管家有）：「记性」能替它记和忘，带不进系统提示预算的内容变淡；「轨迹」占满内容区，在一轮收到的话上能标「这一轮做错了」；「旧账」能搜压缩时存下的旧对话；「声音」管打电话时的人设、开场白和音色。规则分别见[管家](docs/subsystems/orchestrator.md)和[语音](docs/subsystems/voice.md)。

**工作台**（`apps/web/src/app/Shell.tsx`）：干活和配置的地方，农场是看和玩的地方。最左一条木色的栏：管家头像（回农场）、聊天、工单、文档（`/docs`，[文档](docs/subsystems/doc.md)）、项目、帮工、农具、图鉴；最下面是设置和回农场。农具里每台农机画成一件农机，钉着那家 agent 的 logo（来自 LobeHub Icons）。

## 轨迹

管家页和帮工的档案页的轨迹共用 `apps/web/src/features/session/Trajectory.tsx`：先读日志快照，再合并直播步骤，时长按事件自己的时间算，不另问服务端。

- **一步一行**：左边是轮数和时间，中间是带颜色的标签（收到、想了想、它说、工具名、用量、出错等），右边是这一步的话；工具行写 `做了什么 {参数} → 结果`，参数和结果用代码字体，失败标红。点一行展开全文和工具的输入、输出，再点收起。
- **上面的瀑布**：收到、模型、工具三道按时间排，轮和轮之间的空闲不画。模型一段从这次回应的输入（收到的话或工具结果）到这次回答的用量，没有用量就到它的最后一步；工具一段从调用到结果。点一段跳到对应的一行并标出来；分段时间和合计的规则在 `apps/web/src/features/session/rounds.ts`。
- **下面一行合计**：轮数、步数（不算用量）、模型用时和工具用时总在；有缓存命中数据时才显示缓存命中和输入、输出 token。token 是各条用量的 `tokens` 合计，输入含读缓存的部分。
- **右上的搜索**：只留标签、话、工具输入或输出里有搜索文字的行。页面说明放在标题的提示里。

## 精力瓶

农机的剩余额度画成精力瓶（`apps/web/src/farm/hud/QuotaPill.tsx`，额度怎么说在 `features/runtime/quota.ts`，农具页也用它）：液面是最紧那个窗口还剩多少，剩不到 15% 变红；pi 的瓶子是金色，写余额和今天花了多少。顶栏是所有在用的农机里最紧的一瓶，帮工栏和农具页各有体力条。
