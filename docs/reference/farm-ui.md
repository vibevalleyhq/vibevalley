# 农场界面和玩法

农场是一座像素画的小院（`/`）：帮工照手上的事走去书屋、工坊、电台，地里的庄稼按进度长；面板的入口是院子里的小摊、告示板、邮筒这些东西。农场里的东西怎么对上实际的概念见 [concepts.md](../concepts.md)「农场是皮」；像素村怎么画、寻路、音效和素材见 [pixel-village.md](pixel-village.md)。

画风照型号 B「温室花园」（效果图在原图仓库 vibevalley-art，`design/art.sh` 链接进来；[为什么是农场](../../.agents/notes/implemented/feature/2026-10-09-farm-instead-of-construction-site.md)、[为什么是像素](../../.agents/notes/implemented/feature/2026-10-11-pixel-village.md)）。字体是 Fusion Pixel 12px，字号只用 12 和 24。

## 角色

人只有一个：管家，站在农舍门口，旁边睡着一只宠物。管家和宠物都能换（界面 17）。

其余都是小动物帮工：七种动物（熊、兔子、小狐狸、猫、猫头鹰、刺猬、浣熊），每种四套衣服（农夫、园丁、雨衣、冬装），只是长相，和农机没有固定对应。新农场带着这几个档案（`server/internal/protocol/seeds.json`）：

| 档案 | 农机 | 动物 | 职责 |
|---|---|---|---|
| 后端老周 | pi | 熊 | 写接口、改 server、跑 Go 测试 |
| 测试小吴 | pi | 兔子 | 跑测试、修测试、盯 CI |
| 前端阿郑 | pi | 小狐狸 | 页面、3D 场景、交互动画 |
| 文档员 Kimi | pi | 猫 | 通读文档、写 README、整理说明 |
| 情报 Grok | pi | 猫头鹰 | 查资料、读外部文档、调研方案 |
| 夜班反重力 | pi | 浣熊 | 杂活、小改动、夜里补班 |
| Claude 师傅 | Claude Code | 熊 | 读大代码库、重构、查难缠的 bug |
| Codex 老匠 | Codex | 小狐狸 | 照工单把功能做出来，改到测试通过 |
| Pi 实验员 | pi | 刺猬 | 写原型、试新做法 |

## 地里长什么

6 块地是 6 个帮工的位置，也是同时干活的上限；另有 3 块在 Lv.5、8、12 开垦成花坛（只是外观）。地里长什么、挂什么牌子只看帮工的阶段，服务端的 `PlotOfSession` 算好放进 `StateFrame.view`：

| 帮工 | 地里 | 牌子 |
|---|---|---|
| 到场 | 刚播种 | |
| 干活，还没改文件 | 发芽 | |
| 改过文件 | 长叶 | |
| 改过文件后跑了命令 | 开花 | |
| 很久没动静 | 干裂 | 没动静 |
| 模型调用在重试 | 照常 | 重试中 |
| 做完 | 麦子或胡萝卜 | 可收获，或有冲突 |
| 失败 | 枯萎、有虫 | 有虫 |
| 歇着 | 停在当时的样子 | 歇着，或有冲突 |
| 离开 | 麦茬 | |

帮工的姿势（`poseOf`）跟着手上的事：改文件、跑命令是「干活」，读、搜是「琢磨」，熟了「欢呼」，长虫或干裂「发愁」。干活时它在自己的地四周走动，手上的事一变就走到对应的建筑。

## 工具

正下方一排快捷栏，数字键 1–6 拿起；Esc 放下工具，手上已经是手时打开菜单。指着一块地时，上方的小卡片写着这块地的情况和工具点下去会做什么，用不上就写原因。

| 工具 | 点一块地 |
|---|---|
| 手 | 空地：播种（界面 3）；有帮工：看详情（界面 2） |
| 浇水 | 给帮工带句话 |
| 杀虫 | 失败的地：让它接着修 |
| 除草 | 等你批准的权限请求（[提案已否决](../../.agents/notes/rejected/feature/2026-10-10-permission-requests-as-weeds.md)）；现在只有提示 |
| 收获 | 先开收成清单（界面 15），确认后合进项目。计划里的步骤不在这里收 |
| 铲除 | 干着活就叫停，否则请它收工 |

## 界面清单

代码注释里的「screen n」指这里的编号。

1. **农场主界面**：左上是管家和农场卡（等级、金币、经验），右上是地图、频道、精力瓶和菜单，正下方是工具栏，左下是手机和帮工栏，右下是田头。院子里的东西是面板的入口；按住 ⌥ 写出每样的名字。
2. **田地详情**（点一块有帮工的地）：帮工、农机、模型、花费；项目、分支、worktree、工单；正在做什么、冲突、上一轮的结论；能做的事（接着修、收获、叫停、看工单串、请它收工）和带话的输入框。下面是**干活过程**：按轮排，每轮一条时间条，点开看每一步的输入和输出；指着一步点「评论」，它带着那一步接着做。
3. **播种袋**（点空地）：从最多 8 张种子（你写过的工单、给项目的常用工单）里挑一张或自己写，选谁来种。
4. **帮工栏**（左下）：每个档案一个头像和它农机的体力条，最后一格是「捏帮工」。点一个看它的战绩，可以「下一单派它」。
5. **捏帮工**（`/agents/:id`，[agents-and-runtimes.md](agents-and-runtimes.md)「捏帮工」）。
6. **商店**：只列着，买不了（[提案](../../.agents/notes/proposed/feature/2026-10-09-shop-and-daily-tasks.md)）。
7. **仓库**：收获了的工单，每张一格（计划也是一格）。
8. **任务与成就**（`app/lib/farm/achievements.dart`）：等级、金币、称号，新手任务，开垦，成就墙，彩蛋。
9. **农场日志**：你、管家说的话和帮工的汇报，按时间倒序，最多 80 行。
10. **工单**（`/issues`）：看板，四列：待办、处理中、等你看、已关。拖卡片就是操作：待办拖到处理中是开工，拖到另一张待办上是排先后，拖到已关是关单（等你看的先看收成清单），已关拖回处理中是重开。地满了的标「排队中」，有空地自动开工。种植计划是一张「计划：…」卡片，点开去计划板。点卡片在右边打开详情：谁在做、用时、每次干活（为什么开的、做没做完、用了多久、花了多少、中途听到几句）、改动。派给管家的工单（定时交给管家的）是一张不能拖的卡片：管家在做时在「处理中」，答完进「已关」；详情里是要做的和每次干活，回答在它的频道里。
11. **农具、技能书、连接器**（`/runtimes`、`/skills`、`/connectors`）：见 [agents-and-runtimes.md](agents-and-runtimes.md) 和 [server.md](server.md)「连接器：微信、飞书、QQ」。
12. **项目**（`/projects`，[server.md](server.md)「项目是一块地」）：每个项目一块地，按最近一次提交长成不同的样子。选中的项目有地契（路径、提交数、行数）、种了什么（语言占比）、耕作日历（一年的提交）、谁来干过活。「新增项目」可以从 GitHub 下载一个公开仓库，或开一个新的空仓库。
13. **图鉴**（`/catalog`）：农场用的每张图、指针和音效，给画图、调图的人看。
14. **弹窗和提示**：升级、成就到了一档、服务端的提醒、语音没接通。
15. **收成清单**（收获前）：提交、改的文件和 diff、没提交的、会不会冲突；确认后合进主分支，冲突时是「让它解决冲突」。
16. **田头**（右下角的小窗，不占位置）：上面是频道名和管家的状态，点开频道菜单切频道、开频道、看定时；中间是气泡，派活消息只露一行、点开看整张工单，下面挂着工单串，汇报带「做完了」「没做成」「叫停了」标签，有记下的一轮才多一行「用了几个工具」；下面是输入框和麦克风，打 `@` 叫人（按键的说明在发送键的提示里）；管家在想或在说时多一个停止键，叫停它这一轮。看到的就算读过。**聊天页**（`/chat`）是同一个田头摊开成整页：频道、帮工、消息和串。
17. **管家和宠物**：换管家的样子和宠物，存在本机的偏好里。
18. **种植计划**（院子里的图纸桌）：上面是计划列表和「新计划」；选中的计划有目标、分支、进度和按状态变的按钮（开工、暂停、继续、收获、放弃）；下面按先后分列画出每一步，验收步骤标「验收」；最下面是计划的经过。
19. **地图**（`/map`，[截图](../images/map.png)）：工作目录下的每个项目是一座小岛，岛上的地是它的 worktree 和空位（`ProjectSummary.slots`）；农场空着的地不够时，多的位置是锁住的地。排队的活是院门外的种子袋。点帮工打开它的工单，点空位写一张工单，点岛看这个项目。

**工作台**（`app/lib/workbench/workbench_shell.dart`）：干活和配置的地方，农场是看和玩的地方。最左一条木色的栏：管家头像（回农场）、聊天、工单、地图、帮工、农具、技能书、连接器、项目、声音、院门、图鉴、设置。农具里每台农机画成一件农机，钉着那家 agent 的 logo（来自 LobeHub Icons）。

## 农场手机

左下角的手机（`app/lib/phone/`）：农场有事找你就来电，平时是一部像素风的掌机。

- **来电**读服务端的 `StateFrame.inbox`（[server.md](server.md)「Inbox」）。新来电弹出、响铃，20 秒没理算未接。接听去处理（帮工的打开它的地，计划的打开计划板，@ 你的打开那个对话），挂断是先放着。那件事在别处处理掉了，来电自己停。
- **主屏**：未接、记录、打给管家（语音）、频道、计划，和几个小游戏（方块、推箱子、小恐龙、贪吃虫、种田 2048）。游戏的规则是 `lib/phone/` 里的纯函数，最好成绩只记在这次打开里。

## 精力瓶

农机的剩余额度画成精力瓶（`app/lib/ui/kit/energy.dart`）：液面是最紧那个窗口还剩多少，剩不到 15% 变红；pi 的瓶子是金色，写余额和今天花了多少。顶栏是所有在用的农机里最紧的一瓶，帮工栏和农具页各有体力条。

## 计分

金币、连胜、成就奖的是**收进主分支的活**，不是命令数或花掉的 token（[理由](../../.agents/notes/implemented/feature/2026-10-11-achievements.md)）。它们由服务端的账本折出来（`server/internal/game/progress.go`），客户端只显示。回报只是金币和称号，不改变帮工怎么干活。

| 机制 | 规则 |
|---|---|
| 金币 | 一个帮工的活收进主分支：`(30 + min(提交数 × 5, 30)) × 连胜倍率`。收获一个种植计划：`30 + 10 × 合进去的步数`。新手任务每个 20；成就的铜、银、金档各 10、30、60；彩蛋 50（`seeds.json` 的 `achievements`） |
| 连胜 | 连着收进去的活，倍率每件 +10%，最多 ×2；有帮工没做成就清零 |
| 经验 | 工作目录下所有 git 仓库里你名下的 commit（[理由](../../.agents/notes/implemented/feature/2026-10-10-experience-is-commits.md)）；邮箱按 git 的 user.email 加配置的 `git_emails` |
| 等级 | 从 Lv.n 升到 Lv.n+1 要 `10n` 个 commit；Lv.5、8、12 各开垦一块地 |
| 成就 | 见下表；计数的分铜、银、金三档 |
| 称号 | 拿到的任何一档（新手任务除外）都能挂在农场卡上 |

| 类 | 成就 | 怎么算 | 档位 |
|---|---|---|---|
| 新手任务 | 开门、派活、带话、验收、说话、规划、点名 | 开工；派出第一个帮工；给帮工带话；看过收成清单再收获；用语音说话；拆一张计划；在田头 @ 一个帮工 | 一次 |
| 收成 | 开张大吉 → 小有收成 → 粮仓满了 | 收进主分支的活 | 1 / 20 / 100 |
| | 一气呵成 | 第一轮就做完、没带过话、没失败过就收进去的活 | 1 / 10 / 50 |
| | 五谷丰登 | 收获的计划里合进去步数最多的一张 | 3 / 5 / 10 |
| | 小有规模 → 远近闻名 → 一方粮仓 | 农场等级 | 5 / 10 / 20 |
| 手艺 | 稳如老农 | 最长连胜 | 5 / 15 / 40 |
| | 解铃人 | 冲突过、最后收进去的活 | 1 / 5 / 20 |
| | 浴火重生 | 没做成过、最后收进去的活 | 1 / 5 / 20 |
| 精打细算 | 一分钱一分货 | 花不到 ¥0.05 收进去的活 | 1 / 10 / 50 |
| | 物尽其用 | 收进过活的农机种数 | 2 / 3 / 5 |
| 协作 | 交接 | 帮工点名另一个帮工，对方回了话 | 1 / 5 / 20 |
| | 运筹帷幄 | 有一批步骤同时做的计划，收获了 | 1 / 3 / 10 |
| 彩蛋 | 夜猫子、周末农夫、满园春色 | 0–5 点收进一件活；周末收进一件活；六块地同时有人干活 | 一次 |

手机屏幕上整张农场按比例缩小，竖屏布局见[提案](../../.agents/notes/proposed/feature/2026-10-09-mobile-layout.md)。
