# 农场界面和玩法

农场是一座像素画的小院（`/`）：帮工照手上的事走去书屋、工坊、电台，地里的庄稼按进度长；面板的入口是院子里的小摊、告示板、邮筒这些东西。农场里的东西怎么对上实际的概念见 [concepts.md](docs/concepts.md)「农场是皮」；像素村怎么画、寻路、音效和素材见 [pixel-village.md](docs/reference/pixel-village.md)。

画风照型号 B「温室花园」（效果图在原图仓库 vibevalley-art，`design/art.sh` 链接进来；[为什么是农场](docs/subsystems/farm.md)）。字体是 Fusion Pixel 12px，字号只用 12 和 24。

## 角色

人只有一个：管家，站在农舍门口，旁边睡着一只宠物。管家和宠物都能换（界面 17）。

其余都是小动物帮工：七种动物（熊、兔子、小狐狸、猫、猫头鹰、刺猬、浣熊），每种四套衣服（农夫、园丁、雨衣、冬装），只是长相，和农机没有固定对应。新农场带着这几个档案（`apps/server/src/agent/seeds.json`）：

| 档案 | 农机 | 动物 | 职责 |
|---|---|---|---|
| 后端老周 | pi | 熊 | 写接口、改 server、跑 Go 测试 |
| 测试小吴 | pi | 兔子 | 跑测试、修测试、盯 CI |
| 前端阿郑 | pi | 小狐狸 | 页面、3D 场景、交互动画 |
| 文档员 Kimi | pi | 猫 | 通读文档、写 README、整理说明 |

## 界面清单

代码注释里的「screen n」指这里的编号。

1. **农场主界面**：左上是管家、农场卡（等级、金币、经验）和「工作台」，右上是地图、频道、精力瓶和菜单，正下方是工具栏，左下是手机和帮工栏，右下是田头。一个项目一座农场（`/farm/<项目>`，从「项目」地图上岛的「进岛」进来）：信号塔旁立着项目牌写着是谁的，地里只有这个项目的帮工，点牌子回地图。院子里的东西是面板的入口；按住 ⌥ 写出每样的名字。
2. **工单详情**（点一块地，或看板上的一张卡）：农场和工作台都是居中的弹窗，说的话共用 `apps/web/src/rules/issueState.ts`（状态和能做的事是服务端的 `Issue.standing`，[工单](docs/subsystems/issue.md)「给主人看的状态」），农场画 `apps/web/src/farm/issue/IssueView.tsx`，工作台画 `apps/web/src/pages/issues/IssueDetail.tsx`；工作台的弹窗跟着地址 `/issues/<id>` 开，Esc、✕ 或点背景关上，看板留在后面。从上到下回答主人的六个问题，第一屏答完前四个：**这是什么**：`#号` 和一行的短标题（太长的取第一句，`shortTitle`），右边是项目和优先级；**现在怎样**：一行「等你回答 · 已经 3 分钟 · 阿狐 · 跑了 1 轮 · 用了 10 分钟 · ¥0.42」，卡住了是红的；**要你做的**：只在要主人做事时出现，只有一个主按钮：帮工的问题（带选项的是按钮，点一下就是回答，下面可以自己说）、交回来的结论和「验收通过」或「收获」（「打回」展开一个框，一行一棵草）、卡住的原因和「接着修」「让它解决冲突」「接着做」「叫停这一轮」、关上的「重开」；不需要主人时不出现，也没有空的输入框，带话是旁边的一个按钮，点了才有框；**做到哪了**：验收标准逐条，带帮工的自评（做到了、没做到、不确定）和凭据，标题旁是「N / M 条做到了」，等验收时每条前面能打勾（只在这一页）；在做时一行「正在……」；上次打回的草；**做出了什么**：改动（分支、提交数、增删，文件折着），还没有就说「还没有改动」，收获了说合进了哪；**怎么走到这一步**：服务端给的时间线（`issue.timeline`），新的在上，下面折着完整说明、帮工的每一步、每次干活。工作台的右栏只放事实：主动作以外的动作（关上、叫停、带话），时间（开单、开工、在等你、验收过、关单）、帮工和模型、验收方式，其余（档案、分支、worktree、用时、拔了的草）收在「更多」里。农场的左栏画庄稼、小动物、地号和轮次，下面几块折着，详情里是工作台右栏的那些；收获在农场打开收成清单，在工作台打开关单对话框。
3. **播种袋**（点农场的空地，或地图上一座岛的空位）：种在哪个项目不在这里选（岛上的就是这座岛的，农场的就是这座农场的项目）：这个项目「最近」派过的、按类分的「常见的活」（服务端照项目的栈填好命令，选中后光标落在第一个〔…〕空上）和「自己写」，再选谁来种：「开始」交给管家马上派活，「草稿」把这句话写成这个项目的一张备选工单、派帮工起草，打开它的详情（[农场](docs/subsystems/farm.md)「播种袋」）。
4. **帮工栏**（左下）：每个档案一个头像和它农机的体力条，最后一格是「捏帮工」。点一个看它的战绩，可以「下一单派它」。
5. **捏帮工**（`/agents/:id`，[agents-and-runtimes.md](docs/reference/agents-and-runtimes.md)「捏帮工」）。
6. **商店**：只列着，买不了（[提案](.agents/notes/proposed/feature/2026-10-09-shop-and-daily-tasks.md)）。
7. **仓库**：收获了的工单，每张一格（计划也是一格）。
8. **任务与成就**（`apps/web/src/farm/panels/Achievements.tsx`）：等级、金币、称号，新手任务，开垦，成就墙，彩蛋。
9. **农场日志**：你、管家说的话和帮工的汇报，按时间倒序，最多 80 行。
10. **工单**（`/issues`）：看板，四列：待办、处理中、等你看、已关。拖卡片就是操作：待办拖到处理中是开工，拖到另一张待办上是排先后，拖到已关是关单（等你看的先看收成清单），已关拖回处理中是重开。地满了的标「排队中」，有空地自动开工。待办列底下的「＋ 写一张，回车存下」就是加号：这句话马上成为一张备选工单（帮工和项目照上次选的），帮工照它起草，详情随即打开。备选的卡片标「草稿」，正在起草的标「<帮工>在起草」；派出去的卡片在等主人时标它的状态（等你回答、等你验收、卡住了），和详情、地上说的是同一个；标题是一行的短标题。备选工单的详情第一层是草稿：三段进度轨停在「聊清楚」，一句现在怎样（想做什么 / <帮工>在起草 / 草稿写好了 / 它有几个问题要问你）和它问的（带选项的，点一个就填进输入框），一个输入框（想做什么；有问题时是回答；写好了是再起草时要它改什么），「起草」或「再起草」和「开工」；下面是草稿各栏：标题、说明、验收标准（一行一条）、优先级、验收方式、项目、帮工，都能改，「存下改动」。起草时不能开工。种植计划是一张「计划：…」卡片，点开就在工作台里看它（`apps/web/src/pages/issues/TaskDetail.tsx`）：左边是目标、做完几步的进度条，和按能同时做的批次排好的子工单，每一步折成一行（状态、谁做、在等哪一步），点开是它要做的、检查命令和重试、跳过，帮工做过的能打开成自己的工单；右边是开工、暂停、继续、收获（先看改动）、放弃和计划的属性。子工单的详情顶上一行「‹ 计划「…」的一步」回到计划。加步骤、改步骤还在农场的计划板上。点卡片在右边打开同一份工单详情（`issueView`，内容见第 2 项）；每次干活列出触发原因、结果、用时、花费和中途听到几句。派给管家的工单（定时交给管家的）是一张不能拖的卡片：管家在做时在「处理中」，这一轮结束进「等你看」：答完了详情里有「知道了」（关成已完成）和「关上」，没答成只有「关上」；详情里还有要做的和每次干活，回答在它的频道里。
11. **农具**（`/runtimes`）：见 [agents-and-runtimes.md](docs/reference/agents-and-runtimes.md)。
12. **项目**（`/projects`，[项目](docs/subsystems/project.md)）：左边是项目列表，最上面一行「全部」；每个项目画成它在地图上的那座岛。选「全部」右边是整张地图（界面 19）；选一个项目，右边先是这座岛：它的地（在做的工单）、空位、排队的活，下面是地契（路径、提交数、行数）、种了什么（语言占比）、耕作日历（一年的提交）、谁来干过活。岛上的「派一件活」和地图上的「写一张工单」马上建一张备选工单（岛上的就在这个项目里）并打开它的详情，输入框问想做什么。「新增项目」可以从 GitHub 下载一个公开仓库，或开一个新的空仓库。
13. **图鉴**（`/catalog`）：农场用的每张图、指针和音效，给画图、调图的人看。三个书架（图、指针、音效）同一个版面：左栏顶上是书架的切换，下面是这个书架的分类或说明；右栏顶上是搜索框，有图块的书架旁边是图块的底色（格子、草地、夜里）。
14. **弹窗和提示**：升级、成就到了一档、服务端的提醒、语音没接通。
15. **收成清单**（收获前）：提交、改的文件和 diff、没提交的、会不会冲突；确认后合进主分支，冲突时是「让它解决冲突」。
16. **田头**（右下角的小窗，不占位置）：上面是频道名和管家的状态，点开频道菜单切频道、开频道、看定时；中间是气泡，派活消息只露一行、点开看整张工单，下面挂着工单串，汇报带「做完了」「没做成」「叫停了」标签，有记下的一轮才多一行「用了几个工具」；下面是输入框和麦克风，打 `@` 叫人（按键的说明在发送键的提示里）；管家在想或在说时多一个停止键，叫停它这一轮。看到的就算读过。**聊天页**（`/chat`）是同一个田头摊开成整页：频道、帮工、消息和串。
17. **管家和宠物**：换管家的样子和宠物，存在本机的偏好里。
18. **种植计划**（院子里的图纸桌）：上面是计划列表和「新计划」；选中的计划有目标、分支、进度和按状态变的按钮（开工、暂停、继续、收获、放弃）；下面按先后分列画出每一步，验收步骤标「验收」；最下面是计划的经过。
19. **地图**（`/projects` 的「全部」，[截图](docs/images/map.png)）：工作目录下的每个项目是一座小岛，岛上的地是它在做的工单（每张一个 worktree）和空位（`ProjectSummary.maxSessions`）；农场空着的地不够时，多的位置是锁住的地。排队的活是院门外的种子袋。点帮工打开它的工单，点空位打开种在这个项目的播种袋（界面 3），点岛打开这个项目（`/projects/<项目>`）。
20. **设置**（`/settings/<分区>`）：左边是分区，右边是选中的那一块，切分区时左边不动。服务端的设置：DeepSeek、Agora 语音、记性、GitHub（`gh` 装没装、登没登录，只读，能重新检测）；自带列表的页也在这里：连接器（`/settings/connectors`，[田头](docs/subsystems/channel.md)）、技能（`/settings/skills`，[agents-and-runtimes.md](docs/reference/agents-and-runtimes.md)「技能书」）、声音（`/settings/voice`，[语音](docs/subsystems/voice.md)「配置」）、「连接到本机」（`/settings/lan`，[连接到本机](docs/subsystems/lan.md)）。首页的「设置」和工作台的扳手都进这里；没填 DeepSeek 钥匙就点「开始游戏」，会进 DeepSeek 这一块并提示先填。

**工作台**（`apps/web/src/app/Shell.tsx`）：干活和配置的地方，农场是看和玩的地方。最左一条木色的栏：管家头像（回农场）、聊天、工单、文档（`/docs`，[文档](docs/subsystems/doc.md)）、项目、帮工、农具、图鉴；最下面是设置和回农场。农具里每台农机画成一件农机，钉着那家 agent 的 logo（来自 LobeHub Icons）。

## 精力瓶

农机的剩余额度画成精力瓶（`apps/web/src/farm/hud/QuotaPill.tsx`，规则在 `farm/hud/rules.ts`）：液面是最紧那个窗口还剩多少，剩不到 15% 变红；pi 的瓶子是金色，写余额和今天花了多少。顶栏是所有在用的农机里最紧的一瓶，帮工栏和农具页各有体力条。

## 计分

金币、连胜、成就奖的是**收进主分支的活**，不是命令数或花掉的 token（[理由](docs/subsystems/game.md)）。它们由服务端的账本折出来（`apps/server/src/game/progress.ts`），页面只显示。回报只是金币和称号，不改变帮工怎么干活。

| 机制 | 规则 |
|---|---|
| 金币 | 一个帮工的活收进主分支：`(30 + min(提交数 × 5, 30)) × 连胜倍率`。收获一个种植计划：`30 + 10 × 合进去的步数`。新手任务每个 20；成就的铜、银、金档各 10、30、60；彩蛋 50（`seeds.json` 的 `achievements`） |
| 连胜 | 连着收进去的活，倍率每件 +10%，最多 ×2；有帮工没做成就清零 |
| 经验 | 工作目录下所有 git 仓库里你名下的 commit（[理由](docs/subsystems/game.md)）；邮箱按 git 的 user.email 加配置的 `git_emails` |
| 等级 | 从 Lv.n 升到 Lv.n+1 要 `10n` 个 commit；Lv.5、8、12 各开垦一块地 |
| 成就 | 见下表；计数的分铜、银、金三档 |
| 称号 | 拿到的任何一档（新手任务除外）都能挂在农场卡上 |

| 类 | 成就 | 怎么算 | 档位 |
|---|---|---|---|
| 新手任务 | 开门、派活、带话、验收、说话、规划、点名 | 开工；派出第一个帮工；给帮工带话；看过收成清单再收获；用语音说话；拆一张计划；在田头 @ 一个帮工 | 一次 |
| 收成 | 开张大吉 → 小有收成 → 粮仓满了 | 收进主分支的活 | 1 / 20 / 100 |
| | 一气呵成 | 第一轮就做完、没带过话、没失败过就收进去的活 | 1 / 10 / 50 |
| | 五谷丰登 | 收获的计划里合进去步数最多的一张 | 3 / 5 / 10 |
| | 小有规模 → 远近闻名 → 一方粮仓 | 农场等级 | 5 / 10 / 20 |
| 手艺 | 稳如老农 | 最长连胜 | 5 / 15 / 40 |
| | 解铃人 | 冲突过、最后收进去的活 | 1 / 5 / 20 |
| | 浴火重生 | 没做成过、最后收进去的活 | 1 / 5 / 20 |
| 精打细算 | 一分钱一分货 | 花不到 ¥0.05 收进去的活 | 1 / 10 / 50 |
| | 物尽其用 | 收进过活的农机种数 | 2 / 3 / 5 |
| 协作 | 交接 | 帮工点名另一个帮工，对方回了话 | 1 / 5 / 20 |
| | 运筹帷幄 | 有一批步骤同时做的计划，收获了 | 1 / 3 / 10 |
| 彩蛋 | 夜猫子、周末农夫、满园春色 | 0–5 点收进一件活；周末收进一件活；六块地同时有人干活 | 一次 |

手机屏幕上整张农场按比例缩小，竖屏布局见[提案](.agents/notes/proposed/feature/2026-10-09-mobile-layout.md)。
