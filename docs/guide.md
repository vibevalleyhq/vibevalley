# 使用指南

从打开农场走到收下第一份活。界面细节见 [farm-ui.md](docs/reference/farm-ui.md)，叫法见[用语](docs/README.md#用语)。

## 开始之前

- 打开 macOS 应用（[客户端](docs/subsystems/app.md)），服务端在里面；或者在终端里跑服务端，再用 Flutter 客户端连上（[development.md](docs/development.md)「跑起来」）。
- 管家要 DeepSeek 的钥匙：「设置」的 DeepSeek 里填（首页点「设置」或工作台左下的扳手），或者本机的 pi 已经配好。帮工用本机登录好的农机（pi、Claude Code、codex……），在「农具」页启用。
- 项目放在工作目录的 `projects/` 下，一个文件夹一个；没有的管家会建。macOS 应用的工作目录是 `~/vibevalley`（Beta 是 `~/vibevalley-beta`，Alpha 是 `~/vibevalley-alpha`），终端里跑的服务端是 `~/vibevalley-dev`。

## 1. 派第一张工单

在右下角的田头里对管家说要做什么，说清在哪个项目、做到什么程度算完：

> 在 clock-in 项目里加一个查询打卡记录的接口，写测试。

管家挑一个帮工（你点了名就是它，否则按档案「适合的活」挑，见 [agents-and-runtimes.md](docs/reference/agents-and-runtimes.md)「派给谁」），给它开一个分支和 worktree，在田头发一条派活消息，下面挂着这件活的工单串。派不出去时它会说原因：地满了、项目到了上限、余额或预算用完、档案停用。

也可以在「工单」页写一张拖到「处理中」，或者点一块空地从播种袋里挑。

## 2. 看着它干

帮工走到一块地，地里发芽、长叶、开花；它读代码去书屋、跑命令去工坊。这块地就是这张工单。点它（或数字键 1）打开详情，下面是**干活过程**（默认折成一行，展开看每一轮的话、命令和输出）。哪里没做好，用浇水带一句话，它接着做。

## 3. 收获

做完一轮，地里结出麦子或胡萝卜，帮工在工单串里汇报。用「收获」（数字键 5）点这块地，先看**收成清单**：提交、改的文件和 diff、没提交的、会不会冲突。确认后工单的分支合进主分支（开了 PR 的项目是推分支、开 PR），帮工收工，工单进「仓库」。也可以对管家说「收下老周的活」。

**会冲突时**不合并，地上挂「有冲突」。点「让它解决冲突」，它在自己的分支上把主分支合进来、解决、跑测试、提交，之后再收一次。

## 4. 出了问题

| 你看到 | 是什么 | 怎么办 |
|---|---|---|
| 地里长虫，挂「有虫」 | 这一轮失败了，管家会说原因 | 「杀虫」（数字键 3）让它接着修，或请它收工 |
| 地干裂，挂「没动静」 | 4 分钟没有任何动静 | 看干活过程；卡住了就「铲除」叫停 |
| 挂「重试中」 | 农机在自动重试 | 不用管 |
| 红色提醒 | 要你处理：登录、充值、换模型 | 照做 |

## 5. 中途改主意

- **带话**：在工单串里说一句，或「浇水」（数字键 2）。它在干活时话在下一步之前送到，歇着时接着干一轮。
- **叫停**：「铲除」点正在干活的地；带句话就接着干。
- **请它收工**：「铲除」点不在干活的地。没合的提交留在它的分支上。

## 6. 在田头说话

没 @ 人的话给管家；`@w3` 叫的就是那个帮工，管家不插嘴。帮工之间也能 @，来回几次后停下等你。一个帮工老是叫不醒时，农场在它的串里提醒一句，等你亲自对它说。

## 7. 种植计划

一轮做不完的活，拆成种植计划：

1. 对管家说「拆成种植计划」，或在院子里的图纸桌点「新计划」，写要做什么、在哪个项目，点「拆计划」。
2. 拆好后打开看：几步分成几列，一列里的可以同时做；每步的工单、谁来做、跑什么检查都能改。看好了点「开工」。
3. 每步做完、检查过、合进计划分支，后面的才开工。一步没做成，农场自己重来两次，还不行就停下等你重试、改了再试或跳过。
4. 全做完挂「可收获」，看整条计划分支的改动，一次合进主分支。

## 8. 钱和额度

顶栏的精力瓶是在用的农机里最紧的那个；pi 的是 DeepSeek 余额。花费在地块详情、工单看板和汇报里。「农具」→ pi 可以设**每日预算**和**最多同时干活**：到了预算或余额用完，不再派新活，正在干的干完。

## 9. 用语音

服务端配好 Agora 的凭据后（[语音](docs/subsystems/voice.md)「凭据」），按田头窗口里的麦克风说话；说的活交给管家，和打字一样。

## 10. 服务端重启之后

帮工还在各自的地上，正在干的那一轮记成「停在了半路」；带句话就接着原来的会话干。

## 11. 在手机或另一台电脑上用

1. 在跑农场的电脑上打开「连接到本机」页，「允许连接」，「添加设备」，出现二维码和链接（2 分钟有效）。
2. 手机上进「连接到本机」扫码；另一台 Mac 上进「连接到本机」粘贴链接。
3. 回到这台电脑点「让它进来」。

这台电脑换了网络以后，再「添加设备」扫一次。App 关着时要收到汇报，在「连接器」里连上微信或飞书。

## 安全须知

帮工没有权限确认、不开沙箱，能在这台机器上执行任意命令；它们只在工作目录里开工，服务端只听 127.0.0.1。「连接到本机」不加密，只在信得过的网络里开（[连接到本机](docs/subsystems/gate.md)）。
