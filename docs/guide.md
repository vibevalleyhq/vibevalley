# 使用指南

这篇带你从打开农场走到收下第一份活：派活、看着它干、收获、处理冲突和失败、管住花费。界面上每个东西的细节见 [game-ui.md](game-ui.md)，农场里的叫法见 [用语](README.md#用语)。

## 开始之前

- 装了 macOS 应用（`vibevalley.app`，[desktop.md](desktop.md)「打包和安装」）就直接打开它：服务端在里面，关掉窗口农场还在菜单栏里跑。
- 或者在终端里把服务端跑起来，再用 Flutter 客户端连上（[development.md](development.md)「跑起来」）。服务端没开时客户端会说连不上。
- 管家要 DeepSeek 的钥匙：首页「设置」里填，或者本机的 pi 已经配好 DeepSeek。帮工用本机登录好的农机（pi、Claude Code、codex），在农具房启用它们。
- 你的项目放在工作目录（默认 `~/vibevalley-work`）下，一个文件夹一个项目。没有也行，管家会帮你建。

## 1. 派第一张工单

在右下角的田头（农场的群聊）里对管家说要做什么，说清楚在哪个项目、做到什么程度算完：

> 在 clock-in 项目里加一个查询打卡记录的接口，写测试。

第一次说话时农场自动开工。管家会：

1. 挑一个帮工。你点了名（「让测试小吴……」）就是它；在窗口里选了「下一单派它」就优先它；否则按每个帮工「适合的活」挑（[agents-and-runtimes.md](agents-and-runtimes.md)「派给谁」）。
2. 在项目里给它开一个自己的分支（`vibevalley/w1-…`）和 worktree。项目不存在就新建一个 git 仓库。
3. 在田头发一条派活消息，下面挂着这件活的工单串，再回你一句「派了谁去哪」。

派不出去时，管家会照直说原因：地里满了、这个项目同时干活的人到了上限、DeepSeek 余额或今天的预算用完了、帮工档案停用了。

也可以点一块空地：播种袋里挑一张种子（你以前派过的工单，或给你的项目的常用工单）或自己写，选谁来种，下一个到场的帮工就种在这块地上。

## 2. 看着它干

帮工从大门走到一块地，地里播下种子，前沿插一块木牌写着项目和分支。

- 它读代码、思考时站在地边，改文件、跑命令时在地前干活；地里发芽、长叶、开花。
- 头上的小图标是它此刻在做什么，指着它看完整的动作和对象（比如 `pnpm test`）；名牌下面是它用的农机还剩多少精力。
- 点这块地（手、或数字键 1）打开详情：工单、它正在做什么、一共花了多少，下面是**干活过程**，一轮一轮排：你说的话、一条时间条（看时间花在哪），和它这一轮每一条命令、输出（点开看）、说的话。哪一步没做好，点它下面的「评论这一步」写一句，它会带着那一步接着做。

## 3. 它做完了

地里长出麦子或胡萝卜，挂「可收获」。帮工自己在它的工单串里汇报：做成了什么、怎么验证的、这一轮花了多少；田头上那条派活消息下面会显示有新回复。没做成时管家会出来说卡在哪、问你下一步。结论也记进左边的「日志」；收获进主分支以后，这张工单放进「仓库」。它的原话在地块详情的干活过程里。

## 4. 收获

用「收获」（数字键 5）点这块地，或在详情里点「收获…」，先打开**收成清单**：

- 它的提交、改了哪些文件和加减行数，点文件看 diff；
- 还没提交的文件（收获时会替它提交）；
- 这期间主分支多了几个提交；
- 会不会冲突。

确认后点「确认收获，合进 main」：它的分支合进项目的主分支，worktree 和分支删掉，帮工收工离开。它什么都没改时，按钮是「请它收工」。

也可以直接对管家说「收下老周的活」，或者问「老周改了什么」。

## 5. 会冲突时

两个帮工改了同一个文件，后收的那个会冲突：收成清单上是一块红色说明，地牌下挂红色「冲突」，地上挂「有冲突」。这时不会合并，主分支不受影响。

点「让它解决冲突」：帮工收到一句话，在自己的分支上把主分支合进来、解决冲突、跑测试、提交，并在结论里说怎么取舍的。它做完后冲突标记自动去掉，再收获一次。

## 6. 出了问题

| 你看到 | 是什么 | 怎么办 |
|---|---|---|
| 地里枯萎、长虫，挂「有虫」 | 这一轮失败了；管家会说是什么问题（限流、余额不够、登录有问题……） | 「杀虫」（数字键 3）让它看报错接着修；或者请它收工 |
| 地干裂，挂「没动静」 | 一轮里 4 分钟没有任何动静 | 打开详情看干活过程；在跑很久的命令就等等，卡住了就「铲除」叫停 |
| 挂「重试中」 | 模型调用失败，农机在自动重试 | 一般不用管 |
| 一条红色提醒 | 要你处理的事：登录、充值、换模型 | 照提醒去做 |

## 7. 中途改主意

- **带话**：在它的工单串里说一句，或者「浇水」（数字键 2）、详情里的输入框（这两个也记在串里）。它正在干活时，话在下一步之前送到；歇着时，它接着干一轮。在田头上 `@w1 顺便把错误码写上` 也一样，只是叫醒的是它、不是管家。
- **叫停**：「铲除」点正在干活的地，这一轮停下，帮工歇着，带句话就接着干。
- **请它收工**：「铲除」点不在干活的地，或详情里的「请它收工」。它分支上有没合的提交就留着，做过的东西不会丢。
- **大家收工**：对管家说「大家收工」。

## 8. 在田头上和帮工说话

田头是一个群聊：你、管家和地里的帮工都在里面。

- **叫谁**：输入框里打 `@`，选一个帮工（`@w3`）、管家或所有人。田头上没 @ 人的话给管家；@ 了谁，叫醒的就是谁，管家不插嘴（要两个都叫，就都 @ 上）。
- **工单串**：每件活一个串。帮工在里面确认、提问、汇报，你在里面追问；你在串里说的话会叫醒这个帮工。
- **帮工之间**：帮工也能在田头上说话、互相 @，交接时用得上。它们之间来回几次以后会停下来等你说一句，所以不会自己聊个没完。
- **一个帮工老是叫不醒**（比如它的农机登录失效了），农场在它的串里提醒一句，不再自动叫它；你亲自对它说一句就会再试。

## 9. 很长的活：种植计划

一件要改好几处、一轮做不完的活，交给一个帮工容易越做越乱。拆成一张种植计划：

1. 对管家说「把这件事拆成种植计划」，或者在左边「计划」里点「＋ 新计划」，写要做什么、在哪个项目。农场派一个帮工读代码，把它拆成几步，每步一个帮工，有先后。
2. 拆好了，「计划」上挂一个角标。打开看：几步分成几列，一列里的可以同时做。每一步的工单、谁来做、做完跑什么检查，都可以改，也可以加步骤、删步骤。看好了点「开工」。
3. 开工以后农场自己调度：前面的步骤做完、检查过了、合进计划分支，后面的才开工，所以后面的帮工看得到前面的代码。地牌上写着「计划 p1 · api」。计划里的帮工不用你一个个收。
4. 有一步没做成，农场先自己让它重来两次，还不行就停下等你：重试、改了工单再试，或者跳过。不相干的步骤照做。
5. 全做完了挂「可收获」：点「看改动，收获…」，看整条计划分支改了什么，确认后一次合进主分支。

中途可以暂停（正在做的做完）、继续，或者放弃（分支留着）。也可以都对管家说：「计划开工」「p1 跳过 docs 那步」「收下计划」。

## 10. 钱和额度

- 顶栏的精力瓶是在用的农机里最紧的那个；pi 的瓶子是 DeepSeek 的余额，点开看今天花了多少。
- 每个帮工、每一轮花了多少，在详情和仓库里（按 pi 的价目表估算的人民币）。
- 在农具房（左边「农具房」→「农具」→ pi）可以设**每日预算**和**最多同时干活**：到了预算，或余额用完，管家不再派新活，正在干的干完。

## 11. 用语音

服务端配好 Agora 的凭据后（[voice.md](voice.md)「怎么跑」），按田头窗口里的麦克风就能说话。语音里回答你的是 Agora 托管的大模型；你说的活会交给管家派到农场上，和打字一样。

## 12. 服务端重启之后

帮工都还在各自的地上，正在干的那一轮记成「停在了半路」，帮工歇着；给它带句话就接着原来的会话干。田头、工单、仓库、日志都在；交给帮工、它还没来得及看的话，下次叫醒它时再给一遍。

## 13. 在手机或另一台电脑上用

1. 在跑着农场的这台电脑上，打开「院门」页，点「打开院门」，再点「添加设备」。页面上出现一个二维码和一个链接，2 分钟内有效。
2. 手机上打开 VibeValley，进「院门」点「扫码」，扫这个二维码；另一台 Mac 上打开 VibeValley，进「院门」，把链接粘贴进去，点「连接」。
3. 回到这台电脑，页面上会问「某某想进院门」，点「让它进来」。那台设备马上就在用这个农场了。
4. 不想让某台设备再进来，在「配对过的设备」里点「移除」。

手机上的 VibeValley 不在屏幕前时，帮工做完活、没做成、叫你，会弹系统通知；点一下就打开那件事。安卓在后台会一直连着农场，通知栏里有一条「VibeValley 连着农场」；iPhone 离开屏幕一会儿就收不到了。要在 App 关着时也收到，在「连接器」里连上微信或飞书，汇报会发到那里。

这台电脑换了网络（地址变了）以后，那台设备会连不上：在这台电脑上再「添加设备」，让它扫一次就好，不用再点头。

## 14. 工单看板

每块地上的一次种植就是一张工单：从播种，一轮一轮做，到收获。工作台左栏的「工单」是一块看板，四列：待办、处理中、等你看、已关。

- 想到要做的，在「待办」那一列顶上打一行字、回车，就记下了；要选项目、帮工、优先级，点「详细写」。待办上下拖可以排先后。想做了就把卡片拖到「处理中」，帮工就派出去了。
- 顶上可以找工单、按项目或帮工筛。
- 帮工做完或没做成，卡片到「等你看」。点开看干活过程，哪一步不对就评论那一步；满意了拖到「已关」，看过收成清单就收获，不要了就选「不收，直接收工」。
- 收获以后发现还有问题，把「已关」里的卡片拖回「处理中」，写一句这次要做什么，同一个帮工档案会派一个新帮工接着做。

手机上长按卡片再拖。

## 安全须知

帮工没有权限确认、不开沙箱，能在这台机器上执行任意命令。VibeValley 只让它们在工作目录里开工，每人一个分支；服务端只听本机（127.0.0.1），不要把它暴露到网络上。要在手机或另一台电脑上用，打开「院门」，只让你自己的设备配对；院门不加密，只在家里的 Wi-Fi、自己的热点这类信得过的网络里开（[server.md](server.md)「院门」）。

## 农场和 VibeValley 的对照

| 农场里 | VibeValley 里 |
|---|---|
| 管家 | 你唯一说话的 agent |
| 帮工（小动物） | 管家派出去的一个编码 session；每个帮工档案是一种动物 |
| 田地 | 帮工干活的位置。6 块，也是同时干活的上限；另有 3 块按等级开垦 |
| 播种 | 派活：一张工单，谁去做，在哪个项目 |
| 发芽、长叶、开花 | 这一轮的进度：开始、改了文件、改完跑了命令 |
| 成熟 | 这一轮做完，等你看、等你收 |
| 虫子 | 这一轮失败了 |
| 干裂 | 干着活但很久没动静 |
| 杂草 | 等你批准的权限请求（还没有，[提案](../.agents/notes/proposed/feature/2026-10-10-permission-requests-as-weeds.md)） |
| 地牌 | 项目名和帮工的分支 |
| 收获 | 把帮工的分支合进项目主分支，然后它收工 |
| 种植计划 | 一件长活拆成的一张图：每步一个帮工，有先后；每步合进计划自己的分支，最后整条收进主分支 |
| 铲除 | 叫停这一轮，或请它收工 |
| 仓库 | 收进主分支的成果：每张收获了的工单一份 |
| 帮工栏 | 全部帮工档案，在地里的亮着 |
| 农具房 | 农机（runtime）的设置和技能书 |
| 精力瓶 | 农机账户的剩余额度；pi 的是余额 |
| 经验和等级 | 你名下的 commit 数 |
| 金币和成就 | 活收进主分支才给；新手任务带你把农场走一遍；拿到的成就可以挂成称号。只是外观（[game-ui.md](game-ui.md)「计分」） |
