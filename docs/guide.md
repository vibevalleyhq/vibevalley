# 使用指南

从打开农场走到收下第一份活。界面细节见 [桌面架构与页面清单](docs/design/06-desktop-architecture-and-topology.md)，叫法见[用语](docs/README.md#用语)。

## 开始之前

- 打开 macOS 应用（[客户端](docs/subsystems/app.md)），服务端在里面（[development.md](docs/development.md)「跑起来」）。也可以只用命令行（[只用命令行派一个活](docs/development.md#只用命令行派一个活)）。
- 助手要 DeepSeek 的钥匙：在「设置」里填，或者环境变量 `DEEPSEEK_API_KEY` 已设好。帮工用本机登录好的农机（Claude Code、codex、ACP 农机……）或内置的 `vibevalley` 农机，在「农机」页启用。
- 仓库放在空间的 `repos/` 下，一个文件夹一个；没有的助手会建。空间默认在 `~/vibevalley-dev`（`VIBEVALLEY_WORK_ROOT`）。

## 1. 派第一张工单

在「聊天」页的田头里对助手说要做什么，说清在哪个仓库、做到什么程度算完：

> 在 clock-in 仓库里加一个查询打卡记录的接口，写测试。

助手挑一个帮工（你点了名就是它，否则按档案「适合的活」挑，见[挑档案](docs/subsystems/agent.md#模型和不变量)），按档案设置给它开一个分支和 worktree，或让它在仓库目录里干活，在田头发一条派活消息，下面挂着这件活的工单串。派不出去时它会说原因：地满了、仓库到了上限、余额或预算用完、档案停用。

也可以在「工单」页写一张挪到「处理中」，或者在农场点一块空地去建一张。

## 2. 看着它干

工单页打开这张工单，下面是**轨迹**（默认折成一行，展开看每一轮的话、命令和输出）。哪里没做好，在工单串里带一句话，它接着做。

农场里画的是同一件事：帮工走到一块地，地里发芽、长叶、开花；它读代码去书屋、跑命令去工坊。这块地就是这张工单，点它打开详情。

## 3. 完成

做完一轮，帮工在工单串里汇报，地里结出麦子或胡萝卜。在工单详情先看它的**改动**：提交、改的文件和 diff、没提交的、会不会冲突。确认后工单的分支合进主分支，帮工离开，工单关上；开了 PR 的仓库是推分支、开 PR，PR 合进去以后工单才关上。也可以对助手说「收下老周的活」。

**会冲突时**不合并，工单挂「有冲突」。让它解决冲突：它在自己的分支上把主分支合进来、解决、跑测试、提交，之后再完成一次。

## 4. 出了问题

| 你看到 | 是什么 | 怎么办 |
|---|---|---|
| 工单挂「有虫」，地里长虫 | 这一轮失败了，助手会说原因 | 带句话让它接着修，或取消 |
| 挂「没动静」，地干裂 | 4 分钟没有任何动静 | 看轨迹；卡住了就叫停 |
| 挂「重试中」 | 农机在自动重试 | 不用管 |
| 红色提醒 | 要你处理：登录、充值、换模型 | 照做 |

## 5. 中途改主意

- **带话**：在工单串里说一句。它在干活时话在下一步之前送到，歇着时接着干一轮。
- **叫停**：在工单上叫停正在干的那一轮；带句话就接着干。
- **取消**：关上工单。没合的提交留在它的分支上。

## 6. 在田头说话

没 @ 人的话给助手；`@w3` 叫的就是那个帮工，助手不插嘴。帮工之间也能 @，来回几次后停下等你。一个帮工老是叫不醒时，农场在它的串里提醒一句，等你亲自对它说。

## 7. 拆成子工单

一轮做不完的活，可以拆成一组有先后的子工单（[父子工单](docs/subsystems/issue.md#模型和不变量)）：

1. 对助手说把这张活拆成几步，或让帮工在工单里调 `issue_split` 把大活拆成一组子工单。
2. 每张子工单是普通的工单，带自己的帮工、验收标准和前置依赖（`blockedBy`）；互不依赖的子工单同时开工。
3. 子工单做完并过了检查后合进父工单的分支，后面的子工单接着基于父分支开工；哪张子工单没做成或冲突，就在那张子工单上修或重做。
4. 全部子工单完成后，在父工单里看整条父分支的汇总改动，一次验收、合进主分支。

## 8. 钱和额度

精力瓶是在用的农机里最紧的那个；`vibevalley` 农机的是 DeepSeek 余额。花费在工单详情、工单看板和汇报里。「农机」页可以设**每日预算**和**最多同时干活**：到了预算或余额用完，不再派新活，正在干的干完。

## 9. 重启之后

帮工还在各自的地上，正在干的那一轮记成「停在了半路」；带句话就接着原来的会话干。

## 安全须知

帮工没有权限确认、不开沙箱，能在这台机器上执行任意命令；它们只在工作目录里开工，服务端只听 127.0.0.1，没有从别的设备进来的门。只把你愿意交给编码 agent 的仓库放进工作目录。
