# @vibevalley/vdp

Node/TypeScript toolkit for VibeValley DevTools Protocol (VDP 2.0):

- WebSocket JSON-RPC client, isolated sandbox launcher, and UI source-digest incremental bundler.
- Full-tree `UI.dumpLayout` flattening, geometric diffing, and non-wrapping inline layout stability assertions.
- Frame recorder with optional `ffmpeg` H.264 `.mp4` export and HTML contact-sheet / playback gallery renderer.
- Scenario DSL and deterministic Agent `Play` helpers for Block Doc and Canvas co-editing verification.
