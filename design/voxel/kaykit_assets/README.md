# KayKit Medieval Hexagon Pack 1.0

The farm uses these models by Kay Lousberg under CC0 1.0. The upstream glTF, binary buffers and palette are stored together so Blender can rebuild the scene offline. The original license is included. [Pinned upstream assets](https://github.com/KayKit-Game-Assets/KayKit-Medieval-Hexagon-Pack-1.0/tree/84fa4e91af6a88989be7c99e0891cede11f2ca38/addons/kaykit_medieval_hexagon_pack/Assets/gltf) · [License](design/voxel/kaykit_assets/LICENSE.txt)

| Upstream directory under `Assets/gltf/` | Stems of the glTF and binary pairs |
|---|---|
| `buildings/blue/` | `building_blacksmith_blue`, `building_home_A_blue`, `building_well_blue`, `building_windmill_blue` |
| `decoration/nature/` | `tree_single_A` |

The models sample the same upstream `hexagons_medieval.png` palette. The farm's [Blender importer](design/voxel/kaykit.py) adds a separate UV set for the farm materials.
