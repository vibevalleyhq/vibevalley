一块地的游戏化

设计稿。三段、验收（抽穗、长草、结果）、缺肥和地块详情已经做了，见 .agents/notes/implemented/architecture/2026-10-18-every-issue-has-an-acceptance.md；几个人一起种、派一个看地的、验收标准逐条打勾和新农具还没做。一块地就是一张工单；代码相关的工单才带一个 worktree。一块地上的事按三段走：聊清楚、安排活、完成。每张工单都有一道验收，过了才算结果。下面把这三段、地里的样子、农活、谁在地上、验收和地块详情一起画出来。

一、三段，九个样子地里长成什么样，只看工单走到哪

从左往右是一张工单的一生。地的样子由服务端从工单的状态和它的帮工算出来，客户端只画。

聊清楚

你、管家和帮工在工单串里说清楚：要什么，怎么算做完

状态：backlog。缺肥是工单上的一个标记（它有没回答的问题），不是新状态。

定谁来种（可以几个人），要不要拆；代码活这时开 worktree

状态：in_review 就是「等验收」；过了验收是「结果」，收获以后 done。

三、农活每样工具就是一件对工单做的事

手

派活：把工单挪到待办；点一个帮工头像拉它下地（和在田头 @ 它一样）。

施肥 要新画肥料袋

补信息：回答帮工问的，补上验收标准。聊清楚这一段的农活。

浇水

带话：对整张工单说一句，地上的人都听得到；干裂的地浇一下就醒。

除草

照验收意见修：一棵草一条意见；也能点一棵草单独交代怎么修。

杀虫

这一轮失败了：让它带着出错的原因接着修。

收获

验收过了的地：合进主分支、提 PR，或者（不是代码活）直接关上。

铲除

不要了：叫停地上的人，工单挪到已取消；分支上有提交就留着。

稻草人 新

验收：站到抽穗的地里，按这块地的验收方式验（见第五节）。

四、一块地上的人不一定只有一个帮工

在田头 @ 谁，就是叫谁下地。一块地上可以有好几个，但锄头只有一把：谁拿着锄头谁改代码（一块地一个 worktree，两个人同时改会打架）。别人能看、能说、能把意见交给拿锄头的。不是代码活就没有锄头这回事，大家都能动手。

Claude 师傅主种：改代码拿着锄头
Codex 老匠帮手：@ 来写测试等锄头传过来
Pi 实验员看地的：验收插了 3 面小旗
管家拉人、分活、催站在田埂上

每一轮干活标着是谁干的，收成清单里每个提交带着名字，账本按人记功劳。锄头传了几次、现在在谁手上，地块详情里看得到。

五、验收每张工单都有；谁验、怎么验按工单定

你看一眼

最轻：你看过改动，点收获就是过了验收。小改动、文档活的默认。

跑检查

项目的 .vibevalley/check，或这张工单写下的检查命令；全过才结果，没过的每一项是一棵草。

派一个看地的

另一个帮工读工单的验收标准和改动，逐条打勾，挑出来的每条是一棵草。

必须你点头

最重：检查和看地的都过了，还要你点「验收通过」才结果。上线、改数据这类。

验收标准（聊清楚时写下）

命令行能用 issue status 挪状态
不许的转换被拒，并说为什么
看板拖卡调同一个接口
文档跟着改了（看地的拿不准，交给你）

没过验收：三棵草

  • IssueStatus 的错误没带原因 — 已修，拔掉了
  • 看板拖到「处理中」还在调旧的 start

不是代码活的地

比如「写本周周报」「查一下为什么昨天账单变高」。没有 worktree、没有分支、没有锄头；「安排活」那块只列谁在干；验收默认「你看一眼」，收获就是关上。地还在岛上，只是岛上没有它的篱笆院子。

「需要你」只放一件事

缺肥：回答问题；干裂：浇水或叫停；长虫：杀虫；等验收（你来验）：验收通过 / 写意见；结果：收获；冲突：让它解决。没有要你做的，这块就不出现。这一条由服务端算（和手机来电是同一份规则），客户端只画。

加什么放在哪为什么
验收方式 acceptance：看一眼 / 跑检查 / 看地的 / 必须你点头，可以叠加Issue每张工单都有验收，怎么验按工单定

地上的人 crew：主种、帮手、看地的；锄头在谁手上Issue（帮工还是 Session，一张工单可以有几个）@ 谁就是叫谁下地；一块地一把锄头
地的样子按工单算：PlotOfIssueprotocol/game_view.go现在按帮工的阶段算；以后看工单的阶段、验收和地上的人

八、还要你定的

  1. 验收方式的默认值：代码活默认「跑检查 + 你看一眼」，非代码活默认「你看一眼」？还是按项目设默认？
  2. 看地的是谁：管家挑一个和主种不同的档案，还是专门有一个「验收员」档案？
  3. 锄头怎么传：主种交回这一轮就自动放下锄头，下一个被 @ 的接过；还是你（或管家）手动交给谁？
  4. 缺肥谁来判：帮工在汇报里写「要问主人：……」就算一个问题；还是管家在聊清楚这一段读工单串来判？
  5. 先做哪块：建议先做验收（抽穗、结果、长草和稻草人），它最能把「交回来」和「做完了」分开；再做缺肥，最后做几个人一起种。
