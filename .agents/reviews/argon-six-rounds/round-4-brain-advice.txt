#### 二、如何在不搬移 `BrainHandle` 镜像的前提下，在 `vibevalley.ts` 保留全部 5 项并发与 Scope 保证

`vibevalley.ts` 只需要 `Brain` 的 **4 个操作**（`send`、`stop`、`progress`、`events`）加 `close`，根本不需要 `BrainHandle` 那 13 个方法的 Promise 镜像类和 `Set<listener>` 广播器。

在 `apps/server/src/runtime/vibevalley.ts` 中：

1. **定义窄 `BrainOwner`（或保留在 `vibevalley.ts`）**：
   ```ts
   export interface BrainOwner {
     readonly run: <A, E>(effect: Effect.Effect<A, E>) => Promise<A>;
     readonly scope: Scope.Scope;
   }
   ```
   （当 `options.owner` 在单测 `vibevalley.test.ts` 中未传时，默认 `{ run: Effect.runPromise, scope: Scope.makeUnsafe() }`，这样 `vibevalley.test.ts` 连 `standaloneOwner()` 都不需要传！）
2. **在 `vibevalley.ts` 的 `start` 中直接用 `owner.run` 走双子 Scope 与排空关闭**（约 25 行，直接把事件传给本地 `onBrainEvent` 函数，零 `BrainHandle` 包装、零 `Set<listener>`）：
   ```ts
   const { run, scope: parentScope } = options.owner ?? { run: Effect.runPromise, scope: Scope.makeUnsafe() };
   const scope = await run(Scope.fork(parentScope));
   const reading = await run(Scope.fork(parentScope));
   let brain: Brain;
   let reader: Fiber.Fiber<void>;
   try {
     brain = await run(Scope.provide(makeBrain({ ... }), scope));
     reader = await run(
       Scope.provide(
         Effect.flatMap(brain.events, (events) =>
           Effect.forkScoped(Stream.runForEach(events, (e) => Effect.sync(() => onBrainEvent(e)))),
         ),
         reading,
       ),
     );
   } catch (e) {
     await run(Effect.andThen(Scope.close(scope, Exit.void), Scope.close(reading, Exit.void)));
     throw e;
   }
   let closing: Promise<void> | undefined;
   const closeBrain = () =>
     (closing ??= run(
       Effect.andThen(Effect.andThen(Scope.close(scope, Exit.void), Fiber.await(reader)), Scope.close(reading, Exit.void)),
     ));
   ```
   核对 5 项保证：
   - **双子 Scope**：`scope`（跑 `makeBrain`）与 `reading`（跑 `brain.events` 消费纤程）都是 `parentScope` 的子 Scope。
   - **父 Scope 关闭自动中断**：当 `Runtime` 服务关闭 `parentScope` 时，`scope` 与 `reading` 作为子 Scope 自动关闭并打断在途运行。
   - **关闭排空到 `agent_closed`**：`closeBrain()` 先关 `scope`（触发 `makeBrain` 的 finalizer 停止运行、结算未完回合、最后发布 `agent_closed`），再 `Fiber.await(reader)` 等 `Stream.takeUntil(e => e.type === "agent_closed")` 读完包括最后一条 `agent_settled` 在内的全部事件，最后关 `reading`。
   - **并发 `close` 幂等**：`closing ??= ...` 保证多次并发调用共享同一个 Promise。
   - **初始化失败清理**：`try / catch` 在 `makeBrain` 或订阅失败时关闭 `scope` 和 `reading` 并重抛异常。
