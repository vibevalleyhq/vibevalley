# Agent Note: 记忆树：让主人看见农场在长

Status: proposed

## Problem

记性（[子系统](docs/subsystems/memory.md)）现在只在帮工页、管家页的「记性」页签上列成一张表：每个帮工档案一份，跨项目，最多 300 条，超了先删最久没用的。主人看不出农场「学会了」什么、学得多快、忘了什么，记性做得再好也没有存在感。EverOS 接进来以后还会多两样东西：从干活里提炼的经验（agent case：想做什么、怎么做的、关键心得）和从多次经验里提炼的手艺（agent skill），页面上目前也没有地方放。

## Proposal

### 设定

一棵**记忆树**，只给主人看，只讲成长：

| 树上 | 实际的事 |
|---|---|
| 树的大小：枝条展开多少、树干多粗 | 农场一共干过的轮数，只增不减 |
| 叶 | 一条 `note`（「记住：」、主人替它记的、`memory_add`）；一处挂的叶越多，那一簇树冠越大 |
| 果 | 一次经验：EverOS 的 agent case，没接 EverOS 时是本地的 `issue`（做过的活） |
| 种子 | 一门手艺：EverOS 的 agent skill，主人点「播种」才写进技能书 |
| 黄叶、落叶 | 标成 `fading` 的、快被忘掉的 |
| 一颗果闪一下 | 这条刚被想起 |
| 金线（星座） | 谁从谁长出来：种子提炼自哪几颗果，一颗果那件活记下了哪几片叶 |
| 淡蓝线 | 一起被想起：常被放进同一轮的几条 |

- **全局一棵**：汇总所有帮工档案、所有项目的记性。这只是给主人看的那一层；底下每个档案照旧用自己那份，挑法、存法、EverOS 的 `agent_id` 都不变。
- **树上不画项目和帮工**：没有枝对项目、没有帮工的牌子。鼠标停在一颗果、一片叶上才出现「阿郑 · 字幕面板」；面板里用「全部帮工」「全部项目」两个下拉筛。
- **不在农场里**：农场主界面只放活。HUD 右上角加一个「记忆树」按钮，跳到 `/tree`，整屏是树和面板；`/tree` 左上角「回农场」。
- **星空**：面板底下「抬头看星空」，同一份记性画成 3D 的像素星空：种子在核心，往外一圈是果的亮星，再外是叶的星尘，越远越旧（年轮就是时间）；快忘的星在外圈变暗、漂走。也不按项目、帮工分，筛选只是把不相干的星压暗。用 2D canvas 自己投影，低分辨率画、整数倍放大，不加 3D 库。
- **关联**：星空里所有线都淡淡地画着；停在一颗星上，它的星座（往上它从哪来、往下长出了什么，只走直上直下，不把同一颗果长出的别的种子拉进来）和一起被想起的亮起来，其余压暗；树上停在种子或果上，金线连到它的来处和长出的东西。点开的卡片列出「提炼自」「长出了」「常一起想起」，点一条跳过去。
- **成熟链**：叶 → 果 → 种子，就是「记下 → 有经验 → 成了手艺」。主人看一眼就知道农场在哪一步：叶多果少是记得多用得少，种子多是练出了手艺。
- **树是长出来的，不是贴图**：一份固定的「基因」（同一棵树每次长得一样），按农场长到多大展开：枝条一根根伸出来、树干变粗，每条记性都是树上真实的一片叶、一颗果。打开时从芽长到现在的样子；「最早—现在」拖到哪天，树就长回那天的样子。树长在码农谷的山头上：背景是 codex 照标题画面和农场画的一张（俯瞰山谷里的农场、河和海），白天、夜里各一张，同一构图；它按自己的像素画进那张低分辨率画布，和代码画的树在同一套像素格上。抬头分两半：先是山谷由白天变成夜里、树淡去，每片叶、每颗果飞上天；再是视线抬起来，山头沉下去，从山头仰望的夜空（第三张背景）从上面落下来，记忆的星空在它正中。

### 这一步（页面，数据用假的）

1. 素材（`design/pixel/gen.sh`，`process.py` 切成 `apps/web/public/pixel`）：HUD 的按钮和面板的小图标（`memory`，再 `hd-memory`：树、叶、果、种子、落叶、星、年轮、系金丝带的种子袋）；山头的背景 `tree-hill`、`tree-hill-night`（384×256，山头正中留一块空草地给树），和从山头仰望的夜空 `tree-sky`（正中空着给记忆的星空）。
2. 页面 `apps/web/src/tree/`：`TreePage`（面板和切换）、`Scene`（画布：背景、树、星空和中间的过渡）、`grow.ts`（树怎么从记性长出来，纯函数）、`rules.ts`（筛选、星的位置）、`mock.ts`（假的记性汇总）。路由 `/tree` 在壳外，和农场一样整屏。
3. HUD 右上角「记忆树」按钮。
4. 「播种」只在页面里改状态、弹一条提示，不写技能书。

### 下一步（接真数据）

- **形状和接口**：`mock.ts` 的 `MemoryTree` 搬进 protocol（`shapes.ts`、`schema.ts`），加接口 `memory.tree`，由 `Memories` 汇总所有档案：各种类的条数、`fading` 的、最近长出的、星空要的每一条（种类、档案、项目、时间、想起次数）。页面打开 `/tree` 时读一次，不进核心状态。
- **阶段由服务端算**：阶段的名字（芽、小苗、小树、大树、老树）和门槛是规则，归 `memory`，结论写进 `MemoryTree.stage`；页面只把累计轮数画成树的大小（`grow.ts` 的 `growthOf`），不算阶段。
- **累计的数**：累计轮数、累计想起次数现在没有存（`recalled` 跟着条目，条目删了就没了），要在库里加一个只增不减的计数。
- **EverOS**：现在只读回 cases 给检索用、不列（`Can().List` 为假）。要列出某个档案的 cases 和 skills，才能画果和种子；先确认 EverOS 有没有列的接口和 skill 的形状。
- **播种**：一门手艺（skill）被主人点头以后写进技能书（[agents-and-runtimes.md](docs/reference/agents-and-runtimes.md)「技能书」），写给哪些档案要定：默认全农场。
- **按钮上的角标**：有新长出的果或种子时 HUD 的按钮带一个点。这要进帧（`StateFrame` 加一个计数），和「`/tree` 打开时才读」分开做。
- **田头里的「想起了」**：帮工开工想起了记性时，田头里说一句「想起了：……」，点开跳到树上那颗果。农场里不再画摘果。
- **关联的来处**（`MemoryTree.links`）：金线是 EverOS skill 的来源 cases，本地是同一个 Session 写下的笔记和做过的活；淡蓝线从每个 Session 存在库里的「想起过的 id」两两数出来（[子系统](docs/subsystems/memory.md)「想起」第 4 步），要定数到多少次才算「常一起」。

## Alternatives considered

**星图做主体。** 好看，3D 能用深度表达时间。但它和像素农场割裂，遗忘画成星星熄灭像「死了」，主人会不敢让它忘；树的叶 → 果 → 种子更好读。所以星图留作树里的「抬头看星空」，负责全貌和时间。

**每个帮工一棵树（果园）。** 和数据的形状一致，但成长被分散到五棵树上，每棵都长得慢；一个档案同时派出几个帮工时也说不清哪棵是谁的。主人养的是整个班子，全局一棵树更贴近这一点。

**树上画项目和帮工（一枝一个项目、果上挂帮工的牌子）。** 第二轮概念图这样画过：四个项目时好看，十个项目、八个帮工时就成了分类图；树还会跟着项目的增删变形。分类挪到停留和筛选里，信息不丢。

**树种在农场里（每座岛上同一棵，亮这座岛的枝）。** 第三轮概念图画过，能直接看到「想起了」的摘果。但它占农场的地方，主界面应该只放活；摘果的那一下挪到田头里说。

**全局树背后也共享记性。** 让帮工能想起别的档案的经验。这会改挑法和 EverOS 的 `agent_id`，而主人要的是「看见成长」，不是共享；先只汇总展示，种子（技能书本来就能给任何档案用）以后再定写给谁。

**树用五张贴图，一个阶段一张。** 第一版这样做过：五张图之间是跳的，看不出「长」，只看出「换了一张」；画出来的树和面板、星空也不是一个风格。改成按数据长出来，一片叶就是一条记性，慢慢拖时间就看得见它一点点长。没用 SVG：矢量的线和农场的像素对不上，低分辨率画布放大和星空、农场是同一种画法。

**草地、山也用代码画。** 试过：天空分几条色带、两层山、草地、花和小路都用代码画，看起来是哪儿都行的一片草地，不像码农谷。背景交给 codex 照标题画面画（山头俯瞰谷里的农场），树还用代码长：背景不跟着数据变，树才跟着变。

**其他的成长比喻**：踩出来的路（路属于地方、记性属于档案，对不上）、种子仓（因果清楚但没有长大的感觉）、帮工自己长（同一档案的几个帮工得长一样）、酒窖、好感度、图鉴。叶 → 果 → 种子把种子仓的因果和好感度（树根下关于主人的）收进了树里。

## Acceptance criteria

- 农场 HUD 右上角有「记忆树」按钮，点了到 `/tree`；`/tree` 的「回农场」回到进来的农场。
- `/tree` 左边是长出来的树：打开时从芽长大，拖「最早—现在」就长回那天；果、叶、种子能停留看到「帮工 · 项目 · 内容」，点了在面板里看，快忘的叶发黄、飘落；右边面板有天数和轮数、叶果种子三个数、两个筛选、最近长出的、快落的叶、待播种的手艺、「抬头看星空」。
- 「抬头看星空」时叶和果飞上天成星，星空转得动、拖得动，筛选压暗不相干的星，「回到树下」回来。
- 停在一颗种子上，金线连到它提炼自的果、再到那些果记下的叶，淡蓝线连到一起被想起的；别的种子不亮。
- Playwright 覆盖按钮、页面和星空；`verify-app` 截图。

## Risks

- 假数据的形状会被真接口改掉；所以只放在 `src/tree/mock.ts` 一个文件里，页面只认 `MemoryTree` 一个类型。
- EverOS 可能没有列 cases、skills 的接口，那果和种子只能来自本地的 `issue` 和技能书，种子就没有「提炼」这一步。
- 关联多了（几千条记性）线会织成一张网：默认可能只画金线，淡蓝线只在停留时画。
- 树是代码画的，好不好看全靠参数（分叉的角度、长度、树冠的大小）；记性很多（几千条）时一簇簇树冠会糊成一团，要按数量缩小每片叶。
