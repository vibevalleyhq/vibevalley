# Agent Note: 把农场帮工做成可以转身和拿工具的像素 3D 角色

Status: proposed

## Problem

一只帮工在工坊挥锤、沿田埂小跑、停下来等回答，缩到全院视角后，玩家仍应认出是同一只动物，并看出它在做什么。现有图集有 7 种农夫，每种 18 张动作图，共 126 张。狐狸正面为 41×55 像素，侧面 38×58，背面 41×56；正面能看见蓝背带裤的扣子，背面是交叉肩带，侧面能看见白尾尖。这些差别比毛发细节更能建立角色身份。[原图集与脚底锚点](assets/pixel/sprites.json)

## Proposal

建议做**方块四肢、阶梯轮廓、像素材里那样上色的微缩动物**。借 Minecraft 的是积木关节和读得清的动作。狐狸保留外张的三角耳和白尖大尾巴，兔子保留长耳，刺猬要从背面看出刺丛，不能七只都戴一个方头套。草帽、衣服和工具各占一大块颜色，让正在做什么在半秒内可辨。

| 路线 | 院子里会看到什么 | 制作取舍 |
| --- | --- | --- |
| 整只动物按源像素向后挤厚 | 正面最像原画，转到三分之四角度就看出脸和裤子挤在一块厚板上 | 用于核对轮廓和比例 |
| 全身用大小一致的体素堆砌 | 能转圈，方块感强；短耳、眼睛和工具柄容易在全景里碎掉 | 适合方块建筑或道具 |
| 分部件建模，局部做像素阶梯 | 脸有口鼻深度，帽檐会遮眼，前后脚能交错，尾巴过田埂时有摆动 | 推荐。各物种重做头、耳和尾巴，共用脚底、握点和动作时序 |

**第一只选狐狸。** 样模已有草帽的帽冠和深色帽带、白口鼻、蓝裤、背面交叉肩带、鞋底与分节尾巴；主色取自现有图。模型有头、髋、四肢和尾巴的独立转轴，含一秒循环步行动画，可用 GLB 查看器转动。用 Blender 执行 `blender -b -P design/voxel/fox.py -- target/parity/voxel` 可生成模型和定妆图。[样模源文件](design/voxel/fox.py)

**动作由真实工作驱动。** 行走时步幅跟移动速度匹配，落脚后再启动作业循环。读文件时书在胸前展开，跑命令时锤子落在工坊台面，修改文件时锄头落到自己的田。等用户回答时双脚停稳、脸转向院门，让用户看见状态变化。工具跟随握点；田牌、焦点和点击区域继续跟随同一个帮工 ID。动作与地点已有映射。[场景](apps/mac/src/pixel/farm/scene.rs) · [走位](apps/mac/src/pixel/farm/world.rs)

**在院子里定稿。** 从侧面斜俯看全院，三维场景和帮工在固定正交镜头下成为像素画面。用同一批工单对照白天和夜间，以脚底为定位点检验耳尖、工具和地面接触。三间建筑露出侧墙和门廊，书招与炉口在正面。田埂沿院子的地面投影铺开，作物各阶段靠枝叶和穗头的轮廓识别。仓库岛保留中央的工单区域，四周用岸线、坡肩和地标区分主题，导出时留全树冠和风车顶。

**两份视觉交付单独评审。** 完整 Web 农场有自己的近像素验收，沿用源像素角色。3D 样板从同一份状态和相同脚底坐标取数，先将模型按现有朝向预渲染进第二套图集，直接在相同院子比较两种角色的大小、落脚和遮挡。以后若确定相机可旋转，再使用同一个 GLB 实时绘制。[Web 复刻与运行时总案](.agents/notes/proposed/architecture/2026-11-18-native-durable-execution.md)

**用共用材质给现成环境模型换肤。** 工坊、风车和水井采用可商用套件。瓦片沿屋脊、砖纹沿炉壁、木纹沿梁柱取样，生成的底色贴图随制作源入库。院子按原机位烘焙，点选按可见轮廓，砧台、炉口和烟囱分别校准落锤、炉光和冒烟的位置。帮工的动作与工具继续沿用自己的模型。

## Alternatives considered

**先给七种动物各做一整套动画。** 狐狸的握点和步幅还要在现有院子里验证。用狐狸先跑通「从门口走到田边、转身、挥工具、等回答」，再用长耳兔检验这套动作是否能跨物种；两只通过再扩大制作。

## Acceptance criteria

- 在同一视口以原有全景比例并排看像素原画和 3D 角色；狐狸的帽檐、脸、背带、尾尖从前、侧、后和两个斜角都可辨认。
- 用连续录像核对走路无滑步、转身时工具跟手、停下时双脚贴地；在前后两排田之间穿行，遮挡顺序与真实位置一致。
- 六只帮工同时入场，在同一台机器记录帧间隔，对照原版；核对逐人点选、木牌与工单 ID。
- 用窗口鼠标点一次屋顶、侧墙、人物及斜田四角，核对命中区域与工单、去处一致。

## Risks

原画的侧尾有透视夸张，正背面也不是严格的工程三视图。投影相交可估宽度，不能直接推出尾巴根部、帽沿厚度和手握工具的位置。应由样模定体积，再用三个方向的原稿逐面核对；加部件时应同时检查远景像素占比。
