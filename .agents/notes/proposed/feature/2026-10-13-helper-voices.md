# Agent Note: 帮工各自的音色

Status: proposed

## Problem

当前只有助手拥有语音合成与通话音色配置（[语音](docs/subsystems/voice.md)），帮工档案没有独立音色。用户在频道看多个帮工汇报时无法边干别的事边听播报，也听不出是哪个帮工在汇报。

## Proposal

1. **档案音色字段（`Agent.voice`）**：在 `packages/protocol/src/agent/` 的 `Agent` 上增加可选 `voice` 配置（仅保存与默认音色不同的覆盖项，如音色 ID 与开场白），在捏帮工页增加「声音」标签页。
2. **频道汇报朗读**：工作台聊天页提供「听汇报」开关；开启后，帮工贴入工单串或频道的回合汇报按各自档案音色在客户端排队朗读（不占用声网实时通话）。
3. **后续扩展**：待验证声网 ConvoAI `speak` 是否支持单会话动态切换音色后，再评估通话内转述切换帮工音色或直拨帮工。

## Alternatives considered

- **先加档案字段，以后再做发声功能**：无实际效果的设置项会误导用户以为保存即能出声；必须与频道汇报朗读同步上线。
- **所有帮工共用助手音色**：无法通过声音区分汇报人，失去多角色辨识度。

## Acceptance criteria

- 捏帮工页可为帮工档案选择并保存音色，未配置时回退默认音色。
- 开启「听汇报」后，不同音色的帮工汇报时按各自音色顺序朗读；未配密钥或合成失败时静默跳过，不影响文字显示。

## Risks

- 多个帮工同时交回汇报时需在客户端串行排队或仅朗读首句结论，避免声音重叠。
