# Agent Note: 设计体系的下一步：大纲里还缺的几块

Status: proposed

## Problem

[界面怎么做](docs/style/design.md) 把主人给的八篇大纲逐章对过，「部分」和「缺」的这些还没做：

- **原子**：分段的滑块不跟着滑；工单详情里有第二个 `Dot`；原地两次确认在每处各写一遍（档案、模板、频道……）；输入框里待发的附件没有磁贴，文件没有类型的图标。
- **会话**：在想、在写只有三个点，不说想了多久；没有斜杠命令；离开底部时没有「有新消息」的跳回。
- **动效和光影**：农场的田头还各写一份滚动遮罩，没用 `scroll-fade-y`。
- **多媒体**：图片点开是新标签页，没有看大图的浮层；串的侧面板、设置的导航定宽，拖不动；补丁没有语法高亮。
- **桌面和键盘**：没有快捷键一览；极窄的窗口有几处会撑破。

## Proposal

一项一个 PR，按对主人的影响排：

1. **原子收拢**：`Segmented` 的滑块用一个绝对定位的块跟着选中项滑（`ease-out`，280ms）；工单详情改用 `features/channel/bits.tsx` 的 `Dot`；把原地两次确认做成 `ui/` 里的一个 `ConfirmButton`（第一次点变成「X？」加危险按钮和「算了」，失焦或 Esc 收回），各处换成它。
2. **在想多久**：服务端在 `orchestrators[id]` 和会话的阶段里带上开始想的时刻，页面在点旁边写「想了 12 秒」，过一分钟换成分钟；想完折成一行「想了 40 秒 · 用了 3 个工具」，点开是干活的经过。
3. **看大图**：消息里的图片点开是一个对话框（`animate-pop-in`），左右键翻同一条消息里的图，Esc 关；原图另开一个按钮。
4. **补丁的语法高亮**：在 Web Worker 里用 Shiki 按文件后缀着色，颜色接调色板（浅色、深色各一套）；大补丁先出不着色的，着好色再换。
5. **拖得动的分割线**：串的侧面板和设置的导航能拖宽窄，记在本机的偏好里；拖的时候 `cursor-col-resize`，双击回默认。
6. **斜杠命令**：输入框里 `/` 出一张命令表（派活、记工单、定时、找文件），和 `@` 名单同一套写法；命令就是接口（`api.ts` 的一行），不另起一套。
7. **跳回最新**：消息列表离开底部时，底上出一个「有 N 条新消息」的胶囊，点了平滑滚到底（280ms）。
8. **快捷键一览**：`?` 打开一张表，列出全部快捷键，和代码里注册的同一份表生成。
9. **田头的遮罩**：`farm/chat` 的两处遮罩换成 `scroll-fade-y`。

## Alternatives considered

- **一次做完**：每一项都要截图、验收，混在一起审不动；一项一个 PR，做完一项删一项。
- **照搬大纲的玻璃材质、着色器光效、气泡**：见 [界面怎么做](docs/style/design.md) 对照表里「不做」的理由。

## Acceptance criteria

- 每一项做完，[界面怎么做](docs/style/design.md) 对照表里那一行变成「有」，本篇划掉那一项；全部做完删掉本篇。

## Risks

- 语法高亮的库大：放进 Worker，按需加载语言，不进首屏的包。
- 想了多久要服务端带开始的时刻：是核心状态的新字段，照「核心状态只有一份」加在 `shapes.ts` 和 `reduce` 里。
