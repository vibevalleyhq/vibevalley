# Agent Note: 商店和每日任务

Status: proposed

## Problem

游戏账本（[游戏](docs/subsystems/game.md)）产出的金币目前只会累积、没有消费出口；任务面板也只有长期等级与成就，缺少每日轻量目标。

## Proposal

- **农场商店**：开放 `apps/web/src/farm/panels/` 中的商店面板，支持用金币购买院子外观装饰（稻草人、彩旗、狗窝、花坛）与常用工单种子模板。严格遵守「只卖外观与便利模板，不卖并发槽位或生产力」原则（[游戏](docs/subsystems/game.md#模型和不变量)）。
- **每日任务**：按本地自然日生成一组轻量目标（如当日收获 3 单、一轮过完成 2 单），达成后记入 `game_ledger` 发放金币。

## Alternatives considered

- **用金币解锁并发帮工上限或加速农机**：将生产力变成游戏奖品，会诱导用户为了刷金币而拆小单、多花模型费用。

## Acceptance criteria

- 主人可用金币在商店购买装饰物并持久化展示在农场院子中。
- 每日生成新任务，达成条件后自动结算并发放金币。

## Risks

- 每日任务条件若设置不当可能诱导凑单派活，任务类型须限制在正常交付质量指标内。
