# Agent Note: 商店和每日任务

Status: proposed

## Problem

金币只会累积，没有用处；任务面板只有等级和成就，没有让人每天回来的小目标。

## Proposal

- 商店：金币买外观（稻草人、彩旗、狗窝……）和种子（常用工单模板）、开垦新地。只卖外观，不卖生产力（[game-ui.md](../../../../docs/game-ui.md)「计分」）。农场的「商店」面板已经摆出这几样和价钱，还没开张（`app/lib/farm/panels.dart`）。
- 每日任务：比如今天收 3 次菜、不长虫做完 2 单；完成给金币。

## Alternatives considered

**金币换更多的地或更快的帮工。** 把生产力当奖品，会诱导多派活、多花钱。

## Acceptance criteria

能用金币买到一件装饰并在农场上看到；每天有一组新任务，完成后拿到金币。

## Risks

任务设计不好会诱导为了刷任务而派活，反而花钱。
