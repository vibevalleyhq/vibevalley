# Agent Note: 手机竖屏版面

Status: proposed

## Problem

像素农场（[农场的皮](docs/subsystems/farm.md)）当前是一张 384×256 的横向画布。在手机竖屏宽度下，整张画布按整数倍缩小后只占屏幕中间一条，地块、木牌和按钮太小，难以看清和点准。

## Proposal

按竖屏掌上效果图（`design/mockups/v2/D-mobile.png`）提供手机竖屏专属构图：
- **三段式竖屏布局**：顶部为农场等级与仓库切换栏，中部为按竖屏重排的田地与院子画布，底部为农具栏与语音键。
- **半屏抽屉面板**：田头聊天窗与地块详情以占下半屏的可收起抽屉展开，不遮挡顶部状态与正在看的田地。

## Alternatives considered

- **继续整张横向画布等比缩放**：四周留白过多（`apps/web/src/farm/world/world.ts`），竖屏单手操作点不准地块。
- **手机端退化为纯文字列表**：丢失像素农场核心体验，导致桌面与手机成为两个割裂的产品。

## Acceptance criteria

- 在手机竖屏宽度下自动切换竖屏田地构图，可看清每块地的庄稼与木牌状态。
- 单手可点开地块详情、带话、收获并与助手对话。

## Risks

- 需单独维护一张竖屏背景贴图与对应的网格寻路可达区域。
