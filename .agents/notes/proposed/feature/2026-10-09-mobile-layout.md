# Agent Note: 手机竖屏版面

Status: proposed

## Problem

农场是一张横向的画，手机上整张图缩得很小，地块、气泡、按钮都不好点。主人离开电脑时也想看一眼帮工、收个菜、带句话。

## Proposal

按型号 D（竖屏掌上）的效果图（`design/mockups/v2/D-mobile.png`）：上面是状态，中间是田地，下面是工具和语音键；对话窗口占满下半屏，可以收起。田地按竖屏重新排，不缩放横向的整张画。

## Alternatives considered

**整张画缩放（现状）。** 能用，但看不清、点不准。

**只做一个列表视图。** 丢了农场，和桌面版是两个产品。

## Acceptance criteria

在手机宽度下能看清每块地的状态，能点开详情、带话、收获、对管家说话。

## Risks

要另画一张竖屏背景，另描能走的路；两套版面要一起维护。
