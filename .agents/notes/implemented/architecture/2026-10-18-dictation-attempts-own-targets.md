# Agent Note: 一段听写拥有录音和输入目标

Status: implemented

## Problem

农场与工作台共享听写实例，但停止按钮临时提供写字回调。换到另一个输入框停止，会把前一个输入框开始的录音交给后一个；权限、录音启动和转写也可能在原输入框销毁后返回。

## Decision

一次听写拥有起始目标、录音器、临时文件和取消信号。开始时固定目标，停止按钮不能换掉它；输入框离开时使目标失效并取消这一段。录音启动结束前不释放同一个录音器，取消后的迟到结果不再提交。当前行为见 [语音参考](../../../../docs/reference/voice.md#听写)。

`DictationButton` 接收输入控制器，自己维护目标的绑定与销毁；两个页面不用各自保存取消代次或检查异步回调里的 `mounted`。

## Alternatives considered

**在每个回调里加页面存活检查。** 只挡住销毁后的写字，不能挡住在另一输入框按停止造成的目标替换，也不能管理尚未返回的录音启动。

**每个输入框各开一个听写器。** 会允许两个页面同时争用麦克风；保留农场作用域内的单次听写，独立管理每次目标。

## Consequences

取消转写不用等待远端返回。录音器启动尚未结束时先等待它结束再清理，下一段不会复用尚未释放的录音器。识别出的字仍只进入草稿，不自动发送。

## Verification

测试覆盖两个不同目标交替按开始/停止、权限迟到、录音文件迟到、转写结果迟到，以及取消后的录音器只释放一次。
