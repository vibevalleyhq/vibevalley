# Agent Note: 像素村的像素密一倍

Status: implemented

## Problem

像素村是 384×256 个像素格，在 1152 宽的窗口里放大 3 倍。主人觉得可以再细：帮工的脸、庄稼、道具上的小东西在这个格子上都画不下，和风来之国那种细密的画面还差一截。直接改密度，看起来要重画几十张雪碧图，还要把关卡、路径、点击区、HUD 布局里写死的像素坐标全部乘 2。

## Decision

**素材按类重画，引擎按分辨率加载；逻辑坐标不动。** 现在的样子见 [framework.md](../../../../docs/framework.md)「素材」。

- **一类一张雪碧图，整张交给 codex**（主人的主意）：`gen.sh hd-<名字>` 拿现在那张当参照，「格子不变、像素密一倍」重画（雪碧图一格 4 个图像像素，地图 2 个）。同一个角色的帧在一次里画完，风格一致；格子和名字都不变，`process.py` 用 `PIXEL_DENSITY=2`、`PIXEL_RAW_PREFIX=hd-`、`PIXEL_OUT` 照原来的规则切，只是每张的目标高度翻倍，产物先放在 `design/pixel/hd/`，游戏的素材不动。（这是迁移时的做法。换过去以后 `process.py` 默认就按游戏素材的密度、从 `raw/hd-<名字>.png` 切，直接写进 `app/assets/pixel/`；这三个变量只在另试一种密度时用，`design/pixel/hd/` 没有了。）
- **迁移时逐帧检查、整套切换**：比对每帧和旧帧放大两倍后的大小与形状，拼院子新旧对比图，把重画的和没重画的（旧图放大两倍）拼成一整套，所以随时能试、最后一次换过去，游戏里不会新旧密度混在一起。这几个脚本只为迁移，换完删了。
- **引擎不换坐标**：游戏仍按 384×256 的格子摆所有东西。新图按分辨率 2 加载（`atResolution`），在 Pixi 里的逻辑大小还是原来的；整个场景画进分辨率为密度的离屏纹理（`pixelStage` 的 `density`），光照和发亮的滤镜跟着它的分辨率（Pixi 滤镜默认是 1，会把细节压回去），光照仍按逻辑格子算；读像素（地图取色、做法线贴图）按真实像素读。DOM 里用到的像素图（HUD 图标、头像、按钮）把清单里的宽高和锚点除以密度。密度不设开关：`web/src/pixel/density.ts` 用地图的宽除以关卡的宽，素材是哪种密度，引擎就按哪种画。（这是网页版在 Pixi 里的做法，随 [网页退役](../simplification/2026-10-14-retire-the-web-page.md) 删了。Flutter 的像素村（Flame）照样按 384×256 的格子摆（`app/lib/village/level.dart`），`app/lib/sprites/atlas.dart` 用地图的宽除以关卡的宽得出密度，把清单里的宽高和落脚点都除以它。）
- **在 Retina 屏上仍是整数倍**：1152 宽的窗口里一格是 3 个 CSS 像素、6 个物理像素，新图一个像素正好 3 个物理像素。

## Alternatives considered

**坐标全部乘 2，世界变成 768×512。** 关卡、路径、点击区、HUD、动画里的偏移都要改，改一处漏一处；按分辨率加载让逻辑一行不动。

**一张张单独重画。** 帧和帧之间容易不一致（脸、颜色、描边），也更慢；整张雪碧图一起画，codex 一次看到这个角色的全部动作。

**让 codex 把整张大图拆成几层。** 首页那里试过：重画的几层对不齐，接缝会露。这里每张都是照原图加密，不拆层。

**只密 1.5 倍（576×384）。** 在 1152 宽的窗口里正好放大 2 倍，非 Retina 屏也是整数倍；但细节涨得少，主人要的是密一倍。

## Consequences

- 大约 85 张雪碧图要重画（codex 每张几分钟，六路并行一个半小时左右）。
- 非 Retina 的外接屏上，新图一个像素是 1.5 个物理像素，会有一点粗细不匀。
- 光照仍按逻辑格子算：一个光照值落在 2×2 个新像素上，看不出来。
- DOM 里的像素图在 1 倍屏上是缩小一半显示的。

## Verification

- 85 张雪碧图全部重画：先试点地图、熊农夫、管家、狗，再地块、道具、前景、熊的姿势、兔子和狐狸，然后其余 75 张六路并行。迁移时用过的检查脚本（已删，见 git 历史）逐帧比对每帧和旧帧放大两倍后的大小、在落脚点上对齐后的形状：741 帧里 734 帧过；没过的 7 帧是两三个像素的小鸟、树叶、鱼、蝴蝶和缩小按钮，看过都比原来好。
- 形状比对看不出丢字：语言 logo 第一次重画丢了大半字母（C、C++、3、5、JS、TS、php、R……），加上「每个字母、数字、符号照原样」的要求重画三张后都在。
- 新地图在工坊烟囱上画了一缕静止的烟，游戏自己会画动的，让 codex 照它去掉烟（和首页一样）。
- 换进游戏：起初画面并没有变细，查出光照滤镜默认分辨率 1，改成跟随后，Retina 截图里管家的脸、门上的玻璃、木柴、晾的衣服都清楚，光照、帮工走路、HUD、聊天窗口照旧。按默认参数重切一张，结果和游戏里的一字节不差。
- 新画的原图（`raw/hd-*.png`，约 145 MB）和原来的原图一样进仓库；换下来的放在不进仓库的 `raw/hd-rejected/`。
