# Agent Note: 自己的 agent：Go 写的，当管家，也当帮工

Status: implemented

## Problem

管家原先跑在 pi 上：会话、工具、压缩、记性都在 pi 的 SDK 里，VibeValley 只能从外面喂提示、听事件。想加一种能力（定时醒来、按需加载技能、开子 agent、接 MCP），要么等 pi 支持，要么绕开它再搭一层。

服务端、形状和规则后来都是 Go，管家那段还是 TypeScript 和 Promise，错误、取消、资源释放要在两种世界之间翻译。主人要一个自己的 agent：在 VibeValley 里当管家、当帮工，也能单独跑。

## Decision

VibeValley 有自己的 agent，Go 写，分三层：

| 包 | 管什么 |
|---|---|
| `server/pkg/ai` | 调模型：模型表、流式、工具调用、价格和思考强度；请求按 OpenAI 兼容和 Anthropic Messages 两种格式编，现在模型表里只有 DeepSeek |
| `server/pkg/agentcore` | agent 循环、工具的调用和结果、订阅 |
| `server/pkg/agent` | 完整的编码 agent：会话、压缩、技能、记性、MCP、定时、帮手、编码工具 |

类型名和字面量照 pi 对齐，便于两边对照。它不知道农场：农场的工具和现状由服务端在装它的时候给。

- **工具**：`read_file`、`write_file`、`edit_file`、`list_dir`、`grep`、`bash`、`web_fetch`；`spawn_agent` 开一个不存盘的帮手。
- **技能**：按 Agent Skills 的约定找 `SKILL.md`，系统提示只列名字和什么时候用，`load_skill` 读正文。
- **记性**：自己的 `MEMORY.md`，系统提示里带着；`remember`、`rewrite_memory` 改它，`search_archive` 翻压掉的旧对话。
- **MCP**：HTTP 和 stdio。
- **定时**：`schedule`、`list_schedules`、`cancel_schedule`，cron 表达式。
- **会话**：一条消息一行存盘，重启接着聊；超预算把旧对话折成摘要，原文归档。
- **模型**：默认 `deepseek-flash`（DeepSeek V4.1 Flash）；钥匙每次请求前取（应用里的 `settings.json` 或 `DEEPSEEK_API_KEY`），换了立刻生效。

它的三个位置：

- **管家**：`server/internal/manager`，内置档案 `manager`，只在 VibeValley 自己的 agent 上跑；`manager.runtime=pi` 被拒绝。
- **帮工**：`server/pkg/agent/oarruntime` 把它包成 smith 的农机 `vibevalley`；帮工在项目的 worktree 里干活，农场工具经 `/mcp` 给它。
- **命令行**：`server/cmd/vibevalley`，不带命令时就是它，也能 `runtime chat` 和别的农机直接聊。

## Alternatives considered

**接着用 pi，缺什么在外面补。** 定时、子 agent、MCP、按需技能都得在 pi 外面再搭一层；搭出来还是两套世界，pi 一升级就要跟着改。pi 留作可选的一种农机。

**用 nanobot 本身。** Python，有自己的总线、渠道和记性，会和 VibeValley 的田头、连接器重复成两套。照它的结构写需要的部分。

**用 Vercel AI SDK、LangChain.js 这类框架。** 能用，但又是 Promise 世界；和整个仓库一套写法、取消和资源释放跟着 Go 走，比少写几百行更要紧。

**先当帮工再当管家。** 帮工要和 Claude Code、Codex 比编码能力；管家要的是受控的农场工具和低延迟，先在管家这里把循环、会话、压缩磨稳。

## Consequences

- 脑子是自己的：加能力改自己的包；管家、帮工、命令行用同一份代码。
- DeepSeek 的工具调用没有 Claude 稳：靠步数上限、坏参数时给模型一句看得懂的错误、可选参数传 null 当作没填来兜住。
- 跑命令没有沙箱，和别的帮工一样：只在工作目录里开工、服务端只听本机；管家不给 shell 和写文件的工具。
- 压缩会丢细节：原文归档、摘要里写明归档在哪，`search_archive` 能翻回去。
- 要跟着上游维护：DeepSeek 和 Anthropic 的接口、MCP 的 SDK、pi 的字面量。

## Verification

- 不连网：`pkg/agent` 测循环、插话、步数上限、会话和旧文件、压缩、技能、帮手、定时、停下；`pkg/agentcore` 测循环和工具；`internal/manager` 测派活、语音、汇报、叫醒；`pkg/agent/oarruntime` 测工具、事件、插话、排队、停下和 MCP。
- `go vet ./... && go test ./...`。
