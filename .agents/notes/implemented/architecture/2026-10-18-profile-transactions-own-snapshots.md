# Agent Note: 档案事务拥有可修改的工作集

Status: implemented

## Problem

档案存储的 `change` 给回调一个浅拷贝。保存、删除、创建各自记住复制切片和字典，才能保证写盘失败不修改当前版本；嵌套环境变量、MCP 参数或预算指针仍可能绕过这层约定。

## Decision

`change` 提供完整独立的工作集，回调只修改领域数据。提交前再取得不受回调保留引用影响的版本；写盘成功后才发布它。集合复制从七个回调移回存储所有者，读取接口继续返回独立快照。

## Alternatives considered

**要求每个回调继续按需复制。** 每增加一个集合或指针字段都增加隐式约定，失败时是否回滚由修改位置决定，事务接口自身没有保证。

**直接修改当前版本，失败后再读文件恢复。** 其他引用可能已经观察到修改，恢复还会再次依赖磁盘，不能撤回已经泄露的值。

## Consequences

一次更新多复制小型配置工作集，换来统一的失败隔离与发布后隔离。输入参数、创建结果和回调保留的临时引用都不能修改已发布版本。

## Verification

测试在一个事务中修改技能、标签、环境变量、外观指针、MCP 参数与请求头、农机预算后制造写盘失败，验证全部保持原值；另测成功提交后修改保留工作集及创建结果不影响存储。
