# Agent Note: 农场手机：要你处理的事当来电，从核心状态现算

Status: implemented

## Problem

农场有好几处在等你：熟了的地、没做成的活、拆好的计划、@ 你的话。它们散在地上的牌子、帮工栏的红点、田头的未读里，人不盯着画面就不知道有事；桌面客户端有系统通知，浏览器里没有一个「有人找你」的地方。主人想要一部像素风的手机，把这些当来电收起来。

## Decision

行为见 [farm-ui.md](../../../../docs/reference/farm-ui.md)「农场手机」。

- **来电不存，现算**：来电就是 Inbox（`protocol.Inbox(state)`，`server/internal/protocol/inbox.go`），从核心状态读出此刻要你处理的事；服务端每一帧把它放在 `inbox` 里推给客户端（当时是页面上 core 的 `incomingCalls`，客户端迁到 Flutter 时挪进了 protocol 的 `view`，后来成了帧上的 Inbox，见 [要你处理的事是一个 Inbox](../architecture/2026-10-15-inbox.md)）。核心状态只有一份，手机不另记一份「待办」。
- **来电号稳定**：帮工的来电号带轮次（`w1:harvest:2`），同一件事一直是同一个号，下一轮又熟了是新号；计划按计划和失败的那一步，那一步重试后又没做成算第二次（`p1:failed:api:2`，`PlaybookNode.failures` 记它失败了几次），消息按消息号。页面据此只响一次、记住接过哪个。
- **接没接过只属于页面**：接了、挂了的号和通话记录放在客户端的 `phoneProvider` 里（`app/lib/phone/calls.dart`），这次打开有效；重开应用后还在等你的又算未接，不响（农场画面刚打开时在的都算旧的）。
- **接听就是去处理**：打开那块地、种植计划或那个频道，不新造处理的界面。
- **长相**：Flutter 组件画的像素手机（按格子画的像素小图标、机身和四种绿的液晶屏，`app/lib/phone/`），不新生成素材；响铃是合成的音效 `ring`。放在左下角、帮工的上面，往上打开。
- **一部手机，几个应用**：主屏上是未接、记录、打给管家、频道、计划和小游戏：当时是方块、小恐龙两个，后来又加了推箱子（[手机里的仓库推箱子](2026-10-12-phone-sokoban.md)）、贪吃虫和种田 2048。方块和小恐龙的规则写成纯函数（`app/lib/phone/blocks.dart`、`dino.dart`）：一局是一个值，每一步是值到值，自带种子的随机，能重放、能测；画面（`blocks_game.dart`、`dino_game.dart`）只跑时钟（Flutter 的 `Ticker`，规则不碰定时器）、接按键和十字键、用 `CustomPaint` 画。

## Alternatives considered

**服务端推「来电」事件。** 要新的事实或工地事件、要存，而这些事页面已经都知道；现算更简单，模拟服务器也自动有。

**来电存进浏览器（localStorage）。** 刷新后「接过」还记得，但 core 不碰 localStorage，要多一个服务；先只在这次页面里记，真需要再加。

**自动弹出整个通话界面接管画面。** 打扰太大；手机在角落弹出、20 秒没理就收起成未接。

## Consequences

- 重开应用后，还没处理的事会回到未接（不响）。
- Electron 桌面客户端的系统通知和手机曾各有一套「什么值得叫你」；现在桌面版是 Flutter 的，它的通知（`app/lib/host/notify.dart`）读服务端帧里的 `inbox`，和手机用同一套。

## Verification

- `app/test/phone/games_test.dart` 的「方块」「小恐龙」：同一个种子发同样的块、七块一袋；墙挡住移动、转身被推开；满行消掉、上面的落下、按级计分；堆到顶结束。跳起落下、只能从地上跳；站着撞仙人掌、跳起来过去；高的鸟蹲过去；越跑越快、种子能重放。
- 来电的规则当时由 `packages/core/test/phone.test.ts` 逐条测：哪些帮工会打（熟了、没做成、冲突、没动静；到场、干活、重试中的不打，计划里的不打），新的在前；同一轮同一个号、下一轮新号；计划拆好了、有一步失败了由管家打；没读的 @ 你的话会打，读过的、没 @ 你的、没说完的不打；接过的不再响。这个测试随 core 删了；现在 Go 的 `Inbox` 由 `server/internal/protocol/inbox_rules_test.go` 逐条测（上面这些，加上每种来电的号怎么定、文字截到多长、同一时刻的先后），`TestReduceGolden` 也对着黄金数据比每一步的 `inbox`。
- `app/test/phone/widget_test.dart` 用假的 Inbox 代替服务端：农场打开时已有的来电算未接、不响；新来电响铃、打开手机，接听打开那块地、计划或频道，记录里有「接了」；挂断的离开未接；响 20 秒没人接算未接。当时在浏览器里用模拟服务器验过，模拟服务器随网页删了。
