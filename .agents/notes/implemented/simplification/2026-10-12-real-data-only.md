# Agent Note: 页面只给真实数据

Status: implemented

## Problem

主人看技能书、农具、帮工这些页面，要看到的是这台机器上真实的东西。原来有三处不是：

- **技能书**是 VibeValley 种子里写死的六个示例技能（先写测试、小步提交……），这台机器上各农机真装了的技能（几十上百个）反而看不到。
- **农机的技能、MCP 服务器、工具清单**一直是空的：oar 能读，服务端探测农机时没去读。
- **服务端没开时，页面悄悄换成模拟农场**：帮工、技能、额度都是假的，只在角落里有个「模拟数据」的小字。主人以为在看真的。

## Decision

- **探测农机时读它的清单**：oar 的 `skills`、`mcpServers`、`tools`，在帮工干活的根目录下读（`server/internal/runs/runtimes.go`）。读不到的仍是空。
- **技能书分两部分**：上面是这台机器上装的技能，从各农机的清单合成一份（`installedSkills`），只读，帮工按需自己加载；下面是 VibeValley 自己的技能库，主人写的，派活时写进人设。
- **不再预置示例技能**：新装的农场技能库是空的。原来种下的示例，在配置里一字没改的，启动时拿掉，档案上对它们的勾也拿掉；改过的留着（`withoutExamples`）。示例只留给模拟服务器（`EXAMPLE_SKILLS`）；模拟服务器后来随 [网页退役](2026-10-14-retire-the-web-page.md) 删了，示例现在只在种子数据里（`seeds.json` 的 `exampleSkills`），给 `withoutExamples` 认出没改过的那几个。
- **页面只连真的服务端**：连不上就在顶上说「连不上 VibeValley 服务端」，每几秒再试，连上自己消失；不再自动换成模拟。模拟服务器只在网址加 `?mock` 时用，调试台的场景和没有服务端时看画面还用它。这一条取代了[页面里的模拟服务器](../testing/2026-10-09-in-page-mock-and-debug-console.md)里「`/api/health` 不答应时自动用它」的那部分，模拟服务器本身照旧。（模拟服务器和 `?mock` 后来也删了；Flutter 客户端连不上时照样在顶上说这一句，见 `app/lib/shell/server_away.dart`。）

帮工档案的种子（后端老周这些）这次没动：它们是真能派活的配置，不是假数据。

## Alternatives considered

**把装了的技能复制进 VibeValley 的技能库。** 两份会对不上：农机那边改了、删了，VibeValley 这边不知道。装了的就留在农机那里，只读地列出来。

**保留示例技能，只在旁边加一栏真的。** 示例和真装的混在一页，主人分不清哪些真在起作用。

**服务端没开时还用模拟，但把提示做大。** 页面上的一切仍然是假的，提示再大也容易被当成真的。没有服务端就说没有。

## Consequences

- 只开客户端不开服务端时，它是空的，顶上一条提示；要看画面得开一个服务端（原来的 `?mock` 随网页删了）。
- 第一次探测农机多花一两秒：claude 读清单要启动一次它的进程。
- 主人原来勾了示例技能的档案，人设里少了那几段话。改过的示例不受影响。
